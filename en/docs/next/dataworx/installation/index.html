Installation and Setup

Install and Uninstall DataWorX​

Install​

  1. Run the Setup program, enter the installation path and continue.
  2. Accept the license agreement.
  3. Enter user and organization information.
  4. Click Install to proceed.
  5. Install Node.js.
  6. Install PostgreSQL. (See History DB installation)
  7. Reboot the computer after installation completes.

The default installation path is C:\EdgeHub\DataWorX.

Uninstall​

  1. Open Control Panel and go to Programs and Features.
  2. Select DataWorX from the app list and run the uninstaller.
  3. Click Uninstall in the confirmation dialog.
  4. Reboot the computer and verify that the program was removed.

Port Settings​

DataWorX lets you change the web access port used by the browser and the server (backend) port that the web server (nginx) forwards requests to.

  • Configuration file path: [DataWorX installation path]\bin\EngineeringTool\Client\conf
  • With the default installation: C:\EdgeHub\DataWorX\bin\EngineeringTool\Client\conf
Configuration filePurposeDefault
client-port.confWeb access port used by the browser7600
server-port.confPort used by the DataWorX server (backend)5000

Browser requests arrive at the web access port and are forwarded internally to the server port.

Changing the web access port​

Open client-port.conf in a text editor and change the listen value.

listen 7600;

For example, to use port 8080, change it to listen 8080; and connect via http://[server IP]:8080.

Changing the server port​

Open server-port.conf and change the port in the proxy_pass address.

proxy_pass http://127.0.0.1:5000;

The DataWorX server runs on the port set in this file, and the web server forwards requests to the same port. If the port value cannot be found, the default of 5000 is used.

:::caution Notes on changing ports

  • After changing the configuration files you must restart the DataWorX services (server and web server) for the change to take effect.
  • Avoid ports already in use by other programs. A port conflict prevents normal startup.
  • The new port must be allowed in the Windows Firewall for external access. :::

Install and Remove the History DB​

The history DB is installed separately from DataWorX. DataWorX uses PostgreSQL for tag history and alarm history logging, and you may change the default settings during installation.

Install​

Set the following items in the PostgreSQL installation wizard.

SettingDataWorX default / recommendation
Installation pathUse the default
ComponentsPostgreSQL Server and Command Line Tools are required. pgAdmin and Stack Builder are optional
Data directoryDefault C:\EdgeHub\DataWorX\bin\Historian\pgData
Passworddxmaster
Port7678
Cluster LocaleDefault locale

pgAdmin is useful for managing PostgreSQL data, but it is excluded from the default components because you can download and install the latest version separately from the pgAdmin download page.

:::warning If you changed the port or password If you changed the PostgreSQL port or password during installation, you must apply the same values to these files:

  • Template project: [DataWorX installation path]\bin\EngineeringTool\Server\template\[package name]\Config\DX-HISTORIAN.conf
  • User project: [Project path]\[Project name]\Config\DX-HISTORIAN.conf

These values are used when the history DB is created in PostgreSQL. :::

Verify the installation​

  1. Check that PostgreSQL was installed to the installation path and the data directory.
  2. In Task Manager → Services, confirm that dataworx-historian-pg is running.
  3. In Task Manager → Details, confirm that postgres.exe is running.

Remove​

Run the uninstall program inside the PostgreSQL installation path to remove PostgreSQL.

Engine Language​

The engine language setting selects Korean or English. It determines the language of the Report and Modbus Server engines.

Configure it from the DataWorX tray icon on the local PC. Click Yes and restart EdgeHub to apply the language.

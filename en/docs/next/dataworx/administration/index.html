Administration

Global management features that are independent of any project — login, licensing, users and system settings. Most are reached through the application bar.

Login​

The user authentication page for DataWorX. You are redirected here when there is no session or the session has ended.

On first use, log in with the super administrator account admin and the initial password 1234.

First login​

On first login you must set an initial password along with the welcome screen. Passwords must be 8 to 15 characters.

Login attempt lock​

After a configured number of failed login attempts, login is blocked for a configured period. When locked, the number of failures and the remaining lock time are displayed. Configure this under System settings → User security.

Password expiry​

When a password expiry period is set, logging in after the period has passed shows the password change screen. Clicking Change later keeps the password and resets the expiry period. Configure this under Member management.

Profile​

Edit the information of the logged-in user.

  • User name — 3 to 30 characters, English or Korean
  • The ID and role cannot be changed.
  • Click the Set password button at the bottom right of the profile card to change the password. It takes effect immediately when you confirm the modal.

License​

:::info Administrator only The license page can only be used with administrator privileges. :::

If no license is registered, a Trial license allowing 1,000 tags for 14 days from the DataWorX installation date is granted automatically. After 14 days a license must be registered.

License issuance​

A license key is provided by e-mail when DataWorX is purchased.

  • EID — The login ID for offline license registration
  • Product Key — The product number for online license registration

Online license registration​

Use this in an environment with internet access.

  1. Click the Edit button at the top right of License Management.
  2. Select Online as the registration method.
  3. Enter the Product Key from the license e-mail into Product Key (pkId) and save.
  4. Confirm the registration on the license information screen.

Offline license registration​

Use this in an environment without internet access.

  1. Click the Download offline key button at the top left of the License Management table to download DataWorX_Information.c2v.
  2. From a PC with internet access, go to ls-electric.prod.sentinelcloud.com/customer.
  3. Log in with the EID or Product ID listed in the license file.
  4. Click Activate Offline and enter the e-mail address that should receive the license activation file.
  5. Click Select File and upload the *.c2v file saved in step 1.
  6. Click Complete Activation to activate the offline license.
  7. An Activation was successful message appears; download the offline license file (.V2CP). A compressed copy is also sent to the e-mail address you entered.
  8. Upload the downloaded .V2CP file and click Save.
  9. Confirm the registration on the license information screen.

License Transfer​

Moves a license in use to another PC.

  • Executable path: [DataWorX installation path]\ETC\LicenseRehostTool\LicenseRehostTool.exe
  • With the default installation: C:\EdgeHub\DataWorX\ETC\LicenseRehostTool\LicenseRehostTool.exe
note

This transfer method applies from DataWorX v4.0.0 onward. If you need to migrate or keep license keys from a version earlier than v4.0.0, contact LS ELECTRIC.

Two PCs are involved — the New PC and the Current PC. Run LicenseRehostTool.exe on both.

1. [New PC] Create the info file (.id)​

  1. Run LicenseRehostTool.exe on the new PC.
  2. Go to the Step 1. Generate New PC Info (New PC) area.
  3. Click the ... button next to Save PC Info File (.id) and choose a save path.
  4. Click Create at the bottom right to generate the info file (.id).
  5. Copy the .id file to the current PC using a USB drive or similar.

2. [Current PC] Create the transfer file (.h2h)​

  1. Run LicenseRehostTool.exe on the current PC.
  2. Go to the Step 2. Export License File (Current PC) area.
  3. Select the product license to transfer from the Select License to Transfer list.
  4. Click the ... button next to Import New PC Info File (.id) and load the .id file from step 1.
  5. Click the ... button next to Save Transfer File and choose where the transfer file (.h2h) is saved.
  6. Click Create to generate the transfer file (.h2h) and copy it back to the new PC.

3. [New PC] Activate the license​

On the new PC, run the product application and register the .h2h file from step 2 in the license registration window to complete activation.

:::danger Essential precautions 1. Check for running product sessions — Before creating the .h2h file on the current PC, the product application must be completely closed. If a session remains after closing, open http://localhost:1947/_int_/sessions.html and click Disconnect in the Actions column for that product session.

2. Do not lose the transfer file (.h2h) — If the generated .h2h file is lost, it cannot be regenerated under any circumstances. The license then becomes unusable on both the current and the new PC. License loss caused by failing to back up in advance is not covered by free reissue or compensation. :::

Member Management​

FeatureHow
User listView the users currently added to DataWorX
Add user+ button at the top right of the list card
Edit userMenu button in the list → edit page (the ID cannot be changed)
Set passwordSet password button at the bottom right of the user information card
Delete userMenu button in the list. Multi-select with Ctrl/Shift to delete several
  • User ID — 3 to 30 characters using letters, numbers and the special characters - and _
  • User name — 3 to 30 characters, English or Korean
  • Roles — Multiple roles can be selected. See Access Control
caution

The initial administrator admin cannot be deleted.

Password expiry settings​

Turn on the toggle on the password information card and set the validity period and time unit. Logging in after that period shows the password reset window.

Session expiry settings​

Turn on the toggle on the session settings card and set the session validity period and time unit. The user is logged out automatically after that period of inactivity on the web screen. When the web screen is closed, the login is only kept for one hour.

Access Control​

Create roles and grant permissions. Navigate via the application bar → Member management → Access control. Roles created here can be assigned per user.

System Log​

View the DataWorX system log. On entering the page the date range is set to today.

Setting the log period​

Click the date field in the toolbar above the table to change the range. Shortcut buttons to the left of the date picker make common ranges easy to select.

ShortcutDescription
TodayToday
YesterdayYesterday
Last 7 Days7 days ago → today
Last WeekLast Sunday → last Saturday
Current Month1st of this month → today
Last MonthLast month

Future dates cannot be selected, and the start date cannot be later than the end date.

Log retention​

Click the Set period button above the table to set the retention period. 0 means permanent; a number sets the retention in days.

System Info​

View the resource information of the server running DataWorX.

  • Details — Server name, operating system, CPU type, memory, system type, IP address
  • Hard disk — Usage per storage device
  • CPU usage / Memory usage — Current usage
  • CPU usage trend / Network trend — Usage trend graphs

Drivers / About​

  • Drivers — View the drivers available in DataWorX. Clicking the info icon on a driver card opens the right panel with details. For the full list, see Drivers.

Version: DX:4.1.0, VX:5.0.0

뷰어

DataWorX의 태그 이력, 알람 이력, 실시간 알람, 프로젝트 내 파일을 조회하는 페이지입니다. 좌측 메인 내비게이션을 통해 이동합니다.

note

실시간 알람은 프로젝트가 실행 중일 때만 확인할 수 있습니다.

뷰어 관리​

태그 이력, 알람 이력, 실시간 알람, 파일을 위한 뷰어를 생성하고 관리합니다.

작업방법
뷰어 추가서브 내비게이션 상단 또는 테이블 우측 상단의 뷰어 추가 버튼. 서브 내비게이션의 더보기 아이콘으로 지정된 타입의 뷰어 생성 가능
뷰어 정보서브 내비게이션 메뉴 / 테이블 행 더보기 / 테이블 Lock 모드에서 열기 버튼
뷰어 수정서브 내비게이션 메뉴 / 테이블 행 더보기 / 테이블 Edit 모드에서 열기 버튼
뷰어 삭제서브 내비게이션 메뉴 / 테이블 행 더보기

공통 조회 방법​

태그 이력, 알람 이력, 실시간 알람 뷰어는 동일한 조회·필터링 방식을 사용합니다.

이력 검색​

일시를 지정하면 설정된 기간의 이력을 조회할 수 있습니다.

필터링​

뷰어 생성 시 설정했던 필터 조건을 변경할 수 있습니다.

  1. 날짜 선택기 옆의 뷰어 필터 버튼을 클릭합니다.
  2. 우측 패널에서 필터 조건을 변경합니다.
  3. 우측 패널 하단의 확인 버튼을 클릭합니다.
tip
  • 우측 패널 상단의 토글을 켜면 모든 사용자의 PC에 필터가 적용됩니다.
  • 필터 설정이 개별 적용된 경우 초기화 버튼이 활성화되며, 클릭하면 뷰어 정보에 따라 필터 설정이 초기화됩니다.

상세 정보​

태그명 컬럼의 열기 버튼을 누르면 우측 패널에서 이력 상세 정보를 확인할 수 있습니다.

태그 이력​

런타임 시 이력 엔진이 태그 히스토리안을 통해 수집한 태그 이력을 조회합니다. 수집모델을 통해 기록된 이력을 확인할 수 있습니다.

알람 이력​

런타임 시 발생한 태그 관련 알람 이력을 조회합니다.

실시간 알람​

런타임 시 실시간으로 발생하는 알람을 조회합니다. 실시간 알람은 런타임 시에만 조회할 수 있습니다.

실시간 알람 업데이트​

  • 자동 갱신 토글이 켜져 있는 경우 — 1초마다 자동으로 업데이트됩니다.
  • 자동 갱신 토글이 꺼져 있는 경우 — 수동 업데이트 버튼이 활성화됩니다.

실시간 알람 인지​

테이블 내에서 발생한 실시간 알람을 선택한 후, 테이블 우측 상단의 알람 확인 버튼을 누르면 알람이 인지됩니다.

caution

실시간 알람의 상세 정보를 보거나 알람을 인지하려면 자동 갱신 토글을 꺼야 합니다.

앱바 실시간 알람​

애플리케이션 바의 시스템 설정 모달에서 실시간 알람을 활성화하면, 애플리케이션 바에 알림 아이콘이 표시됩니다.

  • 자동 갱신 토글이 켜져 있으면 1초마다 자동 업데이트, 꺼져 있으면 수동 업데이트 버튼 활성화
  • 리스트 좌측의 + 버튼으로 상세 정보 펼침, - 버튼으로 접기
  • 리스트 좌측의 체크 아이콘으로 개별 알람 인지. 아이템 선택 후 우측 상단 체크 아이콘으로 일괄 인지 처리

파일​

프로젝트가 생성된 폴더의 파일과 프로젝트 리포트 내용을 미리 볼 수 있습니다.

파일 목록​

파일 뷰어 생성 시 설정한 경로 내 파일을 확인합니다. 파일 타입이 레포트인 경우 경로는 레포트가 저장되는 폴더로 자동 지정됩니다.

지원되는 파일 확장자​

.rpt · .json · .csv · .xlsx · .pdf · .docx · .jpg · .png · .svg · .gif

파일 미리보기​

파일명 컬럼의 열기 버튼을 누르면 우측 패널에서 파일을 미리볼 수 있습니다. 우측 패널 상단의 버튼으로 패널 사이즈를 조절할 수 있습니다.

note

복사 기능은 텍스트 형식의 파일에만 제공됩니다.

Viewer

The page for querying tag history, alarm history, realtime alarms and files in the project. Reached from the left main navigation.

note

Realtime alarms can only be viewed while the project is running.

Viewer Management​

Create and manage viewers for tag history, alarm history, realtime alarms and files.

ActionHow
Add viewerAdd viewer button at the top of the sub navigation or the top right of the table. The more icon in the sub navigation creates a viewer of a specific type
Viewer infoSub navigation menu / Table row more menu / Open button in Lock mode
Edit viewerSub navigation menu / Table row more menu / Open button in Edit mode
Delete viewerSub navigation menu / Table row more menu

Common Query Features​

The tag history, alarm history and realtime alarm viewers share the same query and filtering behaviour.

Searching history​

Specify a date and time to query the history for that period.

Filtering​

Change the filter conditions set when the viewer was created.

  1. Click the Viewer filter button next to the date picker.
  2. Change the filter conditions in the right panel.
  3. Click Confirm at the bottom of the right panel.
tip
  • Turning on the toggle at the top of the right panel applies the filter to every user's PC.
  • When the filter has been applied individually, the reset button becomes available and restores the filter according to the viewer information.

Detail information​

Clicking the Open button in the tag name column shows the history details in the right panel.

Tag History​

Queries the tag history collected at runtime through the Tag Historian. You can view the history recorded by the historian models.

Alarm History​

Queries the tag alarm history raised at runtime.

Realtime Alarm​

Queries alarms raised in real time at runtime. Realtime alarms can only be queried at runtime.

Realtime alarm updates​

  • Auto-refresh toggle on — Updates automatically every second.
  • Auto-refresh toggle off — The manual update button becomes available.

Acknowledging realtime alarms​

Select a realtime alarm in the table, then click the Acknowledge alarm button at the top right of the table.

caution

To view realtime alarm details or acknowledge an alarm, the auto-refresh toggle must be turned off.

App-bar realtime alarms​

Enabling realtime alarms in the system settings modal of the application bar adds a notification icon to the application bar.

  • With auto-refresh on it updates every second; with it off the manual update button becomes available
  • The + button on the left of the list expands the details; - collapses them
  • The check icon on the left of the list acknowledges an individual alarm. Select items and click the check icon at the top right to acknowledge in bulk

File​

Preview files in the project folder and the contents of project reports.

File list​

Shows the files under the path set when the file viewer was created. When the file type is report, the path is set automatically to the folder where reports are saved.

Supported file extensions​

.rpt · .json · .csv · .xlsx · .pdf · .docx · .jpg · .png · .svg · .gif

File preview​

Clicking the Open button in the file name column previews the file in the right panel. The button at the top right of the panel adjusts the panel size.

note

The copy feature is only available for text-format files.

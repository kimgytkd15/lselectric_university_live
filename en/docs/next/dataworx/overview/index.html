Overview

DataWorX is a web-based software that bridges the OT and IT domains. It runs on Microsoft Windows and provides broad extensibility, high reliability, fast processing and operational convenience.

With DataWorX you can collect, process and store data from a wide range of equipment in the OT domain, apply field-specific logic through programming, and build a system that reliably and flexibly delivers data to upper-level systems in the IT domain.

:::info Document version This document is written against DataWorX v4.1.0 (online manual v3.0.6). :::

Features​

Open Architecture​

An open structure built on open source, with excellent extensibility and compatibility, enables reliable communication with devices and effective interfacing with other systems.

Manage Project Efficiently​

Create and manage different types of projects, and use the copy feature for easy engineering.

Tag Engineering​

Two perspectives on tag management provide engineering efficiency and operator convenience at the same time.

FeatureDescription
Physical ViewA tree-style tag navigator that follows the equipment layout. Device configuration and tag work can be done together
Logical ViewDisplays logical tag groups like Windows Explorer, so tags can be managed by purpose from an operator's point of view
Excel Import/ExportAdd, output and edit tags in bulk using .xlsx files
OperationThe value of a memory tag can be a numeric or a logical expression
SpreadsheetAdd or edit the data of multiple tags at once in a spreadsheet
Import LS PLCImport a variable file (CSV) saved from XG5000 and register it automatically as DataWorX tags

Driver Convenience​

  • Tag Simulator — Run your application exactly as in the field even without a real device, or before communication is established, by feeding tags with data from various rules. This dramatically reduces debugging time.

    Data TypeSimulation Type
    AnalogRandom, Sine wave, Triangle wave, Sawtooth wave, Controllable, XG5000
    DigitalControllable, Random, Change, XG5000
    StringRandom, Controllable

  • Auto-register system tags when adding devices — Registering a device automatically registers its communication status tags, so device status and communication performance can be checked.

  • Validate Tags — Check whether the I/O addresses and communication block settings of XGI/XGK series devices are configured correctly, catching misconfigurations before actual communication.

LogicFlow​

JavaScript-based programming is supported. Instead of writing scripting languages by hand, DataWorX provides a visual development tool called LogicFlow, where field logic is built with a drag-and-drop GUI.

Web-Based System​

Use a web browser to access the DataWorX system for engineering and runtime. There is no need to be physically present at the DataWorX server machine — everything can be done remotely over the network.

System Requirements​

CategoryRecommended Specification
Operating SystemWindows 11 64-bit Pro or later
CPUIntel Core i5 or higher, or equivalent
RAMAt least 16 GB

DisplayGraphics card and monitor supporting a minimum resolution of 1024 × 768

caution

Actual performance varies with project size, number of tags, communication cycle, number of connected devices and operating environment. A large number of tags requires higher CPU and RAM specifications.

License​

DataWorX uses an SW license key — a license with no physical copy.

License Policy​

  • If a project exceeds the number of tags allowed by the SW license, tags are no longer saved and the runtime cannot run.
  • If the license expires, you are returned to the project list screen and can no longer OPEN or RUN a project. Register a new license to continue.

Usage examples

  • With a 1,000-tag license, the runtime will not run once you exceed 1,000 tags.
  • With a term license, the runtime runs as long as the registered tag count stays at or below the licensed number during the term.
  • Without a license, the runtime runs with 1,000 tags for 14 days from the date of DataWorX installation.

For license registration and transfer procedures, see Administration.

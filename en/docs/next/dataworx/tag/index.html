태그

태그는 DataWorX 시스템의 기본 단위입니다. DataWorX에서 지원하고 운영되는 모든 기능은 등록된 태그를 기반으로 동작합니다.

  • 태그는 현장 기기로부터 신호를 받아 처리하는 입출력(I/O) 클래스와, 상위 시스템에서 필요하여 가상으로 등록하는 메모리(Memory) 클래스로 구분됩니다.
  • 속성 창을 통해 태그 정보를 일목요연하게 확인하고 편집할 수 있습니다.
  • Excel 파일 입출력을 지원하여 대량의 태그 데이터를 빠르게 등록·관리할 수 있습니다.

태그 보기​

서브 내비게이션의 탭으로 보기 방식을 변경합니다.

기기별 보기 (Physical)​

태그를 이름에 상관없이 물리적으로 디바이스에 연결된 형태에 따라 보여줍니다. 클래스에 따라 입출력과 메모리로 구분됩니다.

  • 입출력 태그 — 실제 필드 디바이스와의 통신을 통해 데이터를 수집하는 태그
  • 메모리 태그 — 입출력 태그를 제외한 태그로, 데이터를 활용하기 위해 가상으로 생성
    • 일반태그 — 사용자가 직접 엔지니어링을 통해 생성한 태그
    • 그룹태그 — 태그를 계층적으로 그룹화하는 논리적 구조. 파일 탐색기의 폴더와 같은 역할

그룹별 보기 (Logical)​

태그를 그룹화하여 논리적인 계층 구조로 보여줍니다. 태그명을 . 단위로 구분하여 트리 구조로 표현합니다.

태그명이 A.B.C인 경우, 그룹 A와 A.B가 생성되고 그 아래에 태그 A.B.C가 생성됩니다.

tip

그룹별 보기를 사용하면 공장의 라인, 제품, 특징 등을 그룹화하여 쉽게 태그를 관리할 수 있습니다.

디지털 On/Off 라벨​

태그 타입이 Digital인 경우 설정합니다.

  • On 라벨 — 태그값이 1일 때 표시될 문자열
  • Off 라벨 — 태그값이 0일 때 표시될 문자열

장비값 설정​

디바이스에서 수집하는 태그값에 대한 속성입니다. 태그 데이터 타입보다 넓은 범위를 지원합니다.

  • 정수: INT8 / INT16 / INT32 / INT64 / UINT8 / UINT16 / UINT32 / UINT64
  • 실수: FLOAT / DOUBLE
  • BCD: BCD8(-79~79) / BCD16(-7,999~7,999) / BCD32 / BCD64
  • 부호 없는 BCD: UBCD8(0~99) / UBCD16(0~9,999) / UBCD32 / UBCD64
  • 비트: BIT1(0~1) / BIT2(0~3) / BIT3(0~7) / BIT4(0~15)

장비값 데이터 최솟값 / 최댓값도 함께 설정합니다.

태그 변환​

디바이스에서 수집한 장비값을 공업치값으로 변환하는 규칙입니다.

변환 규칙설명
없음장비값이 변환 없이 그대로 공업치값으로 적용
Ratio/Bias기울기/절편 방식. 공업치값 = (Ratio × 장비값) + Bias
비율장비값과 공업치값의 최소/최댓값을 이용하여 비율로 변환
비율/Offset비율 변환 결과에 Offset을 더함
  • Ratio — 장비값에 곱할 값
  • Bias — 장비값에 Ratio를 곱한 값에 더할 값
  • 오프셋 — 비율 변환 결과에 더할 값

알람 설정​

태그 타입이 Analog 또는 Digital일 때 사용 가능합니다.

속성설명
알람 이벤트알람 발생 또는 해제 시 이벤트 발생
지연시간알람 발생에 대한 지연시간. 지연시간만큼 대기 후 그 시점의 값으로 알람 발생. 0은 비활성화
데드밴드알람 불감대 영역. 경계에서 미세하게 변화할 때 불필요한 알람을 방지. Analog에서만 사용 가능
알람 레벨알람의 중요도 1~10
알람 타입태그 타입에 따른 알람 발생 규칙
발생 메시지 / 복구 메시지알람 발생·복구 시 표시될 문자열
사용자 지정 메시지사용자 정의 문자열 1~4

Analog 알람 타입

  • 경계 알람 — HH > HI > LO > LL 순서로 값을 설정합니다. HH는 공업치 최댓값을 초과할 수 없고, LL은 공업치 최솟값보다 커야 합니다.
  • 변화량 알람 — 변화값 이상으로 값이 변화하면 발생. 0 이상의 숫자만 입력 가능
  • 이격 알람 — 이격 기준(절대값/상대값), 기준값 또는 기준태그, 주 이격값, 보조 이격값(주 이격값보다 작아야 함)

Digital 알람 타입 — OFF / ON / ON > OFF / OFF > ON / CHANGE

알람 발생·해제 규칙의 상세는 알람 매니저를 참고하세요.

연산​

태그 클래스가 Memory이며 타입이 Analog 또는 Digital일 때 설정합니다.

  • 연산 주기 — 기본값 0. 0이면 연산식이 관련 태그들의 전후 관계를 설정하여 이벤트 방식으로 동작하고, 양수이면 각 태그가 독립적으로 정주기로 연산식을 수행합니다.
  • 연산식 — 수치연산식 및 논리연산식

태그 관리​

작업방법
태그 추가서브 내비게이션 아이템 메뉴 → 하위 태그 추가 / 테이블 우측 상단 → 태그 버튼. 우측 패널 우측 상단의 확대 버튼으로 패널을 넓힐 수 있음
태그 정보서브 내비게이션 메뉴 / 테이블 행 더보기 / 테이블 Lock 모드에서 태그명 옆 열기 버튼
태그 수정서브 내비게이션 메뉴 / 테이블 행 더보기 / 테이블 Edit 모드에서 태그명 옆 열기 버튼
태그 삭제테이블 행 더보기 / 다중 선택 후 테이블 좌측 상단 삭제 버튼
태그 복제테이블 행 더보기 → 태그 복제
tip

태그 복제를 활용하면 기존 설정 정보에서 태그명만 변경하여 다른 태그로 저장할 수 있습니다. 연속 복제를 고려하여 확인 버튼을 클릭해도 우측 패널이 자동으로 닫히지 않습니다.

그룹 관리​

태그를 그룹화하여 논리적인 계층 구조로 관리합니다. 그룹은 서브 내비게이션의 그룹별 보기 탭에서 확인하며, 태그 목록 상단에 위치합니다.

추가 / 정보 / 수정 / 삭제 방법은 태그와 동일하게 서브 내비게이션 메뉴, 테이블 행 더보기 메뉴, 테이블 우측 상단 버튼을 통해 수행합니다.

추가 기능​

태그 복사 / 붙여넣기​

note

태그 복사/붙여넣기 기능은 그룹별 보기에서만 사용 가능합니다.

  1. 태그 목록에서 태그 또는 그룹 아이템을 선택합니다(다중 선택 가능).
  2. 테이블 좌측 상단의 복사 버튼 또는 Ctrl + C를 입력합니다.
  3. 붙여넣을 위치로 이동한 뒤 붙여넣기 버튼 또는 Ctrl + V를 입력합니다. 취소하려면 X 버튼을 클릭합니다.

태그 내보내기 / 가져오기​

대량의 태그 작업 시 엑셀(.xlsx) 파일을 이용합니다. 테이블 우측 상단 더보기 메뉴에서 사용합니다.

  • 내보내기 — 프로젝트의 태그를 엑셀 파일로 저장합니다. 파일명은 tags_[날짜]_[시간] 입니다.
  • 가져오기 — 엑셀 파일의 데이터를 태그로 저장합니다. 태그 이름이 같으면 업데이트, 다르면 추가됩니다. 결과는 전체·성공·실패 개수 요약 화면으로 표시되며, 다운로드 버튼으로 엑셀 저장이 가능합니다.

LS PLC 가져오기​

LS ELECTRIC PLC의 변수 파일(CSV)을 가져와 태그로 등록합니다. XG5000에서 프로젝트 → 변수/설명 파일로 저장으로 내보낸 CSV 파일을 사용합니다.

:::warning 지원 드라이버 LS PLC 가져오기는 XGI/XGK 계열 드라이버(XGIEnet, XGICnet, XGKEnet, XGKCnet)만 지원합니다. :::

  1. 채널 선택 — 지원 드라이버를 사용하는 채널을 선택합니다.
  2. 디바이스 선택 — 선택한 채널에 속한 디바이스를 선택합니다.
  3. CSV 파일 업로드 — 파일 내 Type이 Tag인 변수만 대상이며, 한글 포함 파일도 자동 인식(EUC-KR)됩니다.
  4. 태그 검토 및 수정 — 업로드한 변수가 스프레드시트로 표시됩니다.
    • 컬럼: TagName, Type, Variable, Address, DataType, Property, Scope, Comment
    • 태그명은 변수명 기준으로 자동 생성되며 .은 _로, ,는 -로 치환됩니다. 변수명이 없으면 Variable_[주소] 형식으로 생성됩니다.
    • 데이터 타입에 따라 태그 타입이 자동 매핑됩니다(BIT/BOOL → 디지털, INT/WORD/DINT/REAL → 아날로그).
    • 데이터 타입이 BIT/WORD인 변수는 BIT_, WORD_ 접두어가 붙은 두 개의 태그로 분리되어 등록됩니다.
  5. 가져오기 결과 — 이름이 같으면 수정(Edit), 다르면 추가(Add). 결과를 엑셀로 저장할 수 있습니다.

입출력 태그 검사기​

디바이스에 등록된 입출력 태그의 통신 주소와 통신 블록이 올바르게 설정되어 있는지 검사합니다. 주소 형식·사용 영역·비트 타입, 블록의 존재 여부·범위·사용 여부 등을 점검하여 실제 통신 전에 잘못된 설정을 확인할 수 있습니다.

:::warning 지원 드라이버 입출력 태그 검사기는 XGI/XGK 계열 드라이버(XGIEnet, XGICnet, XGILoader, XGKEnet, XGKCnet, XGKLoader)만 지원합니다. :::

테이블 우측 상단 더보기 메뉴 → 태그 유효성 검사로 실행합니다.

  1. 디바이스 선택 — 지원하지 않는 드라이버의 디바이스는 비활성 표시됩니다. 개별 또는 전체 선택 후 검사 시작을 클릭합니다.
  2. 검사 결과 — 전체 / 오류 / 경고 / 정상 개수 요약과 함께 이슈가 있는 태그가 표시됩니다. 결과 표는 심각도, 태그명, 메시지, 채널, 디바이스, 입출력 주소 컬럼으로 구성됩니다. 다운로드 버튼으로 io_tag_validation_result_[날짜]_[시간].xlsx 저장이 가능합니다.

심각도 구분

심각도설명
오류 (Error)실제 통신이 정상적으로 이루어지지 않는 설정 오류. 반드시 수정 필요
경고 (Warning)통신은 가능하나 확인이 필요한 상태 (비활성 디바이스/블록, 허용 범위 초과 등)
정상 (OK)발견된 이슈 없음 (결과 표에는 이슈가 있는 태그만 표시)

오류 검사 항목

  • 입출력 주소에 앞뒤 공백이 포함된 경우
  • XGI 주소가 %로 시작하지 않거나, XGK 주소가 %로 시작하는 경우
  • 주소 형식을 해석할 수 없는 경우(파싱 실패)
  • 드라이버에서 사용할 수 없는 영역을 사용한 경우
  • 비트 주소인데 태그 타입이 Digital이 아닌 경우
  • 해당 영역에 블록을 만들 수 없어 매칭 블록이 존재할 수 없는 경우
  • 매칭되는 통신 블록이 없거나, 해당 영역의 블록이 없거나, 블록 범위를 벗어난 경우

경고 검사 항목

  • 사용여부가 비활성화된 디바이스에 속한 태그인 경우
  • 디바이스에 Auto Block이 설정되어 있는 경우
  • 매칭되는 블록이 비활성화 상태인 경우
  • 영역별 허용 범위를 벗어난 경우

디바이스를 찾을 수 없거나, 지원하지 않는 드라이버이거나, 검사 중 오류가 발생한 디바이스는 태그 단위가 아닌 디바이스 단위로 결과 표에 오류로 표시됩니다.

스프레드 시트​

시트를 이용하여 태그 데이터를 추가하거나 수정합니다. 사용 방법은 화면 구성 요소 — 스프레드 시트와 동일합니다.

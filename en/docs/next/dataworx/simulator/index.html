시뮬레이터

DataWorX에 장비가 실제로 연결되어 있지 않아도 시뮬레이터 기능을 통해 가상의 값을 태그에 공급할 수 있습니다.

또한 XG5000 소프트웨어의 시뮬레이션과 연동되어 PLC 래더의 모니터링 값을 DataWorX 시뮬레이션에 전송할 수 있고, 반대로 DataWorX의 제어 명령을 XG5000 시뮬레이션에 보낼 수 있습니다.

시뮬레이션 관리​

시뮬레이션 목록​

속성설명
이름시뮬레이션의 명칭
Default런타임 시작 시 적용할 시뮬레이션. Boolean 타입으로 표시되며 1개만 설정 가능
적용런타임 중 현재 적용되고 있는 시뮬레이션은 TRUE로 표시 (읽기 전용)
수정일마지막 수정시간 (읽기 전용)

기본적으로 Default_Simulation이 생성되어 있습니다.

추가 / 정보 / 수정 / 삭제 / 복제​

작업방법
추가서브 내비게이션 상단 또는 테이블 우측 상단의 시뮬레이션 추가 버튼
정보서브 내비게이션 메뉴 / 테이블 행 더보기 / 테이블 Lock 모드에서 열기 버튼
수정서브 내비게이션 메뉴 / 테이블 행 더보기 / 테이블 Edit 모드에서 열기 버튼
삭제서브 내비게이션 메뉴 / 테이블 행 더보기 / 다중 선택 후 좌측 상단 삭제 버튼
복제서브 내비게이션 메뉴 / 테이블 행 더보기 → 시뮬레이션 복제

시뮬레이션 복제는 기존 시뮬레이션의 모든 설정 정보를 복사하여 새로운 시뮬레이션을 생성할 때 사용합니다.

시뮬레이션 설정​

서브 내비게이션의 시뮬레이션명 또는 테이블 행의 시뮬레이션명을 클릭하여 이동합니다.

설정 정보​

태그의 속성과 시뮬레이션 설정 속성이 하나의 테이블에 표시됩니다.

속성설명
Name태그명
Description태그 설명
IO/Memory입출력 태그 / 메모리 태그
Type아날로그 / 디지털 / 스트링
데이터 타입태그의 데이터 타입
채널 / 디바이스태그가 속한 채널명 / 디바이스명
시뮬레이션 타입시뮬레이션 발생 규칙
최소 / 최대데이터 발생 시 변동영역의 하한 / 상한 값
초깃값시뮬레이션 규칙이 적용될 때의 초기 시작 값
주기주기를 가지는 시뮬레이션 타입(사인파형, 톱니파형, 삼각파형, 랜덤)의 1주기 시간

시뮬레이션 타입​

태그 타입선택 가능한 시뮬레이션 타입
Analog제어가능, 랜덤, 사인파형, 톱니파형, 삼각파형, XG5000
Digital제어가능, 랜덤, Change, XG5000
String제어가능, 랜덤
note

메모리 태그는 위의 규칙을 따르되 XG5000이 제외됩니다.

개별 설정​

  1. 테이블의 태그명 옆에 나타나는 열기 버튼을 클릭하여 시뮬레이션 개별 설정 패널을 엽니다.
  2. 우측 패널에 설정 정보를 입력합니다.
  3. 확인 버튼을 클릭합니다.

일괄 설정​

  1. 테이블에서 태그를 다중 선택합니다.
  2. 테이블 우측 상단의 설정 버튼을 클릭합니다.
  3. 우측 패널에 설정 정보를 입력하고 확인 버튼을 클릭합니다.

시뮬레이션 설정 제거​

시뮬레이션 설정을 제거할 태그를 선택한 뒤, 테이블 우측 상단의 제거 버튼을 클릭하고 모달에서 확인합니다.

시뮬레이션 적용 / 해제​

info

적용/해제 버튼은 프로젝트가 RUNNING 상태일 때만 표시됩니다.

  1. 테이블 상단의 런타임 적용 버튼을 클릭합니다.
  2. 모달에서 원하는 시뮬레이션 명을 선택하고 확인합니다.
  3. 현재 적용되고 있는 시뮬레이션은 적용 컬럼에 TRUE로 표시됩니다.
  4. 시뮬레이션을 중지하려면 테이블 상단의 적용해제 버튼을 클릭합니다.

Communication and Tag Monitoring

Two pages for monitoring the state of a running project. Both are reached from the left main navigation.

Communication​

Monitor the status of devices associated with a running project, or enable and disable them.

Communication status​

StatusDescription
InactiveThe project is not running and communication has not been attempted
ActiveThe project is running and the device is connected
ErrorThe project is running but there is trouble connecting to the device

Device activation​

Click ON / OFF in the Activation column of the table to turn devices on and off.

note

The ON/OFF button is only available while the project is running.

Status lists​

  • Status List — See the status of all devices connected to the project
  • Status List by Channel — Click a channel name in the sub navigation or the table to filter devices on that channel

Property descriptions​

PropertyDescription
Channel NameThe channel name
Device NameThe device name. The text colour indicates the status
Device DescThe description of the device
IP/Station No.IP communication shows the IP; serial communication shows the station number
Read Total / Read SuccessesNumber of read attempts and successes (shown while the project runs)
Write Total / Write SuccessNumber of write attempts and successes (shown while the project runs)
Retry ConnectNumber of reconnection attempts (shown while the project runs)
ActivationWhether the communication connection is currently enabled

:::tip Diagnosing communication When checking communication status, look at Retry Connect, Read Total and Read Successes.

  • Retry Connect keeps increasing → re-check the device settings
  • Read Total and Read Successes differ → re-check the tag settings :::

Tag Monitoring​

Monitor tag values and status in a running project, or control tag values.

Tag list​

Like the Tags page, tags can be filtered through the sub navigation on the left or the table header. Unlike the Tags page the table has no toolbar, but it has additional columns for monitoring.

Monitoring columns​

Tag Value — The current tag value. Tags with a simulation applied show an SI icon before the status.

Tag Status

StatusDescription
-Not running
SCAN START : [details]Initial communication attempt
SCAN STOPInitial communication could not be established
GOODGood
UNKNOWNUnknown
IO BAD : [details]Communication is currently not possible after the initial connection
ENG BAD : [details]Equipment or raw value data exceeded the data range
ALARM : [details]Alarm message
ALARM DELAYAlarm delay

Date Time — The time the tag value was updated.

Tag info​

Hovering a tag item in the table reveals an Open button to the right of the tag name column. Clicking it shows the tag information in the right panel.

PropertyDescription
Tag NameThe name of the tag or group
DescriptionThe description of the tag or group
TypeAnalog / Digital / String (groups are not shown)
Real Time ValueOnly visible while the project runs. Shows simulated values or actual collected data
StatusOnly visible while the project runs. Shows the status of the data
CHANGE TAG VALUEEnabled only when the project is running, the account has Admin or Engineering permissions, and Write Tag is checked in the tag settings
Tag Data TypeThe value type of the tag
Tag Data Min / MaxThe minimum and maximum tag values
Raw Data Min / MaxThe minimum and maximum settings of the equipment being collected
DeadbandShown only when the tag type is Analog; the decimal deadband value from the analog details

Controlling tag values​

In the tag information panel, click the CHANGE TAG VALUE text button at the bottom right of the tag information card to change the value.

:::warning Conditions for control All three conditions must be met before a tag value can be controlled.

  1. The project must be running.
  2. The account permissions must be Admin or Engineer.
  3. Write Tag must be checked in the tag's Action properties. :::

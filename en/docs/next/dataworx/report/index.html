Report

EdgeHub reports query the logging data defined in historian models and generate or print Excel files at a scheduled time.

  • Reports in the product's own format can be generated and printed even where Excel is not installed.
  • Alarm logging data can be queried and printed as a report in the product's own format.
  • Current tag values and tag properties can be queried and produced as Excel or native-format reports.
  • Reports can be printed at the desired time on a variety of cycles: hourly, daily, weekly, monthly, yearly, free and periodic.

Report Features​

  • The report duplication feature makes it convenient to create similar types of reports.
  • Reports are organized into Excel Reports, which use an Excel file as a form, and General Reports, which use their own form.
  • Excel reports keep Excel's graphs, charts, formatting and statistics.
  • The General Report form editor makes table-based report forms easy to build, including tag/alarm/event logging report forms.
  • Results can be produced in PDF, DOC, XLS and TEXT formats.

Report Start​

EdgeHub reports are built in C# on .NET Framework 3.5 and run as an executable. Microsoft Excel 2007 or later must be installed to create Excel reports.

Report editor executable: [installation path]/DataWorX/bin/Report/EhReportEditor.exe

Report editor layout​

AreaDescription
MenuAutomatically update output information — reflects editor changes while online / History information — shows the data storage status of historical data collection models
Project formShows report groups and reports as a tree. Right-click the top-level node for the management pop-up menu
Report layout editorSplit into the Excel report and general report layout editors
Report editing logLogs the actions taken in the editor

Report editing menus​

  • Project menu (right-click the top-level node) — Add Group / Add Report / Properties
  • Group menu (right-click a group icon) — Add Group / Delete Group (not possible if it contains groups or reports) / Add Report / Properties
  • Report menu (right-click a report icon) — Copy Report / Move Report / Delete Report / Report Properties / Report Layout

Report details​

TypeDescription
Hourly, Daily, Weekly, Monthly, YearlyDefault reports with a fixed number of data points. The generation interval is fixed and the user sets the data collection interval
Free ReportThe user sets both the report generation interval and the data collection interval
Periodic ReportThere is no generation interval, only a data collection interval. A trigger such as a script supplies the lookup period and generates the report

Report generation cycle examples

  • Report period = 1 day, collection period = 1 hour → a daily report is generated once 24 one-hour data points are collected
  • Report period = 1 day, collection period = 15 minutes → a daily report is generated once 96 fifteen-minute data points are collected

Layout Definition​

The layout editor has two forms depending on the report type.

  • Tag logging report layout — Set the table properties in the editor.
  • Excel report layout — Build the final output on top of an Excel form.

Report Runtime​

Select [Show report runtime] from the report runtime tray icon pop-up menu to display the runtime screen, showing all defined report information and a log of report generation.

Registered report list​

Shows the reports registered through the report editor, distinguishing general reports from Excel reports by type.

ColourMeaning
BlueReport detail type is Periodic Report. Excluded from automatic generation; created only manually or via script
RedProperties are set but the report has no layout. Excluded from automatic generation

Layout edit / file view / manual generation​

Right-click a report in the list to use the pop-up menu.

Layout edit — Opens the selected report in the report editor and shows the layout edit screen.

File view — Query, open, print and delete generated reports.

  • Open report — General reports (.RPT) open in the built-in viewer; Excel reports open Excel. PDF/DOC/TXT formats launch the associated application, so check that it is installed first.
  • General report viewer — In addition to printing, the [Export] menu generates reports in PDF/XLS/DOC/TXT/TIFF format.
  • Print report — Only .RPT general reports and Excel reports can be printed directly.
  • Delete report — Deletions are also written to the log.

Manual generation — Generate a report for a period of your choosing.

  • Report data collection status — Lists data model, collection interval, first stored time and last stored time (not shown for alarm reports)
  • Select request time — Periodic reports set a base time; period reports set a start and end time
  • Confirm — Generates the report for the requested period. The report name includes date/time information plus the word manual

Automatic report generation​

  • On startup the report runtime reads the report list, checks generation times, and when a generation time arrives it queries the historical data using the report configuration and layout, then writes, saves and prints the report.
  • Selecting [Automatically update output information] in the report editor reflects changes while online.
  • The automatic generation process is recorded in the log at the bottom of the report runtime.
  • Reports are also generated in the PDF/XLS/DOC/TXT formats specified in the report properties.

Report Constraints​

warning
  • The maximum number of tags that can be added to one sheet in an Excel report is 100.
  • In the Excel report form file, the privacy option "Remove personal information from file properties on save" must be unchecked for the report to work correctly.
  • For yearly reports:
    • To show 12 monthly data points → a historian model with a 1-month collection period (Statistics, Accumulation)
    • To show 365 daily data points → a logging group with a 1-day collection period (Period)

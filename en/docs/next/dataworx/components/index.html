UI Components

Every DataWorX page is built from the same set of common components. Once you know how these work, you can operate every page the same way.

Application Bar​

The top-level component for global settings, the current time and project-related settings.

ItemDescription
BI imageClick to go to the project list page
Project barShows project setting items when a project is open
Current timeDisplays the current time
User menuShows the logged-in user ID. Profile / Logout
Online usersShows the ID, IP address and login time of currently logged-in users
Settings menuLicense management / Member management / System settings
Help menuI/O driver list / System info / System log / Manual / About

System Settings modal​

SettingDescription
NotificationTurning on the app-bar realtime alarm toggle adds a notification icon to the right of the application bar, showing alarms raised in real time while the project runs
Language & ThemeSets the application language (Korean/English) and theme (light/dark)
LayoutChanges the style of the main navigation
TableSets row spacing and font size for tables. The reset button at the bottom clears all table settings stored on the PC
User securityWhen enabled, the account is locked for a configured period after a configured number of failed login attempts
Client redundancyWhen client screen auto-switching is enabled, the client screen switches automatically to the Standby server if the Master server fails

Display settings refresh the page when Apply is clicked so the changes take effect.

Project Bar​

Shown in the application bar when a project is open. It lets you change the project state.

  • Project name — Click for the Project list / Close project menu
  • Project status — OPENED is the default state; it changes to RUNNING when the project runs
  • Status change button — A run button is shown when the project is open, and a stop button while it is running
  • Close project button — Closes the project and returns to the project list page

Styles​

Change the style under Settings → System settings → Layout in the application bar.

  • Icon — The default style. Hovering shows the item name as a tooltip
  • Icon + Text — The item name is shown under the icon (width stays fixed)
  • Icon + Expansion panel — Hovering expands the navigation and shows item names

Sub Navigation​

Navigate to an entity's page, or create/edit/delete entities.

  • Search — Filters entities in the sub navigation by keyword. Matches are highlighted in blue and the search is case-insensitive.
  • Add button — Creates a root-level entity. Clicking it opens the right panel.
  • Tree view — Expand the tree to see child items. The toggle state is remembered.
  • Entity menu — Add a child item, or view/edit/delete the entity.

Right Panel​

Add an entity, or view and edit its information.

  • Top — Panel title on the left, close button on the right. ESC also closes the panel
  • Body — Input fields or entity information. Cards can be collapsed or expanded with the button at the top left of the card
  • Bottom — Shown when the body contains input fields. Cancel (discard and close) / Confirm (submit)

Breadcrumbs​

Shows the hierarchy from the parent page down to the current page. Clicking a parent name navigates to that page; clicking the home icon returns to the project list.

Table​

Displays entity properties as rows and columns, and lets you add, edit and delete entities. The items in the more menu differ by page.

Rows​

FeatureDescription
Child item listNavigate to the child list page when the item has children
Open right panelHovering a row reveals a button that opens the property panel
Right panel lockLock — displays information / Edit — properties can be modified
Row menuEdit, delete or duplicate the item, or add a child item
SortAscending (ASC) / descending (DESC). Hold Ctrl and click another column's sort icon for multi-column sorting
FilterFilter data by a column condition
Search fieldFilter table data by keyword
Row heightCompact / Standard / Comfortable
Total row countShown at the bottom right of the table

Columns​

  • Show/hide columns, resizing (drag the bar between columns), reordering (drag the column name)
  • Column menu — Sort / Pin (left or right) / Filter / Column
  • Column header filter — Quick access to per-column filters. Hidden initially; enable it from the toolbar menu.
note

On pages where data updates periodically (Simulator, Communication, Tag Monitoring) the column header filter settings cannot be changed.

Selecting items​

KeysDescription
Ctrl + ASelect all items (select an item with the mouse first)
Click first row → Shift + EndSelect all items
Shift + ↑/↓Multi-select while moving with the arrow keys from the selected item
Shift + ClickMulti-select from the selected item to the clicked item
Ctrl + ClickMulti-select only the clicked items

Hold Ctrl and click a selected item to deselect it.

Spreadsheet​

Use the spreadsheet to add or edit data. Available only on the Device, Block and Tag pages.

  • Entering data on the row after the existing data adds a new entity.
  • The first column contains the unique ID and cannot be edited.
  • Clicking Confirm after entering data runs validation; invalid data is reported on the left of the panel.
  • Data in the sheet can be filtered and sorted.

Tag-specific menu​

Tag option settings, Import, Export, Import LS PLC, Validate Tags. See Tag — Additional features.

Other features​

  • Download — Download table data as .csv
  • Print — Print table data
  • Reset table settings — Clears stored sort and filter settings

Alert Bar​

When the engineering page changes while the project is running, an alert bar appears at the top right of the page. Clicking Apply applies the changes to the project runtime; the X button dismisses the alert (it reappears after one minute).

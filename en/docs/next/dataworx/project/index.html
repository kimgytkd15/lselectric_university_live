Project

DataWorX can create and manage multiple projects.

Project List​

View the projects created in DataWorX. The list includes a Demo project.

  • Open project — Click a project card
  • Project status — Projects that are OPENED / RUNNING show the status next to the project name
  • Rename project — Hover over the project name and click the pencil icon
  • Refresh project list — Click the refresh icon. The time next to the button is the last refresh time
caution

Project names cannot start with a space or a number and are limited to 25 bytes. Only letters, numbers, Korean characters and the special characters - and _ are allowed. Projects that are OPENED or RUNNING cannot be renamed.

Project Path​

The project path is used to load the project list and to determine where projects are saved. Navigate here with the Path settings button on the project list page.

  • The default project path is C:/EdgeHub/DataWorX/Project.
  • Add path — + button at the top right of the list card. The modal works like a file explorer, and breadcrumbs move back to a previous location.
  • Delete path — Table row more menu, or multi-select and use the delete button at the top left of the table.

Password settings​

  1. Turn on the Use password toggle on the password settings card.
  2. Click the Set password text button at the bottom of the card.
  3. Set the password you want in the modal.
  4. When set, the check mark on the text button turns blue.

System redundancy settings​

  1. Turn on the Use system redundancy toggle on the system redundancy card.
  2. Select the redundancy role of this PC (Master / Standby).
  3. Set the Master IP and Standby IP.
  4. Run the project on both the Master PC and the Standby PC to activate system redundancy.

Behaviour:

  • When the Master PC shuts down, the Standby PC starts up.
  • When the Master PC recovers, the Standby PC returns to standby.

:::warning IP rules

  1. For the Master role, the primary IP address must equal the Master IP.
  2. For the Standby role, the primary IP address must equal the Standby IP.
  3. The Master IP and Standby IP must differ from each other. :::

Line redundancy settings​

  1. Turn on Use line redundancy on the details card and set the secondary IP.
  2. Turn on Use system redundancy on the system redundancy card.
  3. Set the Master secondary IP and the Standby secondary IP.

Switching rules:

  • When the web client connects on the primary IP — switches to the Master IP or Standby IP according to the system redundancy role
  • When the web client connects on the secondary IP — switches to the Master secondary IP or Standby secondary IP

Line redundancy is currently used for client redundancy switching over the additional secondary IP when system redundancy is configured.

Client redundancy​

Client redundancy switches the screen automatically when system redundancy is configured.

  • When both the Master PC and Standby PC are active: logging in on the Standby PC IP switches to the Master IP screen.
  • If the Master PC shuts down while its screen is open, the screen switches automatically to the Standby PC.
  • When the Master PC recovers, the Standby PC screen switches back to the Master PC screen automatically.
note

Connecting with localhost or 127.0.0.1 is treated as engineering and does not switch screens.

If you do not want client switching when connecting on the Master IP or Standby IP, turn the redundancy switching toggle off and log in. You can turn it back on in the system settings.

Project Info / Edit​

  • Project info — View the settings of the currently open project. Navigate from the left main navigation.
  • Edit project — Navigate with the Edit button at the top right of the project information card.
caution

The creator, package name and path cannot be changed, and the project name is edited on the project list page.

Project Log​

View the activity log in DataWorX. On entering the page the date range is set to today; period selection and retention settings work the same way as the system log.

Delete Project​

danger

Projects created in DataWorX cannot be deleted from the UI. Use File Explorer to navigate to where the project is stored and delete the whole folder. Be careful not to delete a project that is currently open or running.

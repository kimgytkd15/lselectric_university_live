Project Settings

Configure what the VisualWorX project service needs. Run Tools → Project settings from the main menu.

General​

Displays general information about the currently open VisualWorX project, as entered when the project was created in VisualWorX Server.

note

Nothing can be modified except the project type, whose data source can change from DataWorX to InfoU while running.

External DB​

Sets the connection information for fetching data from an external database. The configured connections can be used by VX Chart, VX Grid and VX Text.

PropertyDescription
NewAdds a new external DB connection
DeleteSelect an item in the connection list on the left and click Delete (double-click switches to edit mode)
SaveSaves the added or edited connection information
CancelCancels the addition or edit
CreateProvides a UI for composing the connection string for the database type
TestChecks whether the composed connection string can connect

Supported types: MSSQL, MySQL, SQLite. Select a type, click Create, fill in the details and confirm — the connection string is composed automatically.

caution

When composing in the editor, the SQLite DB file path must be the server-side path.

Report Group​

Creates and manages report groups.

  • Report group list — Right-click in the list to show the pop-up menu and use Add, Edit and Delete to manage groups.
  • Report alias list — Creates and manages report paths. A report path belongs to the currently selected report group, and one report group can have multiple report paths.

Users​

Adds users and assigns roles.

PropertyDescription
AddDisplays the user settings window to add a user
EditEdits the settings of the user selected in the list
DeleteDeletes the user selected in the list

User settings​

PropertyDescription
User ID*3 to 15 alphanumeric characters
User name*Up to 20 English or 10 Korean characters
Password*6 to 15 characters mixing letters and numbers
Confirm password*Re-enter the same password
User level*Grants a level so only matching tag and alarm information is visible. 0 = no permission, 1–10 = the lower the number, the higher the permission
Department / Phone / E-mail / Address / DescriptionAdditional user information
Screen auto-adjustWhether 'screen auto-adjust' is checked at Runtime login
Fit to screen ratioWhether 'fit to screen ratio' is checked at Runtime login
Show alarm popupWhether 'show alarm popup' is checked at Runtime login
Hide mouseHides the mouse after the configured idle time while Runtime is running. Moving the mouse shows it again
Password expirySets the validity period of the password
Session expirySets the validity period of the session
Add / DeleteAdds a role to the user / deletes the selected role

* indicates a required field.

Roles List​

Sets permissions for engineering, monitoring pages, tags, alarm groups, report groups and logging groups. Configured roles can be assigned to users.

PropertyDescription
Role name3 to 15 alphanumeric characters
Role descriptionA description of the role
Engineering permissionSets permission to edit in the Editor and change project settings

Runtime permissions​

PermissionDescription
All tagsGrants read permission for all tags (Control: grants write permission)
All alarm groupsGrants all alarm groups. Applies when showing the alarm group list; not directly related to alarm occurrence
All report groupsGrants all report groups. Applies when browsing report folders registered on the VisualWorX server
All logging groupsGrants all logging groups. Applies when selecting logging tags
All pagesGrants all monitoring pages
Start screenThe monitoring screen shown first when logging in from a web client
Page layout settingsSets the menu page and its position (top / bottom / left / right)

Settings tabs​

TabDescription
Page settingsAssigns monitoring pages to the user. Only assigned pages can be displayed in the web client
Tag/tag group settingsUsed when querying or setting tag values. Also applies when querying alarms for a tag, so the tag or a tag group containing it must be assigned to query its alarms
Alarm group settingsAssigns alarm groups. Applies when showing the alarm group list
Report group settingsAssigns report groups. Applies when browsing report folders registered on the VisualWorX server
Logging group settingsAssigns logging groups. Applies when selecting logging tags

:::tip Selecting tags The tag selection window lists tags by group tag and device tag, and group tags are also shown under device tags. Hold Shift to select multiple tags or tag groups, then click Confirm selection in the toolbar to add them to the list.

In the logging group selection window, double-click a logging group name in the tree on the left to add it to the list. :::

Page Layout Settings​

PropertyDescription
TopThe page placed at the top of the screen
BottomThe page placed at the bottom of the screen
LeftThe page placed on the left of the screen
RightThe page placed on the right of the screen
note

For how to change the screen layout through the API, see Event Script — Basic Script.

Version: DX:4.1.0, VX:5.0.0

프로젝트 설정

VisualWorX 프로젝트 서비스에 필요한 사항들을 설정합니다. 메인 메뉴의 도구 → 프로젝트 설정 메뉴를 실행합니다.

일반​

현재 오픈된 VisualWorX 프로젝트의 일반 정보를 표시합니다. VisualWorX Server에서 프로젝트를 생성했던 내용이 표시됩니다.

note

구동 중 데이터 소스가 DataWorX에서 InfoU로 바뀔 수 있는 프로젝트 타입을 제외하고는 수정할 수 없습니다.

외부DB​

외부 Database로부터 데이터를 가져오기 위한 연결 정보를 설정합니다. 설정된 연결정보는 VX 차트, VX 그리드, VX 텍스트에서 사용할 수 있습니다.

속성내용
신규새로운 외부 DB 연결을 추가
삭제왼쪽 연결 목록에서 항목을 선택하고 삭제 버튼 클릭 시 삭제 (더블 클릭 시 수정모드로 변경)
저장추가 또는 수정한 연결 정보를 저장
취소추가 또는 수정을 취소
만들기연결 문자열을 Database 타입에 맞게 작성할 수 있는 UI 제공
테스트작성된 연결 문자열의 접속 여부를 확인

지원 유형: MSSQL, MySQL, SQLite. 유형을 선택하고 만들기 버튼을 누른 후 작성·확인하면 연결 문자열이 자동으로 만들어집니다.

caution

편집기에서 작성 시, SQLite의 DB 파일은 서버측 경로를 입력합니다.

보고서 그룹​

보고서 그룹을 생성하고 관리합니다.

  • 보고서 그룹 목록 — 리스트에서 우클릭하여 팝업 메뉴를 표시한 후 추가, 수정, 삭제 기능으로 관리합니다.
  • 보고서 별칭 목록 — 보고서 경로를 생성하고 관리합니다. 보고서 경로는 현재 선택된 보고서 그룹에 속하며, 하나의 보고서 그룹에 다수의 보고서 경로를 생성할 수 있습니다.

사용자​

사용자를 추가하거나 역할을 설정합니다.

속성내용
추가사용자 설정 창을 표시
수정리스트에 선택된 사용자의 설정을 수정
삭제리스트에 선택된 사용자를 삭제

사용자 설정 항목​

속성내용
사용자ID*3자 이상 15자 이하의 영숫자
사용자명*영문 20자, 한글 10자 이하
비밀번호*6자 이상 15자 이하의 영문과 숫자의 혼합
비밀번호 확인*비밀번호를 동일하게 확인 입력
사용자 레벨*레벨에 맞는 태그 및 알람 정보만 확인 가능. 0 = 권한 없음, 1~10 = 숫자가 낮을수록 높은 권한
부서 / 전화번호 / 이메일 / 주소 / 설명사용자 부가 정보
화면 자동조절Runtime 로그인 시 '화면 자동조절' 체크 여부
화면비율에 맞춤Runtime 로그인 시 '화면비율에 맞춤' 체크 여부
알람팝업 표시Runtime 로그인 시 '알람팝업 표시' 체크 여부
마우스 숨김Runtime 실행 시 설정 시간 경과 후 마우스를 숨김. 마우스를 움직이면 다시 표시
비밀번호만료설정비밀번호의 유효기간
세션만료설정세션의 유효기간
추가 / 삭제사용자에 역할을 추가 / 선택한 역할을 삭제

*는 필수 항목입니다.

역할목록​

엔지니어링 권한, 감시화면 페이지, 태그, 알람그룹, 보고서그룹, 로깅그룹 등의 권한을 설정합니다. 설정된 역할은 사용자에 할당할 수 있습니다.

속성내용
역할 이름3자 이상 15자 이하의 영숫자
역할 설명역할에 대한 설명
엔지니어링 권한에디터 편집 및 프로젝트 설정 권한

런타임 권한​

권한내용
전체 태그전체 태그 읽기 권한 할당 (제어: 쓰기 권한 할당)
전체 알람 그룹전체 알람 그룹 할당. 알람그룹 리스트 표시 시 적용되며 알람 발생과는 직접 관련 없음
전체 보고서 그룹전체 보고서 그룹 할당. VisualWorX 서버에 등록된 보고서 폴더 조회 시 적용
전체 로깅 그룹전체 로깅 그룹 할당. 로깅 태그 선택 시 적용
전체 페이지전체 감시화면 페이지 할당
시작화면웹클라이언트에서 로그인했을 때 최초로 표시할 감시화면 선택
페이지 레이아웃 설정메뉴 페이지와 위치 설정 (상단/하단/좌측/우측)

설정 탭​

탭내용
페이지 설정사용자에게 감시화면 페이지를 할당. 할당된 감시화면만 웹클라이언트에서 표시
태그/태그그룹 설정태그값을 조회하거나 설정할 때 사용. 태그에 대한 알람을 조회할 때도 적용되므로, 특정 태그의 알람을 조회하려면 해당 태그 또는 태그를 포함하는 태그그룹을 할당해야 함
알람그룹 설정알람그룹을 할당. 알람그룹 리스트 표시 시 적용
보고서그룹 설정보고서그룹을 할당. 서버에 등록된 보고서 폴더 조회 시 적용
로깅그룹 설정로깅그룹을 할당. 로깅 태그 선택 시 적용

:::tip 태그 선택 태그 선택 창에서는 그룹 태그 / 기기 태그별 목록을 표시하며, 기기 태그에서 그룹 태그도 표시됩니다. Shift 키를 사용하면 다수의 태그/태그그룹을 선택할 수 있고, 툴바의 선택확인 버튼으로 선택 항목을 리스트에 추가합니다.

로깅 그룹 선택 창에서는 좌측 트리의 로깅 그룹 이름을 더블클릭하면 리스트에 추가됩니다. :::

페이지 레이아웃 설정​

속성내용
Top화면의 상단에 위치시킬 페이지
Bottom화면의 하단에 위치시킬 페이지
Left화면의 좌측에 위치시킬 페이지
Right화면의 우측에 위치시킬 페이지
note

API를 사용하여 화면의 레이아웃을 변경하는 방법은 이벤트 스크립트 — 기본 스크립트를 참고하세요.

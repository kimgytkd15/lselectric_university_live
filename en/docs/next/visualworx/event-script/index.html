Event Script

You can write scripts that run when an event occurs on an object or a page. Scripts must be written in JavaScript.

:::tip Auto-completion Use Ctrl + Space to complete a word. For example, typing Open and pressing Ctrl + Space lists the words starting with Open. If only one match exists, the word is completed directly.

Objects on the monitoring screen are accessed by object name. :::

Canvas Script​

Page-level (canvas) events.

EventDescription
OnInitializeRaised when the page is displayed
OnDisposeRaised when the page is closed
OnUpdateRaised when the page is refreshed

Basic Script​

Events common to objects.

EventDescription
OnClickMouse click event
OnDblClickMouse double-click event
OnInitializeObject initialization event
OnLButtonDown / OnLButtonUpLeft mouse button down / up event
OnMouseMoveMouse move event
OnRButtonDown / OnRButtonUpRight mouse button down / up event
OnUpdateObject update event

Page control functions​

OpenPage(PageName, TagParam, Callback?)

Opens a pop-up window displaying a page.

ArgumentDescription
PageNameThe name of the page to open
TagParamThe names substituting tags on a template screen. Pass an empty string ("") when no tag is substituted
CallbackReceives the result from the pop-up page (optional)
OpenPage("Page1", "$TagGroup=Monitoring");

OpenPage("Page1", "$TagGroup=Monitoring", (object) => {
  console.log(object);
});

OpenPageEx(x, y, width, height, pageName, TagParam, Callback?)

OpenPage with the window position and size added.

ArgumentDescription
x, yThe window position coordinates
width, heightThe window width and height
PageName, TagParam, CallbackSame as OpenPage
OpenPageEx(100, 100, 800, 600, "Page1", "$Tag=SOLAR");

OpenPageEx(100, 100, 800, 600, "Page1", "$Tag=SOLAR", (object) => {
  console.log(object);
});
tip

For how to change the screen layout through the API, see Event Script — Basic Script in the online manual.

VX object scripts​

The VX Chart, Grid and Text controls have both common and dedicated scripts.

Script groupDescription
VX object common scriptFunctions shared by VX Chart, Grid and Text
VX Chart dedicated scriptChart functions, including box plot chart and normal distribution chart specific functions
VX Grid dedicated scriptGrid data functions such as setJsonData
VX Text dedicated scriptText data functions such as setText and setJsonData
note

The Script type settings of the VX controls embed the Axios library, so REST data can be fetched and placed into the control. For usage see Control settings.

Relationship with the Global Script​

Functions and variables shared across the project are declared in the Editor's global script and called from event scripts using the Global. prefix.

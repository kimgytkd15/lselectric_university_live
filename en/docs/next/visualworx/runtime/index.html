Runtime

VisualWorX Runtime consists of HTML5 web pages and JavaScript. It receives project information served by VisualWorX Server and performs monitoring.

:::caution Prerequisites For VisualWorX Runtime to run correctly, EdgeHub DataWorX and VisualWorX Server must be running.

It runs in any browser supporting the HTML5 standard (Chrome, Firefox and others); the latest version of Chrome is recommended. :::

Login​

  1. Enter the VisualWorX Server address in the browser address bar to display the login screen.
  2. Enter the user ID and password registered in the VisualWorX project into USER_ID and PASSWORD, then click LOGIN.

Auto login​

Checking auto login before logging in means that re-entering the Runtime path logs you in automatically and shows the screen you last viewed.

  • Auto login survives the browser being closed and reopened and the server being rebooted.
  • However, it is released 365 days after the login where auto login was enabled. After that, closing and reopening the browser or rebooting the server requires logging in again.
  • Selecting Logout at the top right of the web client toolbar releases auto login and redirects to the login window.

Reconnecting​

If the network drops or the server shuts down while Runtime is running, a reconnect pop-up appears.

  • Network failure — After the reconnect pop-up, the existing page is restored when the network recovers
  • Server shutdown — After the reconnect pop-up, the login page is shown when the server comes back up

Click Dynamic Properties​

For objects with a click dynamic property, the user performs the action with the mouse. Such objects display a border in response to the mouse cursor and run dynamic properties such as page navigation and value input.

For configuration see Dynamic Properties — Click actions.

Tag Viewer​

Click the Tag viewer button in the toolbar to display the tag viewer.

Double-click a tag to display the tag detail screen, where entering a new value and clicking Apply changes that tag's value.

note

The tags and groups shown in the tag viewer follow the tag/group settings assigned to each user. Users with administrator permissions see all tags.

Report Viewer​

Click the Reports button in the toolbar to display the report viewer.

The folders belonging to the report groups configured for the logged-in user are shown. Double-click a folder to see the report files inside.

File formatSupported features
PDFView PDF + download
ExcelDownload only

Double-clicking a file displays the report pop-up menu, and View PDF shows the report in the built-in PDF viewer.

Remote Editing​

Edit a project served by VisualWorX Server remotely. The browser runs the VisualWorX Editor features so monitoring pages and user information can be edited.

:::warning Feature limitations The remote editor cannot use the graphic library, smart symbols or project management features. :::

Remote editor login​

Logging in to the remote editor requires administrator permissions.

  1. Enter the remote editor address in the browser address bar.
    • Address format: http://IPAddress:Port/editor
    • Example: http://192.168.0.11:80/editor
  2. Enter the user ID and password registered in the VisualWorX project, then click Login.
  3. The WebSocket port field shows 2160 by default. If the VisualWorX Server WebSocket port has been changed, enter the same value as the server setting before logging in.

Once logged in, the project appears in the remote editor and can be used the same way as the local VisualWorX Editor, apart from the limited features.

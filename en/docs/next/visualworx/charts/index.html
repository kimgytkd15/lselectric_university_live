VX 차트 컨트롤 설정

VX 차트 컨트롤 설정은 차트 디자인과 외부 데이터(Database, JSON)를 설정하는 기능을 합니다.

공통 설정 구조​

대부분의 차트는 다음 설정 탭을 공통으로 가집니다. 차트 종류에 따라 일부 탭이 없을 수 있습니다.

설정 탭설명
일반 설정레이아웃(제목·부제목·메뉴·색상), 범례, 차트 영역
3D 설정3D 표현 옵션
Plot 라인 설정기준선 추가·삭제 및 스타일
시리즈 설정데이터 계열별 표현 방식
X축 설정 / Y축 설정축 표시, 범위, 눈금
데이터 설정Database / Script 데이터 소스 연결
샘플 실행 화면설정 결과 미리보기

일반 설정 항목​

라인 차트의 일반 설정이 대부분의 차트에 공통 적용되며, 다른 차트 문서에서는 "Line Chart 일반 설정과 동일"로 생략됩니다.

설정명설명
적용설정 사항을 차트에 적용하고 차트 컨트롤을 재시작
불러오기저장된 설정을 가져와서 적용. 웹클라이언트는 브라우저 내부 DB, 로컬은 JSON 파일
내보내기설정을 저장. 웹클라이언트는 브라우저 내부 DB에 이름을 명시, 로컬은 JSON 파일
레이아웃 (제목 / 부제목)차트의 제목·부제목
레이아웃 (메뉴 표시)체크 시 차트 오른쪽 상단에 메뉴버튼 표시
레이아웃 (설정 버튼 보이기)체크 시 메뉴버튼 하위에 "차트 설정" 버튼 표시
레이아웃 (배경 색 / 선 색)메뉴버튼의 배경색 / 선색
범례 (표시방법)수직 / 수평
범례 (수직정렬)상단 / 중단 / 하단
범례 (수평정렬)좌측 / 중간 / 우측
범례 (활성 시 / 호버 시 / 비활성 시)상태별 텍스트 색상
차트 영역 (배경색)차트 배경 색상
차트 영역 (X·Y축 선 색 / 굵기 / 모양)차트 내부 그리드 설정

차트 종류​

라인 차트​

기본이 되는 차트로, 일반 설정·Plot 라인 설정·3D 설정·시리즈 설정·X축/Y축 설정·데이터 설정을 모두 제공합니다.

바 차트​

세로 바 차트와 가로 바 차트가 있으며, 두 설정이 동일합니다.

분산 차트 / 영역 차트 / 방사 차트 / 버블 차트​

일반 설정은 라인 차트와 동일하며, Plot 라인·시리즈·축·데이터 설정을 제공합니다.

파이 차트 & 도넛 차트​

두 차트의 설정이 동일합니다. 일반 설정 · 3D 설정 · 전용 설정 · 데이터 설정으로 구성되며, X축/Y축 설정은 없습니다.

게이지 차트​

일반 설정 · 시리즈 설정 · Y축 설정 · 데이터 설정으로 구성됩니다. X축 설정과 Plot 라인 설정은 없습니다.

솔리드 게이지 차트​

게이지 차트와 동일한 구조이며, 일반 설정의 차트 영역에 배경색 항목만 제공됩니다.

박스 플롯 차트​

일반 설정은 라인 차트와 동일합니다.

note

박스 플롯 차트는 Observations와 Outliers 2가지 채널만 존재하며, 추가하거나 삭제할 수 없습니다.

표준정규분포 차트​

일반 설정은 라인 차트와 동일하며, Plot 라인·시리즈·축·데이터 설정을 제공합니다.

차트 외부 데이터 구조​

차트에 연결할 외부 데이터의 형태는 축 구성에 따라 달라집니다.

X축, Y축 데이터​

X축과 Y축이 있는 경우로, 라인 · 가로 바 · 세로 바 · 분산 · 영역 · 레이더 · 버블 차트에 사용합니다.

DataBase 타입 — 쿼리문을 다음과 같은 테이블 구조로 작성합니다. 컬럼명은 달라도 무방합니다.

필드설명
REC_TIMEX축이 될 필드. X축 타입이 Datetime일 경우 UNIX_TIMESTAMP로 변환해야 함
series1, series2, series3 …X축이 아닌 나머지 필드는 시리즈로 인식되며, 차트 설정의 시리즈 설정에서 필드명과 같은 시리즈명으로 설정해야 차트에 표현됨

기타 데이터 구조​

구조사용 차트
Y축, 카테고리 데이터카테고리 축을 사용하는 차트
Y축 데이터Y축만 사용하는 차트
Y축과 데이터가 하나인 경우게이지, 솔리드 게이지 등 단일 값 차트

각 구조의 상세 필드 정의는 온라인 매뉴얼의 차트 외부 데이터 구조를 참고하세요.

tip

차트를 스크립트로 제어하거나 REST 데이터를 연결하려면 VX 객체 공통 스크립트 / VX 차트 전용 스크립트를 참고하세요. 박스플롯 차트와 표준정규분포 차트는 별도의 전용 스크립트를 제공합니다.

:::note 차트 개수 제한 VX 차트 컨트롤의 개수와 채널 개수는 VisualWorX 서버 설정(dbChartCount, dbchart.channelCount)에서 설정할 수 있습니다. :::

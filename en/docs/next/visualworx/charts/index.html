VX Chart Control settings

VX Chart control settings configure the chart design and the external data (Database, JSON).

Shared Settings Structure​

Most charts share the following settings tabs. Some tabs are absent depending on the chart type.

Settings tabDescription
General settingsLayout (title, subtitle, menu, colours), legend and chart area
3D settings3D rendering options
Plot line settingsAdding, deleting and styling reference lines
Series settingsHow each data series is rendered
X axis settings / Y axis settingsAxis display, range and ticks
Data settingsConnecting a Database or Script data source
Sample screenA preview of the configured result

General settings​

The line chart's general settings apply to most charts, and other chart documents omit them as "same as the Line Chart general settings".

SettingDescription
ApplyApplies the settings to the chart and restarts the chart control
LoadLoads and applies saved settings. Web clients read from the browser's internal DB; local reads a JSON file
ExportSaves the settings. Web clients save to the browser's internal DB under a name; local saves a JSON file
Layout (title / subtitle)The chart title and subtitle
Layout (show menu)When checked, shows the menu button at the top right of the chart
Layout (show settings button)When checked, shows a "Chart settings" button under the menu button
Layout (background colour / line colour)The background and line colour of the menu button
Legend (display method)Vertical / horizontal
Legend (vertical alignment)Top / middle / bottom
Legend (horizontal alignment)Left / centre / right
Legend (active / hover / inactive)Text colour in each state
Chart area (background colour)The chart background colour
Chart area (X/Y axis line colour, width, style)The chart's internal grid settings

Chart Types​

Line Chart​

The base chart, offering general settings, plot line settings, 3D settings, series settings, X/Y axis settings and data settings.

Bar Chart​

There are vertical and horizontal bar charts, and the settings for both are identical.

Scatter / Area / Radar / Bubble Chart​

The general settings are the same as the line chart, with plot line, series, axis and data settings.

Pie Chart & Donut Chart​

The settings for both are identical. They consist of general settings, 3D settings, dedicated settings and data settings — there are no X/Y axis settings.

Gauge Chart​

Consists of general settings, series settings, Y axis settings and data settings. There are no X axis settings or plot line settings.

Solid Gauge Chart​

Has the same structure as the gauge chart, and its general settings chart area offers only the background colour item.

Box Plot Chart​

The general settings are the same as the line chart.

note

The box plot chart has only two channels, Observations and Outliers, which cannot be added to or removed.

Normal Distribution Chart​

The general settings are the same as the line chart, with plot line, series, axis and data settings.

Chart External Data Structure​

The shape of the external data connected to a chart depends on how the axes are composed.

X axis and Y axis data​

For charts with both an X and a Y axis — line, horizontal bar, vertical bar, scatter, area, radar and bubble charts.

DataBase type — Write the query to produce the following table structure. The column names may differ.

FieldDescription
REC_TIMEThe field used as the X axis. When the X axis type is Datetime it must be converted with UNIX_TIMESTAMP
series1, series2, series3 …Every field other than the X axis is recognized as a series, and the series settings of the chart must use series names matching the field names for them to be rendered

Other data structures​

StructureCharts
Y axis and category dataCharts using a category axis
Y axis dataCharts using only a Y axis
Single Y axis and single data pointSingle-value charts such as gauge and solid gauge

For the detailed field definitions of each structure, see Chart external data structure in the online manual.

tip

To control charts by script or connect REST data, see the VX object common script / VX Chart dedicated script. The box plot chart and normal distribution chart provide their own dedicated scripts.

:::note Chart count limits The number of VX Chart controls and their channel counts can be set in the VisualWorX server settings (dbChartCount, dbchart.channelCount). :::

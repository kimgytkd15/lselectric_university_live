Drawing and Editing Tools

Insert and edit objects on a page. Every object is inserted from the main menu Insert or from a toolbar icon.

Common Properties​

Most objects share the following properties.

PropertyDescription
Object nameThe name (object type) of the object
LayerThe layer number the object belongs to
Left, TopThe top-left coordinates of the minimum bounding rectangle (MBR) containing the object
Width, HeightThe width and height of the object
Line colour / Line widthThe colour and thickness of the line representing the object
Background colourThe colour filling the inside of the object
No line colourWhen true, the object's line colour is transparent
No background colourWhen true, the object's background colour is transparent

Drawing (General)​

Character​

Insert with Insert → Character or the character icon in the toolbar.

In addition to the common properties:

PropertyDescription
Foreground colourThe colour of the text
Font type / Font size / Font styleFont settings for the text
Horizontal alignmentAligns text Left / Center / Right
Vertical alignmentAligns text Top / Middle / Bottom

Tag Value​

Insert with Insert → Tag Value. Selecting a tag through dynamic property settings (Display Value) displays that tag's value.

The properties are the same as the Character object.

Picture​

Insert with Insert → Picture. Selecting a picture file in the file dialog inserts it at the centre of the page.

Supported formats: bmp, gif, jpg, png, svg and others.

PropertyDescription
Image transparent colourThe colour to treat as transparent
Apply transparent colourSet to False to cancel transparency. Selecting an image transparent colour changes it to True
Image settingSets the image file
Image ratioAdjusts the size to the original image ratio

GIF Animation​

Insert with Insert → GIF Animation. Click where the animation should be placed, then select the GIF file. The properties are the same as the Picture object.

Drawing (Shapes)​

ShapeHow to draw
LineInsert → Line. Drag to draw
EllipseInsert → Ellipse. Drag to draw
RectangleInsert → Rectangle. Drag to draw
Rounded rectangleInsert → Rounded Rectangle. Drag to draw
TriangleInsert → Triangle. Drag to draw
PolygonInsert → Polygon. Click to add points; double-click or press Esc to finish
Sequence (polyline)Insert → Sequence. Drawn the same way as a polygon

Shape objects use the common properties. The Line object has no background colour properties.

Drawing (Controls)​

Controls are inserted by clicking and dragging to set their size.

ControlDescription
Alarm Viewer ControlDisplays the alarm list. Width and height must each exceed 100 for it to appear
Trend Viewer ControlDisplays a trend chart. Width and height must each exceed 100 for it to appear
Data Viewer ControlQueries data as a list. Width and height must each exceed 100 for it to appear
ComboBox ControlDropdown selection. Only the width can be changed
EditBox ControlText input
Date Control / Time ControlDate / time selection
Listbox ControlList selection
RadioButton Control / Checkbox ControlSingle / multiple selection
Sound ControlPlays sound
Tree ControlDisplays a hierarchy
WebViewer ControlEmbeds a web page
File Open ControlSelects and opens files
Flow Message ControlShows a flow message when an alarm occurs (see sysRTFlow)
VX Chart ControlDisplays charts (see VX Charts)
VX Grid ControlDisplays external data in a grid
VX Text ControlDisplays external data as text

:::tip Sub settings Right-click a control to show the context menu and click Sub settings to configure the detailed properties of that control. For runtime configuration see Control settings. :::

:::note Control count limits The number of each control object can be limited in the VisualWorX server settings (editorEnv). :::

Editing Tools​

Alignment​

Aligns two or more selected objects.

  • Horizontal — Align left / Align centre (left-right) / Align right
  • Vertical — Align top / Align centre (top-bottom) / Align bottom

Undo / Redo​

Undo returns to the previous state during editing, and redo restores it. Up to 10 history entries are kept.

Group / Ungroup​

Select two or more objects, then right-click → Group → Group or use the group icon in the toolbar. Grouped objects behave as a single object.

With a group object selected, clicking a sub-object once more lets you edit that sub-object inside the group.

caution
  • A group object cannot be included in another group.
  • Ungrouping deletes the dynamic properties applied to the group.

Find & Replace String​

Finds strings used across all objects on the page and replaces them.

PropertyDescription
Find whatThe string to find
Replace withThe replacement string
Replace whole stringReplaces the entire string containing the match
Find nextFinds the next matching string
ReplaceMarks the string in the list as planned for replacement
Select allSelects every string containing the match
ApplyApplies the replacements as shown in the list

Find & Replace Tag​

Finds tags mapped in all objects on the page, or in selected objects, and replaces them. It can also apply tag information and custom definitions as tooltips in bulk to the objects that use the selected tag.

PropertyDescription
Find whatThe tag name to find
Replace withThe replacement tag name
Replace whole tag nameReplaces the entire tag name containing the match
Find nextFinds the next matching tag
Select tagOpens the tag selector to choose the replacement tag name
ReplaceMarks the tag in the list as planned for replacement
ApplyApplies the replacements as shown in the list

Apply tooltip — Applies tooltips to objects: select an object in the object list on the right, configure the tooltip and apply.

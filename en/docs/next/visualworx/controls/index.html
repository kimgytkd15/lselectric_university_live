Control Settings

Configure the runtime query conditions and display of the controls inserted on a page.

Alarm Viewer Control settings​

Sets the query conditions of the alarm control included on a VisualWorX page.

Toolbar​

ButtonDescription
Play realtime alarmsResumes updating the grid with stopped realtime alarms
Stop realtime alarmsStops realtime alarm updates
Realtime alarmsUpdates the grid with realtime alarms
History alarmsDisplays history alarms in the grid
Alarm filter settingsDisplays the alarm settings window

Alarm settings window (EdgeHub project)​

Organized into four tabs: Filtering settings / Display item settings / General settings / Font settings.

Filtering settings

SettingDescription
Alarm statusThe alarm statuses shown in the alarm viewer
Alarm typeThe alarm types shown in the alarm viewer
Alarm group (group filtering)Whether group filtering applies and which groups are shown. When selected only those groups are displayed; when not selected all alarm tags are displayed
Alarm group (select all)Selects every item in the group list
Alarm group (group name filtering)Detailed character filtering on alarm group names. ; is the word separator and + the string separator
Tag filteringFilters by the tag name that raised the alarm on the realtime and history alarm screens, using the same ; and + separators
Apply / CloseApplies the settings to the alarm view control / closes the settings window

Group name filtering example — Typing UT;FA+Grp and pressing the detailed character filtering button automatically selects the alarm group names AlmGrp_UT and AlmGrp_FA.

Display item settings — Drag and drop the items you want from All items into Selected items to show those columns on screen.

General settings

SettingDescription
General settings (colours)Row background and text colours per alarm type
General settings (control)Show or hide the list scroll bar, header, toolbar and so on

Font settings — Sets the font of the alarm list.

:::note InfoU project The alarm settings window for an InfoU project has three tabs — Filtering settings / Display item settings / General settings — and the filtering items differ slightly: Alarm selection, Group tag (group filtering / select all / detailed character filtering) and Tag filtering. In its general settings, checking Limit display allows a maximum list count to be applied. :::

Trend Viewer Control settings​

Changes the runtime settings of the trend viewer control. Click the Show settings window button in the toolbar to display the trend settings window.

General settings​

SettingDescription
ApplySaves the settings to the trend and restarts the trend viewer control
LoadLoads and applies saved settings. Web clients read from the browser's internal DB; local reads a JSON file
ExportSaves the settings. Web clients save to the browser's internal DB under a name; local saves a JSON file
Layout (title / subtitle)The trend title and subtitle
Layout (multi trend)The trend type: single trend / multi trend (X-Y) / multi trend (Y-Y)
Layout (show menu button)Whether the menu button at the top right of the trend is displayed
Layout (background colour / line colour)The background and line colour of the menu button
Legend (display method)Vertical / horizontal
Legend (vertical alignment)Top / middle / bottom
Legend (horizontal alignment)Left / centre / right
Legend (text colour)Text colour when active, hovered and inactive
Chart area (fill / background colour)How the chart background colour is displayed, and the colour
Chart area (X/Y axis line colour, width, style)The chart's internal grid settings
Realtime/history (refresh interval)The chart refresh interval. 1 to 600
Realtime/history (X axis collection count)The number of X-axis data points displayed. 10 to 86400
Realtime/history (history sample count)The number of history samples. 30 to 3600

Plot line settings​

SettingDescription
Add / DeleteAdds or deletes a plot line
Plot nameThe name of the plot line shown on the chart
Y axisSelects the Y axis
ValueThe value at which the plot line is drawn
Colour / Line styleThe colour and style of the plot line
note

Up to "channel count × 3" plot lines can be added.

Channel settings​

SettingDescription
Layout (Y axis setting)The Y axis applied to the channel
Layout (line colour / width / style)The channel's display colour, thickness and style (solid, dashed and so on)
Layout (marker)The shape marking data positions along the channel's line
Layout (step)Displays the channel's line as a step chart
Layout (fill)Fills the area below the channel's line
Data (tag type)The tag type applied to the channel: online tag / archive tag
Data (tag name)The tag applied to the channel. The … button opens the tag selector
Data (data type)Selectable when the archive tag is a statistics tag

Data type options (tied to the historian model types of the DataWorX Tag Historian)

Historian modelSelectable data
PeriodAnalog (current value), Digital (current value)
StatisticsAnalog (current value, minimum value, maximum value, average value, variance, sample count) / Digital (current value, number of runs, uptime, number of changes, sample count)
AccumulationAnalog (current value)
StringString (current value)
note

The maximum number of trend viewer control channels can be set in the VisualWorX server settings.

Y axis settings​

SettingDescription
Show axis / Show axis title / Show axis labelDisplayed when checked
Major unit / Major tickThe Y axis interval / the major tick position (outside, inside)
Minor unit / Minor tickWhether Y axis minor units are shown (Auto, None) / the minor tick position
Axis rangeUse auto-scale / use user-defined maximum and minimum
Minimum / MaximumThe Y axis range
note

A trend viewer control can have up to 10 Y axes.

Data Viewer Control settings​

The data viewer control provides list-based data queries. It can be configured for realtime tags and history tags, and offers downloading the query screen to Excel.

note

Toolbar buttons such as query by hour and query by date appear when a history tag is configured.

General settings​

SettingDescription
Do not show timeWhen checked, time is not shown in the list
Screen refresh interval (sec)1 to 600
List (sample) countThe maximum number of list entries. 10 to 3600
Value display formatHow decimal places are displayed

Channel settings​

SettingDescription
Channel listThe channels currently configured
Tag typeOnline tag / archive tag
Select tagThe Tag button opens the tag selector; the selected tag is displayed
Tag descriptionThe string entered here is used as the column name of the data view. If left blank the tag name is used
NewClears the tag selection and description so a new channel can be configured
SaveRegisters a newly configured tag or changes to an existing channel
DeleteDeletes the selected channel
Apply / CloseApplies the settings / closes the settings window
note

A data viewer control can have up to 10 channels.

VX Grid Control settings​

Sets the external data (Database, JSON) shown in the grid.

DataBase type​

SettingDescription
ApplyApplies the settings to the DB grid control and restarts it
Load / ExportLoads or saves settings (web client: browser internal DB; local: JSON file)
External DB nameSelects an external DB connection
Query stringThe query executed periodically
Update intervalHow often the query runs (milliseconds, seconds, minutes, hours)
Query timeout (sec)The query timeout
Other (show sequence number)Whether a sequence number is shown in the grid
Run queryRuns the query and shows it in the grid below. The displayed grid matches the actual control
Grid style settingsOpens the grid style settings window

Script type​

SettingDescription
ScriptSets the DB grid data by script (the Axios library is embedded)
responseThe variable receiving REST data through the Axios library
this.Grid.setJsonData(response.data)Where setJsonData inserts the REST data
Update intervalThe execution interval (milliseconds, seconds, minutes, hours)
Expand editorOpens the script editing screen as a pop-up

Grid style settings​

Fonts and colours

SettingDescription
Header font / Row fontThe header and row fonts
Header font size / Row font sizeThe font sizes
Header background colour / Header text colourHeader colours
Row odd background / Row even background / Row text colourRow colours
Selected row text / background colourColours of the selected row
Selected cell text / background colourColours of the selected cell

Alignment and layout

SettingDescription
Column / Ascending·DescendingThe column to sort by and the sort direction
Header text alignment / Column text alignmentText alignment for the header and columns
Double headerConfigures a two-row double header
Row heightSets the row height
Column width %The column width percentage (CSV type, to two decimal places)
Auto-fit column widthFits column width to the cell contents

External data structure​

  • Database type — Rendered in the grid exactly as the query result.
  • Script type — Applies the JSON format provided by dhtmlx (Native JSON format or Basic JSON format). Reference: dhtmlx documentation — Configuring Grid from JSON
warning

The VX Grid runs on every configured interval, so write queries and scripts that do not load the server.

VX Text Control settings​

Sets the external data (Database, JSON) shown in the text.

DataBase type​

SettingDescription
ApplyApplies the settings to the DB text control and restarts it
Load / ExportLoads or saves settings
External DB nameSelects an external DB connection
Query stringThe query executed periodically
Update intervalHow often the query runs (milliseconds, seconds, minutes, hours)
Run queryRuns the query and shows it in the grid below
Display position (row, column)Shows the data at that row and column in the text control

Script type​

SettingDescription
ScriptSets the DB text data by script (the Axios library is embedded)
responseThe variable receiving REST data through the Axios library
this.DBText_1.setJsonData(response.data)Where the REST data is inserted
Update intervalThe execution interval (milliseconds, seconds, minutes, hours)
Expand editorOpens the script editing screen as a pop-up
warning

The VX Text runs on every configured interval, so write queries and scripts that do not load the server.

When writing scripts, see the VX object common script and VX Text dedicated script.

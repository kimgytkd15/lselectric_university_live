Dynamic Properties

Dynamic properties let an object change its size, position, colour and more according to a tag value, and implement user actions such as changing pages or writing values on click.

Select an object, right-click and run Dynamic property settings from the context menu. Dynamic properties that involve animation are linked to a tag by default.

Common Settings​

PropertyDescription
…Opens the tag selector to choose the tag that supplies the input value for the dynamic property
ScriptUses an expression to drive the dynamic property. See Dynamic properties script
ConfirmSaves the changes and closes the window
ApplySaves the changes and keeps the window open. Useful when moving between objects without closing the settings window
CancelCloses the window without saving

:::warning Dynamic property notes

  • Dynamic properties are configured per object.
  • The dynamic properties available differ by object.
  • A dynamic property only runs when its name is checked. Input validation runs on the fields of checked dynamic properties.
  • Multiple dynamic properties can be set on a single object. :::

Size and Movement​

Horizontal Size / Vertical Size​

Changes the size horizontally or vertically.

PropertyDescription
Tag nameThe tag the dynamic property applies to. Using a script that reads from DBSource also allows it to respond to a DB value
Move directionThe direction in which the size changes
Data change rangeThe range of tag input values used by the dynamic property. For example, with a minimum of 50 and a maximum of 100, the dynamic property is shown while the tag value is between 50 and 100. There is no limit on the values entered, but they should reflect the tag's value range
Size change rangeThe size change range as a percentage (%), between 0 and 100

Horizontal Move / Vertical Move​

Moves the object horizontally or vertically. Tag name, move direction and data change range are the same as for size changes.

PropertyDescription
Move change range (pixels)The movement range in pixels, between 0 and 9999. The minimum movement is fixed at 0
caution

Entering a value larger than the canvas moves the object off screen, where it may not be displayed.

Horizontal Fill / Vertical Fill​

Fills the object horizontally or vertically.

Horizontal Drag / Vertical Drag​

Lets the user drag the object to change a tag value.

Display Changes​

Image​

Shows a different image according to the tag or DBSource value.

PropertyDescription
Reference value settingsSets which image is shown for which value
Insert row / Delete rowAdds or removes a reference value

Color​

Changes the object's colour according to the tag value.

Display String​

Sets the string displayed according to the tag value.

Display Value​

Displays the tag's value on the object. Used with the Tag Value object.

Blink / Visible / Rotate​

  • Blink — Makes the object blink according to the tag value
  • Visible — Shows or hides the object according to the tag value
  • Rotate — Rotates the object according to the tag value

Frame Animation​

Displays several frames in sequence as an animation.

Click Actions​

Click - Change Page​

Switches to the specified page on click.

Click - Write Digital Value​

Writes a value to a digital tag on click.

Click - Enter Value​

Shows a value input window on click and writes the value to a tag.

note

At runtime, objects with a click dynamic property display a border in response to the mouse cursor. See Runtime — Click dynamic properties.

Dynamic Properties Script​

To use a tag expression, click the Script button to open a window where you load tags and write the script.

Writing the script so it reads data from DBSource lets the dynamic property respond not only to tag values but also to DB values.

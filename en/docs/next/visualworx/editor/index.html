Editor

VisualWorX Editor is the graphic editor that provides the features needed to build monitoring screens.

Features​

Functions​

  • Provides various graphic object tools — Line, Rectangle, Rounded Rectangle, Ellipse, Triangle, Polygon, Sequence, Picture, GIF Animation, Character, Tag Value, Alarm Object, Listbox Object, Radio Button Object, Checkbox Object, VX Chart Object, VX Grid Object, VX Text Object and more
  • Dynamic property settings provide a variety of animations and user actions — horizontal/vertical size, horizontal/vertical movement, colour, blinking, visibility, rotation, tag writing and more
  • User settings let you register users and set pages, tag lists and so on per user

Start​

caution

To start VisualWorX Editor, the VisualWorX Server service must be started.

Select VisualWorX Editor from the Program menu to run it.

Project​

A VisualWorX project folder contains system pages and user pages.

Starting a project​

Connect to VisualWorX Editor and log in with the project administrator ID/password.

info

Projects are created in VisualWorX Server, and an administrator ID/password is required at creation.

The demo project's administrator account is User ID admin / Password admin1234.

Saving and logging out​

MenuDescription
File → Save projectSaves the whole project (also available from the toolbar)
File → Save pageSaves only the page you are currently viewing
File → LogoutLogs the current account out and returns to the initial login screen

The user is logged out when the session expiry time set under Project settings → Users is reached.

:::warning Concurrent editing If VisualWorX Editor is logged in to the server from different remote locations at the same time, unintended work may be performed from another location, causing unwanted behaviour or conflicts. :::

Reloading a project​

After opening a project served by VisualWorX Server in the Editor and editing pages or users, click the Reload project button in the toolbar to have the server reload and serve the changes immediately.

Reconnecting​

While VisualWorX Runtime is running, a reconnect pop-up appears if the network drops or the server shuts down.

  • Network failure — After the reconnect pop-up, the existing page is restored when the network recovers
  • Server shutdown — After the reconnect pop-up, the login page is shown when the server comes back up

Page​

A page is the monitoring screen composed in the Editor and monitored in the Runtime.

Adding a page​

Create one with File → New page, by right-clicking User Pages in the page pane and choosing Add, or with the New Page button in the toolbar.

PropertyDescription
NameUp to 60 characters using Korean/English letters, numbers and _
WidthAn integer between 20 and 3840
HeightAn integer between 20 and 3840

Editing and deleting pages​

Right-click a user page to edit its name, width and height, or to delete it.

danger
  • If the previous page name was used in dynamic properties, layouts or other VisualWorX features, renaming the page stops those features from working. Update every dynamic property and layout setting that uses the page name.
  • Clicking Delete removes the file from the file system immediately.

Page background settings​

With no object selected, double-click Background settings in the page properties to open the canvas background settings window.

Colour settings

PropertyDescription
Background colourThe background colour of the page
Margin background colourThe margin colour outside the page
Border (px)The page border thickness

Image settings

PropertyDescription
Image fileSets the background image
PatternNo repeat / Repeat / Repeat horizontally / Repeat vertically
Image settingShown only for the no repeat pattern; sets the image size (original size / fit to canvas)
caution

Setting a background image embeds the image data in the project file, so a small image file is recommended (limit: 2 MB or less).

DBSource​

Both controls and pages can access a database and fetch data periodically.

  • The DBSource in the right property pane when an object is selected → called from the object
  • The DBSource in the right property pane when no object is selected → called from the page

Use the add/delete buttons on the left to manage the queries sent to the database. The usage is the same as the Database settings of the VX Grid control.

tip

Because controls can read a value already held at page level, this can improve performance compared with each control fetching the data itself.

Script (Global Script)​

An area for defining user functions and variables shared across the whole project, loaded automatically when the project runs.

  • Declaration — Declare functions and variables using standard JavaScript syntax.
  • Invocation — Typing Global. in a script shows the functions and variables declared in the global script. If nothing appears, press Ctrl + Space after Global..

User Images​

Register external images or images you create into the library, then drag them from the library onto a page.

ActionHow
RegisterSelect an object → right-click → Save as user image. Saved into the User Image folder, visible in the library
UseDrag and drop from the user image folder of the graphic library
DeleteSelect the image in the library → right-click → Delete image → Yes in the confirmation window

User Symbols​

A user symbol makes objects reusable by replacing each tag name in the dynamic properties with a substitutable string. You define the object only once, then supply the substitution strings each time you place it on a page.

Registering​

  1. Enter a substitution string (keyword) as the tag name in the dynamic properties. Substitution strings start with $ (for example, $screen).
  2. Select the objects containing the substitution strings and right-click.
  3. Run Save symbol in the pop-up menu. It is saved into the User Symbol folder.

Using and configuring an instance​

Drag and drop the symbol from the user symbol folder of the graphic library onto a page. The user symbol instance settings window appears at the moment of insertion, where you enter the substitution string for each keyword.

Deleting​

Select the user symbol in the library → right-click → Delete symbol → Yes in the confirmation window.

System Pages​

System pages are named pages for common use within a project. They are included by default when a new project is created, and can be modified, or deleted and recreated with the same name.

sysRTTrend (Realtime Trend)​

Right-click a tag value object on the runtime screen to view it and pop up the real-time trend for that tag. For setup details see Trend Viewer Control settings.

sysRTAlarm (Realtime Alarm)​

Right-click a tag value object on the runtime screen to view it and pop up the real-time alarms for that tag. For setup details see Alarm Viewer Control settings.

sysRTFlow (Flow message)​

A page that can always be displayed on the runtime screen, popping up when a registered alarm tag is raised.

When it first appears there is no pop-up header; clicking once creates a header so it can be moved or closed, and clicking again removes the header and fixes it in place.

Unlike other system pages, sysRTFlow has a flow position property so the flow message can be shown where you want it.

PropertyDescription
Background settingSets the background colour of the flow message system page
DBSourceSee DBSource
Use the Flow PopupSets whether the flow message is used
Flow positionSets where the flow message appears: Top / Middle / Bottom

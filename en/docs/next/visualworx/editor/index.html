에디터 (Editor)

VisualWorX Editor는 그래픽 편집기로서 감시화면을 제작할 수 있는 다양한 기능을 제공합니다.

특징​

기능​

  • 다양한 그래픽 오브젝트 툴 제공 — 선, 직사각형, 둥근 직사각형, 타원, 삼각형, 다각형, 연속선, 그림, GIF 애니메이션, 문자, 태그값, 알람 오브젝트, 리스트박스, 라디오 버튼, 체크박스, VX 차트, VX 그리드, VX 텍스트 등
  • 동적 특성 설정으로 다양한 애니메이션과 유저 액션 제공 — 수평/수직 크기, 수평/수직 이동, 색상, 점멸, 출몰, 회전, 태그 값쓰기 등
  • 사용자를 등록하고 각 사용자별 페이지, 태그 리스트 등을 설정

시작​

caution

VisualWorX Editor를 시작하려면 VisualWorX Server의 서비스가 시작된 상태여야 합니다.

프로그램 메뉴에서 VisualWorX Editor를 선택하여 실행합니다.

화면 구성​

영역설명
메인메뉴VisualWorX Editor에서 제공하는 기능들을 사용
툴바그래픽 편집에서 자주 사용되는 표준 도구와 오브젝트 도구를 아이콘화
프로젝트현재 작업 중인 프로젝트
페이지 편집 화면페이지를 편집하는 화면. 오브젝트 작화 및 동적 특성 정의
네비게이션페이지에서 원하는 작업영역으로 쉽게 이동
속성 창각 오브젝트의 속성을 표시하거나 변경
레이어레이어 on/off, 편집 레이어 설정, 레이어 이름 변경
상태 바캔버스 크기, 마우스 좌표 등 현재 편집 중인 페이지의 상태 값 표시

프로젝트​

VisualWorX는 프로젝트 폴더 내에 시스템 페이지와 사용자 페이지로 구성되어 있습니다.

프로젝트 시작하기​

VisualWorX Editor에 접속하여 프로젝트 관리자 ID/Password로 로그인합니다.

info

프로젝트는 VisualWorX Server에서 생성할 수 있으며, 생성 시 관리자 ID/Password를 필수 항목으로 입력해야 합니다.

데모 프로젝트의 관리자 계정은 User ID admin / Password admin1234 입니다.

프로젝트 저장 / 로그아웃​

메뉴설명
파일 → 프로젝트 저장하기프로젝트 전체를 저장 (툴바 버튼으로도 가능)
파일 → 페이지 저장하기현재 보고 있는 페이지만 저장
파일 → 로그아웃현재 계정을 로그아웃하고 초기 로그인 화면으로 전환

프로젝트 설정 → 사용자 메뉴에서 설정한 세션 만료 시간이 되면 자동 로그아웃 처리됩니다.

:::warning 동시 편집 주의 VisualWorX Editor는 서로 다른 원격지에서 서버에 로그인하여 동시에 엔지니어링 작업을 할 경우, 사용자가 의도하지 않은 작업이 다른 원격지에서 이루어지는 등 원치 않은 동작이나 충돌이 발생할 수 있습니다. :::

프로젝트 재로드​

VisualWorX Server에서 서비스하고 있는 프로젝트를 Editor에서 열어 페이지나 사용자를 수정·편집한 후, 툴바의 프로젝트 재로드 버튼을 클릭하면 변경된 내용을 즉시 서버에서 재로딩하여 서비스할 수 있습니다.

재접속​

VisualWorX Runtime 실행 중 네트워크가 끊어지거나 서버 종료 시 재접속 팝업이 노출됩니다.

  • 네트워크 이상 시 — 재접속 팝업 노출 후, 네트워크 정상화 시 기존 페이지로 전환
  • 서버 종료 시 — 재접속 팝업 노출 후, 서버 가동 시 로그인 페이지로 전환

페이지​

페이지는 Editor에서 작화해서 Runtime에서 모니터링하는 감시화면입니다.

페이지 추가​

파일 → 새 페이지 메뉴, 페이지 창에서 사용자 페이지 우클릭 → 추가, 또는 툴바의 새 페이지 버튼으로 생성합니다.

속성설명
이름한글/영문/숫자와 _의 조합으로 최대 60자
너비20 ~ 3840 사이의 정수값
높이20 ~ 3840 사이의 정수값

페이지 수정 / 삭제​

사용자 페이지에서 우클릭하여 이름 및 너비, 높이를 수정하거나 삭제합니다.

danger
  • 수정 이전의 페이지 이름이 동특성, 레이아웃 등에서 사용된 경우, 페이지 이름을 수정하면 해당 기능이 실행되지 않습니다. 페이지 이름을 수정하면 해당 이름을 사용하는 동특성, 레이아웃 등의 설정도 함께 변경해야 합니다.
  • 페이지 삭제를 클릭하면 해당 파일이 파일 시스템에서 즉시 삭제됩니다.

페이지 배경 설정​

객체가 선택되지 않은 상태에서 페이지 속성의 배경설정을 더블클릭하면 캔버스 배경 설정창이 표시됩니다.

caution

배경이미지 설정 시 프로젝트 파일에 이미지 데이터가 포함되므로 작은 용량의 이미지 파일 사용을 권장합니다. (이미지 용량 2MB 이하 제한)

DBSource​

각 컨트롤과 페이지 모두에서 DB에 접근하여 데이터를 주기적으로 가져올 수 있습니다.

  • 객체를 선택했을 때 나타나는 우측 속성창의 DBSource → 객체에서 호출하여 사용
  • 객체를 선택하지 않았을 때 나타나는 우측 속성창의 DBSource → 페이지에서 호출하여 사용

좌측의 추가/삭제 버튼으로 DB에 보낼 쿼리를 관리하며, 사용 방법은 VX 그리드 컨트롤의 Database 설정과 동일합니다.

tip

페이지 단위에서 가지고 있는 값을 각 컨트롤에서 가져와 사용할 수 있으므로, 컨트롤에서 직접 가져오는 것보다 성능 향상을 기대할 수 있습니다.

스크립트 (전역 스크립트)​

프로젝트 전체에서 공통으로 사용할 사용자 함수 및 변수를 정의하는 영역으로, 프로젝트 실행 시 자동으로 로드됩니다.

  • 선언부 — JavaScript에서 지원하는 문법으로 함수 및 변수를 선언합니다.
  • 호출부 — 호출할 스크립트에서 Global. 을 입력하면 전역 스크립트에 선언한 함수 및 변수가 표시됩니다. 표시되지 않으면 Global. 뒤에서 Ctrl + Space를 누릅니다.

사용자 이미지​

외부 이미지 또는 사용자가 만든 이미지를 라이브러리에 등록하여 사용하는 기능으로, 라이브러리에서 드래그하여 페이지로 쉽게 추가할 수 있습니다.

작업방법
등록객체 선택 → 우클릭 → 사용자 이미지로 저장. User Image 폴더에 저장되며 라이브러리에서 확인 가능
사용그래픽 라이브러리의 사용자 이미지 폴더에서 드래그/드롭
삭제라이브러리에서 이미지 선택 → 우클릭 → 이미지 삭제 → 확인 창에서 예

사용자 심볼​

사용자 심볼은 객체들의 동적 특성을 구성할 때 각 태그 이름을 대체 가능한 문자열로 두어 재사용이 가능하도록 만든 심볼입니다. 객체를 단 한 번만 정의하면 되고, 페이지에 놓을 때마다 대체 문자열만 지정하면 됩니다.

등록​

  1. 동특성의 태그 이름에 대체할 문자열(키워드)을 입력합니다. 대체할 문자열은 $로 시작합니다. (예: $screen)
  2. 대체 문자열을 포함하는 객체들을 선택하고 우클릭합니다.
  3. 팝업 메뉴의 심볼 저장 메뉴를 실행합니다. User Symbol 폴더에 저장됩니다.

사용 및 인스턴스 설정​

그래픽 라이브러리의 사용자 심볼 폴더에서 심볼을 드래그/드롭하여 페이지에 삽입합니다. 삽입되는 순간 사용자심볼 인스턴스 설정 창이 표시되며, 각 키워드에 대한 대체 문자열을 입력합니다.

삭제​

라이브러리에서 사용자 심볼 선택 → 우클릭 → 심볼 삭제 → 확인 창에서 예.

시스템 페이지​

프로젝트 내에서 공통적으로 사용할 수 있도록 이름이 정해진 페이지입니다. 새 프로젝트 생성 시 기본으로 포함되며, 사용자가 원하는 형태로 변경하거나 삭제 후 동일 이름으로 다시 만들어 사용할 수 있습니다.

sysRTTrend (실시간 트랜드)​

런타임 화면의 태그값 오브젝트에서 우클릭하여 조회하며, 해당 태그에 대한 실시간 트랜드를 팝업으로 띄웁니다. 자세한 설정은 트랜드 뷰어 컨트롤 설정을 참고하세요.

sysRTAlarm (실시간 알람)​

런타임 화면의 태그값 오브젝트에서 우클릭하여 조회하며, 해당 태그에 대한 실시간 알람을 팝업으로 띄웁니다. 자세한 설정은 알람 뷰어 컨트롤 설정을 참고하세요.

sysRTFlow (흐름메세지)​

런타임 화면에서 항상 띄울 수 있으며, 등록된 알람태그 발생 시 팝업 형태로 표시되는 페이지입니다.

처음 화면에 나타났을 때는 팝업의 헤더가 없는 상태이며, 한 번 클릭하면 헤더가 생성되어 이동하거나 닫을 수 있고, 한 번 더 클릭하면 헤더가 사라져 해당 자리에 고정됩니다.

sysRTFlow는 다른 시스템 페이지와 달리 플로우 위치 속성이 있어 원하는 위치에 흐름메시지를 표시할 수 있습니다.

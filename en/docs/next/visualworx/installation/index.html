Installation and Removal

Install​

  1. Run the Setup program and select the installation language.
  2. Enter the installation path and continue.
  3. Click Next to proceed.
  4. Accept the license agreement.
  5. Enter user and organization information.
  6. Select the installation option.
    • Complete — Installs all items (recommended)
    • Custom — Installs selected items
  7. Click Install to proceed.
  8. Click OK to finish installing the VisualWorX license program.
  9. Installation complete.

The default installation path is C:\EdgeHub\VisualWorX.

:::tip First run after installation When VisualWorX Server is run for the first time it starts in a stopped state. Right-click the tray icon to complete the service settings and license registration before starting the service. :::

Uninstall​

  1. Open Control Panel and go to Programs and Features.
  2. Select VisualWorX from the app list and run the uninstaller.
  3. Click Uninstall in the confirmation dialog.
  4. Verify that the VisualWorX program was removed correctly.

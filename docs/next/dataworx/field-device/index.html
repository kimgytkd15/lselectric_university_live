필드 디바이스

Field Device는 DataWorX에서 사용할 채널, 디바이스, 블록을 등록하고 관리하는 메뉴입니다. 장비로부터 데이터를 수집하기 위해 통신 채널, 디바이스, 통신 블록을 추가·설정합니다.

계층 구조는 채널 → 디바이스 → 블록 순입니다.

채널​

DataWorX는 물리적인 디바이스와 통신하기 위한 드라이버 및 통신 설정을 채널이라는 단위로 관리합니다.

채널 추가​

  1. 서브 내비게이션 상단 또는 테이블 우측 상단의 채널 추가 버튼을 클릭합니다.
  2. 우측 패널에 채널 설정 정보를 입력합니다.
  3. 우측 패널 하단의 확인 버튼을 클릭합니다.
노트

드라이버를 선택해야 해당 채널의 설정 정보를 확인할 수 있습니다.

채널 정보 / 수정 / 삭제​

작업방법
정보서브 내비게이션 메뉴 → 채널 정보 / 테이블 행 더보기 → 채널 정보 / 테이블 Lock 모드에서 채널명 옆 열기 버튼
수정서브 내비게이션 메뉴 → 채널 수정 / 테이블 행 더보기 → 채널 수정 / 테이블 Edit 모드에서 채널명 옆 열기 버튼
삭제서브 내비게이션 메뉴 → 채널 삭제 / 테이블 행 더보기 → 채널 삭제 / 다중 선택 후 테이블 좌측 상단 삭제 버튼

디바이스​

디바이스는 DataWorX에 물리적으로 연결된 하위 필드 디바이스를 의미합니다. PLC, Inverter, 전력량계 등의 단위 기기일 수도 있으며, 다른 시스템 및 서버 등 데이터를 수집하는 모든 대상을 DataWorX 입장에서는 디바이스로 관리합니다.

채널 목록 페이지에서 서브 내비게이션 또는 테이블을 통해 이동합니다.

디바이스 추가​

  1. 서브 내비게이션의 채널 더보기 메뉴 또는 테이블 우측 상단의 디바이스 추가 버튼을 클릭합니다.
  2. 우측 패널에 디바이스 설정 정보를 입력합니다.
  3. 확인 버튼을 클릭합니다.

정보 / 수정 / 삭제 방법은 채널과 동일합니다.

팁

스프레드 시트 기능을 사용하면 디바이스 추가·수정을 엑셀에서 쉽게 진행할 수 있습니다.

블록​

블록은 하위 필드 디바이스의 통신 수집 단위 및 주기를 설정합니다. 메모리 주소 타입(Address Type), 시작 주소(Start Address), 길이(Length), 주기(Period) 등을 설정하여 데이터를 수집합니다.

:::caution 블록 설정 시 유의사항

  • 블록 단위로 수집하고, 태그에서 해당 범위 내의 주소값을 입력하여 사용합니다.
  • 블록에서 설정한 범위 내에 없는 주소는 태그 설정에서 사용할 수 없습니다.
  • 블록 길이의 Max Size는 기기 종류와 타입별로 상이합니다.
  • 디바이스와 프로토콜 종류에 따라 블록 설정이 없는 경우가 있습니다. :::

디바이스 목록 페이지에서 서브 내비게이션 또는 테이블을 통해 이동합니다.

블록 추가​

  1. 서브 내비게이션의 디바이스 더보기 메뉴 또는 테이블 우측 상단의 블록 추가 버튼을 클릭합니다.
  2. 우측 패널에 블록 설정 정보를 입력합니다.
  3. 확인 버튼을 클릭합니다.
노트

Enable 토글을 OFF하면 해당 블록은 데이터를 수집하지 않습니다.

정보 / 수정 / 삭제 방법은 채널·디바이스와 동일하며, 스프레드 시트로 일괄 작업할 수 있습니다.

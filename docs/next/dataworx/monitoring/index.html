통신 상태 및 태그 모니터링

런타임 중인 프로젝트의 상태를 감시하는 두 페이지입니다. 모두 좌측 메인 내비게이션을 통해 이동합니다.

통신 상태​

실행 중인 프로젝트와 연결된 디바이스의 상태를 감시하거나 디바이스 사용 여부를 설정합니다.

디바이스 통신상태​

상태설명
Inactive프로젝트가 실행되지 않은 상태 및 통신 미시도 상태
Active프로젝트가 실행되어 디바이스가 연결된 상태
Error프로젝트가 실행되었으나 디바이스와의 연결에 문제가 있는 상태

디바이스 사용 설정​

테이블 내 사용 컬럼의 ON/OFF를 클릭하여 디바이스를 켜고 끌 수 있습니다.

노트

ON/OFF 버튼은 프로젝트 실행 중에만 사용 가능합니다.

목록 보기​

  • 통신상태 전체목록 — 프로젝트에 연결된 모든 디바이스의 상태 확인
  • 채널별 통신상태 목록 — 서브 내비게이션의 채널명 또는 테이블의 채널명 클릭 시 해당 채널의 디바이스만 필터링

속성 설명​

속성설명
채널명채널 명
디바이스명디바이스 명. 글씨 색에 따라 상태를 나타냄
설명디바이스 설명
IP / Station No.IP 통신은 IP를, Serial 통신은 Station Number를 표시
읽기 시도 / 읽기 성공장비 읽기 시도 및 성공 횟수 (Project Run 시 표시)
쓰기 시도 / 쓰기 성공장비 쓰기 시도 및 성공 횟수 (Project Run 시 표시)
재연결 시도통신연결 재시도 횟수 (Project Run 시 표시)
사용현재 통신 연결을 Enable로 설정했는지 표시

:::tip 통신 상태 진단 정상 통신 상태를 확인할 때는 재연결시도, 읽기 시도, 읽기 성공을 확인합니다.

  • 재연결시도가 지속적으로 증가하는 경우 → 디바이스 설정 정보를 재확인
  • 읽기 시도와 읽기 성공의 숫자가 다른 경우 → 태그 설정 정보를 재확인 :::

태그 모니터링​

실행 중인 프로젝트의 태그값과 상태를 감시하거나 태그값을 제어합니다.

태그 목록​

태그 페이지처럼 좌측 서브 내비게이션 또는 테이블 헤더를 통해 태그를 필터링할 수 있습니다. 태그 페이지와 달리 테이블에 툴바가 없으며, 모니터링을 위한 컬럼이 추가되어 있습니다.

태그 모니터링 컬럼​

태그값 — 현재 태그값이 표시됩니다. 시뮬레이션이 적용된 태그는 상태 앞에 SI 아이콘이 표기됩니다.

태그 상태

상태설명
-미동작 상태
SCAN START : [상세]최초 통신 시도
SCAN STOP최초 통신 연결 불가
GOOD정상
UNKNOWN알 수 없음
IO BAD : [상세]최초 통신 연결 이후, 현재 통신 불가
ENG BAD : [상세]장비 또는 공업치 데이터의 범위를 넘었을 경우
ALARM : [상세]알람 메시지 표시
ALARM DELAY알람 딜레이 표시

업데이트 시간 — 태그값이 업데이트된 시간

태그 정보​

테이블의 태그 아이템에 마우스를 올리면 태그 이름 컬럼 우측에 열기 버튼이 나타납니다. 클릭하면 우측 패널에서 태그 정보를 확인할 수 있습니다.

속성설명
이름태그명, 그룹명
설명태그 또는 그룹의 설명
종류Analog / Digital / String (그룹은 미표시)
현재값프로젝트가 Run일 때만 표시. 시뮬레이션 값 또는 실제 수집 데이터
상태프로젝트가 Run일 때만 표시. 데이터의 상태
변경 버튼프로젝트가 Run이고, 계정 권한이 Admin 또는 Engineering이며, 태그 설정 시 Write Flag가 체크된 태그만 활성화
태그값 종류태그의 Value Type
태그 최솟값 / 최댓값공업치 데이터의 최솟값 / 최댓값
장비 최솟값 / 최댓값수집되는 장비의 최소 / 최대 설정 값
Deadband태그 종류가 Analog일 때만 표시. Analog 상세의 소수점 Deadband 값

태그값 제어​

태그 정보 패널에서 태그 정보 카드 우측 하단의 태그값 변경 텍스트 버튼을 클릭하여 값을 변경합니다.

:::warning 제어 가능 조건 태그값은 다음 세 조건이 모두 충족되어야 제어 가능합니다.

  1. 프로젝트가 실행 중이어야 합니다.
  2. 계정의 권한이 Admin 또는 Engineer여야 합니다.
  3. 태그 속성 중 추가 기능의 태그값 쓰기가 체크되어 있어야 합니다. :::

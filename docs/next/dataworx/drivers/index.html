드라이버

DataWorX가 제공하는 통신 드라이버입니다. 각 드라이버 문서는 연결 가능 기종 → 결선도 → 통신드라이버 설정(PLC 설정 / EdgeHub 설정) → 사용 가능 디바이스 순으로 구성되어 있습니다.

주소 체계, 결선도, 영역별 허용 범위 등은 드라이버마다 크게 다르므로, 실제 설정 시에는 아래 표의 상세 매뉴얼을 직접 확인하십시오.

팁

드라이버를 채널에 할당하는 방법은 필드 디바이스 — 채널을, DataWorX가 지원하는 전체 드라이버의 프로토콜·제조사 목록은 지원 드라이버 목록을 참고하세요.

알람 매니저

DataWorX를 비롯한 SCADA 시스템에서 알람은 중요한 항목입니다. 이 문서에서는 DataWorX의 알람 처리 방식과 알람 그룹 설정을 설명합니다.

정보

DataWorX에서는 태그 타입이 아날로그 또는 디지털인 경우에만 알람을 설정할 수 있으며, 태그의 값이 정상적으로 수집된 경우에만 알람 처리를 합니다.

알람 발생 및 해제 규칙​

태그 종류알람 구분알람 종류발생 규칙해제 규칙
아날로그경계 알람HH 알람태그 값이 HH 이상일 때HH 알람 발생 후, 태그값이 HH 미만일 때
HI 알람태그 값이 HI 이상이고 HH보다 작을 때HI 알람 발생 후, 태그값이 HI보다 작거나 HH 이상일 때
LO 알람태그 값이 LO 이하이고 LL보다 클 때LO 알람 발생 후, 태그값이 LO보다 크거나 LL 이하일 때
LL 알람태그 값이 LL 이하일 때LL 알람 발생 후, 태그값이 LL보다 클 때
변화량 알람변화량 알람태그 값이 과거 값 대비 기준 값 이상으로 편차가 클 때변화량 알람 발생 후, 편차가 기준값 미만일 때
이격 알람주 이격 알람태그 값이 기준 값 대비 주 이격 값 이상으로 차이날 때주 이격 알람 발생 후, 차이가 주 이격 값 미만일 때
보조 이격 알람태그 값이 기준 값 대비 보조 이격 값 이상, 주 이격 값 미만으로 차이날 때차이가 주 이격 값 이상이거나 보조 이격 값 미만일 때
디지털디지털 알람ON 알람태그의 값이 ON일 때태그의 값이 OFF일 때
OFF 알람태그의 값이 OFF일 때태그의 값이 ON일 때
ON → OFF 알람태그의 값이 ON에서 OFF로 바뀔 때발생과 동시에 해제
OFF → ON 알람태그의 값이 OFF에서 ON으로 바뀔 때발생과 동시에 해제
변화 알람태그 값이 변할 때발생과 동시에 해제

아날로그 알람​

경계 알람​

태그가 아날로그 타입일 때 가장 많이 사용되는 알람입니다.

  • HH, HI, LO, LL 네 가지 경계 값을 설정합니다.
  • 태그 값의 영역을 수평으로 나누어, 값이 해당 영역에 위치하면 알람이 발생하고 벗어나면 해제됩니다.
  • 각 경계는 불감대(Deadband) 영역을 가질 수 있습니다. 알람 Deadband 값을 설정하면 태그값의 증감 및 위치 영역에 따라 Deadband 룰이 적용됩니다.

변화량 알람​

  • 태그의 현재 값이 과거 값과 비교하여 태그 속성에 설정된 변화값 이상으로 변화하면 발생합니다.
  • 이후 값이 설정된 변화값 미만으로 변화하면 해제됩니다.
  • 태그의 값이 크게 변화하면 안 되는 경우 설정합니다.
  • 변화량 알람은 불감대(Deadband) 룰이 적용되지 않습니다.

이격 알람​

  • 태그의 값이 기준값을 기준으로 주 이격과 보조 이격의 차이를 이용하여 발생합니다.
  • 경계 알람과 마찬가지로 알람 불감대(Deadband) 룰이 적용됩니다.
  • 경계 알람과의 차이점:
    • 이격 알람은 경계 알람과 같은 상하의 구분이 없습니다.
    • 기준 값은 절대값 또는 상대값(다른 태그의 값) 으로 설정 가능합니다.

디지털 알람​

태그 타입이 디지털인 경우 이전 값과 현재 값에 따라 알람을 설정합니다.

알람 타입설명
ON 알람값이 ON일 때 발생, OFF일 때 해제
OFF 알람값이 OFF일 때 발생, ON일 때 해제
ON → OFF 알람값이 ON에서 OFF로 바뀔 때 발생하며 동시에 해제
OFF → ON 알람값이 OFF에서 ON으로 바뀔 때 발생하며 동시에 해제
변화 알람값이 변화할 때 발생하며 동시에 해제

알람 지연​

현장의 값이 이상 상태를 보일 때 즉시 알람 처리하지 않고, 설정된 지연 시간이 지난 후의 값을 최초 알람 발생 시점 이전의 값과 비교하여 알람을 발생시키는 기능입니다.

알람 지연 설정​

알람 지연 기능을 사용하려면 두 가지 항목을 설정해야 합니다.

1. 지연시간 설정

태그 → 알람 설정에서 지연 시간을 입력합니다. 이 값은 각 태그에 대해 개별 설정하며, 해당 태그의 모든 알람에 적용됩니다.

2. 알람지연 플래그 설정

[프로젝트 경로]/[프로젝트 명]/Config/ehDataProcess.ini 파일을 열어 다음과 같이 설정합니다.

DP_ALARMDELAY_FLAG=1

DataWorX 런타임을 기동시키면 알람 지연 시간이 적용됩니다.

경고

알람 지연 시간 설정은 DataWorX 런타임 적용 시 상당한 부하를 야기할 수 있으므로 꼭 필요한 경우에만 사용해야 합니다.

알람그룹 관리​

알람그룹은 태그를 논리적 집합으로 구분하고 관리 포인트별로 일괄 동작을 수행하기 위한 역할을 합니다. 발생된 알람은 알람그룹별로 필터링하여 조회하거나 LogicFlow에서 처리 동작을 정의할 수 있습니다.

속성설명
알람그룹 명필수 입력 항목. 알람그룹의 이름
알람그룹 설명알람그룹에 대한 설명
등급알람그룹의 등급 (1~10). 태그 설정 시 태그의 알람 등급이 정해지지 않은 경우 알람그룹의 등급을 사용

추가 / 정보 / 수정 / 삭제는 서브 내비게이션 메뉴, 테이블 행 더보기 메뉴, 테이블 우측 상단 버튼을 통해 수행합니다.

알람태그 설정​

태그 페이지에서 생성한 태그를 알람그룹에 등록합니다. 서브 내비게이션 또는 테이블의 알람그룹명을 클릭하여 이동합니다.

  • 태그 등록 — 테이블 우측 상단의 태그 등록 버튼 → 모달에서 태그 선택 → 확인
  • 태그 제거 — 테이블 행 더보기 메뉴 또는 다중 선택 후 테이블 좌측 상단의 제거 버튼
노트

태그 등록 모달의 태그 목록에는 알람이 설정되어 있는 태그만 표시됩니다.

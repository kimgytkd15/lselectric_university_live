화면 구성 요소

DataWorX의 모든 페이지는 공통 컴포넌트로 구성됩니다. 각 컴포넌트의 조작 방법을 익히면 전체 페이지를 동일한 방식으로 사용할 수 있습니다.

애플리케이션 바​

전역 설정, 현재 시각 확인, 프로젝트 관련 설정을 수행하는 최상단 컴포넌트입니다.

항목설명
BI 이미지클릭 시 프로젝트 목록 페이지로 이동
프로젝트 바프로젝트 오픈 시 프로젝트 설정 아이템 표시
현재 시각현재 시각 표시
사용자 메뉴로그인한 사용자 아이디 표시. 프로필 / 로그아웃
온라인 사용자현재 로그인한 사용자들의 아이디, IP 주소, 로그인 시간 표시
설정 메뉴라이선스 관리 / 사용자 관리 / 시스템 설정
도움 메뉴I/O 드라이버 목록 / 시스템 정보 / 시스템 로그 / 매뉴얼 / About

시스템 설정 모달​

설정설명
알림앱바 실시간 알람 토글을 켜면 애플리케이션 바 우측에 알림 아이콘이 생성되어, 프로젝트 실행 중 발생하는 알람을 실시간으로 확인
언어 & 테마애플리케이션에서 사용되는 언어(한국어/영어)와 테마(밝게/어둡게) 설정
레이아웃메인 내비게이션의 스타일 변경
테이블테이블의 열 간격과 테이블 내 글자 크기를 작게 설정. 하단 초기화 버튼으로 PC에 설정된 전체 테이블 설정 초기화
사용자 보안설정된 횟수만큼 로그인 실패 시 설정된 시간 동안 계정 잠금
클라이언트 이중화클라이언트 화면 자동절체를 켜면 Master 서버 장애 시 Standby 서버로 화면 자동 전환

디스플레이 설정은 적용 버튼 클릭 시 설정 반영을 위해 페이지가 새로고침됩니다.

프로젝트 바​

프로젝트 오픈 시 애플리케이션 바에 표시되며, 프로젝트의 상태를 변경할 수 있습니다.

  • 프로젝트 명 — 클릭 시 프로젝트 목록 이동 / 프로젝트 닫기 메뉴 사용
  • 프로젝트 상태 — OPENED가 기본 상태이며, 프로젝트 실행 시 RUNNING으로 변경
  • 프로젝트 상태 변경 버튼 — 오픈 상태에서는 실행 버튼, 실행 중에는 중지 버튼 표시
  • 프로젝트 종료 버튼 — 프로젝트를 종료하고 프로젝트 목록 페이지로 이동

메인 내비게이션​

프로젝트의 주요 페이지로 이동하는 좌측 내비게이션입니다.

아이템이동 대상
프로젝트프로젝트
로그프로젝트 로그
필드 디바이스필드 디바이스
태그태그
로직플로우로직플로우
시뮬레이터시뮬레이터
서버서버
태그 히스토리안태그 히스토리안
알람 매니저알람 매니저
통신 상태통신 상태
태그 모니터링태그 모니터링

메인 내비게이션 하단의 서브 내비게이션 버튼으로 보조 내비게이션인 서브 내비게이션을 닫거나 열 수 있습니다.

스타일​

애플리케이션 바의 설정 → 시스템 설정 → 레이아웃에서 변경합니다.

  • 아이콘 — 기본 스타일. 마우스를 올리면 툴팁으로 아이템명 확인
  • 아이콘 + 텍스트 — 아이콘 하단에 아이템명 표시
  • 아이콘 확장 패널 — 마우스 호버 시 내비게이션이 확장되며 아이템명 표시

서브 내비게이션​

특정 엔티티의 페이지로 이동하거나 엔티티를 생성/수정/삭제합니다.

  • 검색 — 서브 내비게이션 내의 엔티티를 검색어로 필터링. 검색어는 파란색으로 하이라이트되며 영문 대소문자를 구분하지 않습니다.
  • 추가 버튼 — 루트 레벨의 엔티티를 생성. 클릭 시 우측 패널이 열립니다.
  • 트리 뷰 — 하위 아이템이 있는 경우 트리를 펼쳐 목록 확인. 토글 상태는 저장됩니다.
  • 엔티티 메뉴 — 하위 아이템 추가, 해당 엔티티의 정보 확인/수정/삭제

우측 패널​

엔티티를 추가하거나 정보를 확인·수정하는 패널입니다.

  • 상단 — 좌측에 패널 제목, 우측에 닫기 버튼. ESC 키로도 종료
  • 본문 — 입력필드 또는 엔티티 정보 표시. 카드는 좌측 상단 버튼으로 접거나 펼침
  • 하단 — 입력필드가 포함된 경우 표시. 취소(작업 취소 후 종료) / 확인(작성 내용 제출)

브레드크럼​

상위 페이지부터 현재 페이지까지의 계층 구조를 표현합니다. 상위 페이지 이름 클릭 시 해당 페이지로, 홈 아이콘 클릭 시 프로젝트 목록으로 이동합니다.

테이블​

엔티티의 속성을 행과 열로 나타내며, 엔티티를 추가/수정/삭제합니다. 페이지마다 더보기 메뉴의 아이템이 다를 수 있습니다.

로우 (행)​

기능설명
하위 아이템 목록하위 아이템을 가진 경우 해당 목록 페이지로 이동
우측 패널 오픈로우에 마우스를 올리면 나타나는 버튼으로 속성 정보 확인
우측 패널 잠금Lock — 정보 표시 / Edit — 속성 수정 가능
행 메뉴아이템 수정/삭제/복제, 하위 아이템 추가
정렬오름차순(ASC)/내림차순(DESC). Ctrl + 다른 컬럼 정렬 아이콘 클릭 시 다중 컬럼 정렬
필터컬럼의 특정 조건에 따라 데이터 필터링
검색필드테이블 데이터를 검색어로 필터링
행 높이좁게 / 기본 / 넓게
전체 로우 수테이블 우측 하단에 표기

컬럼 (열)​

  • 컬럼 표시/숨김, 리사이징(컬럼 사이 바를 드래그), 순서 변경(컬럼 이름을 드래그)
  • 컬럼 메뉴 — Sort / Pin(좌·우 고정) / Filter / Column
  • 컬럼 헤더 필터 — 컬럼별 필터에 빠르게 접근. 초기에는 숨겨져 있으며 툴바 메뉴로 사용 여부를 설정합니다.
노트

주기적으로 데이터가 업데이트되는 페이지(시뮬레이터, 통신상태, 태그 모니터링)에서는 컬럼 헤더 필터 설정을 변경할 수 없습니다.

아이템 선택​

단축키설명
Ctrl + A모든 아이템 선택 (사용 전 마우스로 아이템을 선택해야 함)
첫 행 클릭 → Shift + End모든 아이템 선택
Shift + ↑/↓선택된 아이템 기준으로 화살표 이동하며 다중 선택
Shift + Click선택된 아이템부터 클릭한 아이템까지 다중 선택
Ctrl + Click클릭한 아이템만 다중 선택

로우를 클릭하면 해당 아이템이 선택되며, Ctrl 키를 누르면서 선택된 아이템을 클릭하면 선택이 해제됩니다. 복사 기능은 현재 태그 페이지의 그룹별 뷰에서만 제공됩니다.

스프레드 시트​

스프레드 시트를 사용해 데이터를 추가하거나 수정합니다. 디바이스, 블록, 태그 페이지에서만 사용 가능합니다.

  • 우측 패널 상단의 버튼으로 패널 사이즈를 조절할 수 있습니다.
  • 기존 데이터의 다음 행에 데이터를 입력하면 엔티티가 추가됩니다.
  • 첫 번째 열은 고유 아이디를 포함하므로 데이터 입력이 불가합니다.
  • 입력 후 확인 버튼을 클릭하면 유효성 검사가 실행되고, 유효하지 않은 데이터는 패널 좌측에 결과가 표시됩니다. 세부사항은 테이블 아이템 좌측의 버튼으로 확인하며, 유효성 검사 카드는 접거나 펼칠 수 있습니다.
  • 시트 내 데이터를 필터링하거나 정렬할 수 있습니다.

태그 전용 메뉴​

태그 옵션 설정, 가져오기, 내보내기, LS PLC 가져오기, 태그 유효성 검사. 자세한 내용은 태그 — 추가 기능을 참고하세요.

기타 기능​

  • 다운로드 — 테이블 데이터를 .csv로 다운로드
  • 인쇄 — 테이블 데이터를 인쇄
  • 테이블 설정 초기화 — 저장된 정렬, 필터 등의 설정 초기화

알림 바​

프로젝트가 실행 중일 때 엔지니어링 페이지에 변경이 생기면 페이지 우측 상단에 알림 바가 나타납니다. 적용 버튼을 클릭하면 변경된 내용이 프로젝트 런타임에 반영되며, X 버튼으로 알림을 종료할 수 있습니다(1분 뒤 다시 나타남).

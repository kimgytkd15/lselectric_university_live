프로젝트

DataWorX는 여러 개의 프로젝트를 생성하고 관리할 수 있습니다.

프로젝트 목록​

DataWorX에 생성한 프로젝트 목록을 확인합니다. 목록에는 Demo 프로젝트가 포함되어 있습니다.

  • 프로젝트 오픈 — 프로젝트 카드를 클릭
  • 프로젝트 상태 — OPENED / RUNNING 중인 프로젝트는 프로젝트 명 옆에 상태 표시
  • 프로젝트 명 변경 — 프로젝트 명에 마우스를 올리면 나타나는 연필 아이콘 클릭
  • 프로젝트 목록 업데이트 — 업데이트 아이콘 버튼 클릭. 버튼 좌측의 시간은 마지막 업데이트 시각
주의

프로젝트 명은 공백 또는 숫자로 시작할 수 없으며, 길이는 25 Byte로 제한됩니다. 영문, 숫자, 한글과 특수문자 -, _만 허용됩니다. OPENED/RUNNING 중인 프로젝트 명은 변경할 수 없습니다.

프로젝트 경로​

프로젝트 목록을 불러오거나 프로젝트가 저장될 위치를 설정합니다. 프로젝트 목록 페이지의 경로 설정 버튼으로 이동합니다.

  • 기본 프로젝트 경로는 C:/EdgeHub/DataWorX/Project 입니다.
  • 경로 추가 — 목록 카드 우측 상단의 + 버튼. 모달에서 파일 탐색기와 동일한 방식으로 폴더를 찾고, 브레드크럼으로 이전 위치로 이동합니다.
  • 경로 삭제 — 테이블 행 더보기 메뉴, 또는 다중 선택 후 테이블 좌측 상단의 삭제 버튼

비밀번호 설정​

  1. 비밀번호 설정 카드에서 비밀번호 사용 토글을 켭니다.
  2. 카드 하단의 비밀번호 설정 텍스트 버튼을 클릭합니다.
  3. 모달에서 원하는 비밀번호를 설정합니다.
  4. 설정이 완료되면 카드 하단 텍스트 버튼의 체크 표시가 파란색으로 변경됩니다.

시스템 이중화 설정​

  1. 시스템 이중화 설정 카드에서 시스템이중화 사용 토글을 켭니다.
  2. 해당 PC의 이중화 역할(Master / Standby)을 선택합니다.
  3. Master IP와 Standby IP를 설정합니다.
  4. Master PC와 Standby PC에서 프로젝트를 모두 실행하면 시스템 이중화가 활성화됩니다.

동작 방식:

  • Master PC가 종료되면 Standby PC가 기동됩니다.
  • Master PC가 복구되면 Standby PC는 대기 상태로 변경됩니다.

:::warning IP 설정 규칙

  1. 역할이 Master인 경우, 기본 IP 주소와 Master IP가 동일해야 합니다.
  2. 역할이 Standby인 경우, 기본 IP 주소와 Standby IP가 동일해야 합니다.
  3. Master IP와 Standby IP는 서로 달라야 합니다. :::

회선 이중화 설정​

  1. 세부정보 카드에서 회선 이중화 사용 토글을 켜고 보조 IP를 설정합니다.
  2. 시스템 이중화 설정 카드에서 시스템이중화 사용 토글을 켭니다.
  3. Master 보조 IP와 Standby 보조 IP를 설정합니다.

절체 규칙:

  • 웹 클라이언트로 접속한 IP가 기본 IP인 경우 — 시스템 이중화 역할에 따라 Master IP 또는 Standby IP로 클라이언트 절체
  • 웹 클라이언트로 접속한 IP가 보조 IP인 경우 — Master 보조 IP 또는 Standby 보조 IP로 클라이언트 절체

현재 회선 이중화 설정은 시스템 이중화 설정 시 추가적인 보조 IP에 따른 클라이언트 이중화 절체에서 사용됩니다.

클라이언트 이중화​

시스템 이중화 설정 시 화면이 자동 절체되는 기능입니다.

  • Master PC와 Standby PC가 모두 Active인 경우: Standby PC IP로 로그인하면 Master IP 화면으로 전환됩니다.
  • Master PC에 화면 접속 중 Master PC가 종료되면 Standby PC 화면으로 자동 절체됩니다.
  • Master PC가 복구되면 Standby PC 화면이 자동으로 Master PC 화면으로 절체됩니다.
노트

localhost 또는 127.0.0.1 IP로 접속한 경우 엔지니어링으로 간주하여 화면 절체가 이루어지지 않습니다.

Master IP 또는 Standby IP로 접속 시 클라이언트 절체를 원하지 않으면, 이중화절체 토글을 OFF로 변경하고 로그인합니다. 시스템 설정에서 다시 ON으로 변경할 수 있습니다.

프로젝트 파일​

프로젝트가 생성되면 [프로젝트 경로]/[프로젝트 명]에 다음 파일들이 생성됩니다.

프로젝트 정보 / 수정​

  • 프로젝트 정보 — 현재 오픈된 프로젝트의 설정 정보를 확인합니다. 좌측 메인 내비게이션으로 이동합니다.
  • 프로젝트 수정 — 프로젝트 정보 카드 우측 상단의 수정 버튼으로 이동합니다.
주의

프로젝트의 생성자, 패키지명, 경로는 변경 불가하며, 프로젝트 명은 프로젝트 목록 페이지에서 수정합니다.

프로젝트 로그​

DataWorX 내 활동 로그를 확인합니다. 페이지 진입 시 날짜 범위는 오늘로 설정되며, 기간 지정과 보관기간 설정 방식은 시스템 로그와 동일합니다.

프로젝트 삭제​

위험

DataWorX에서 생성한 프로젝트는 UI를 통해 삭제할 수 없습니다. 파일 탐색기에서 프로젝트가 저장된 위치로 이동하여 폴더 전체를 삭제합니다. 현재 열려 있거나 운영 중인 프로젝트를 삭제하지 않도록 주의하십시오.

관리 기능

로그인, 라이선스, 사용자, 시스템 설정 등 프로젝트와 무관한 전역 관리 기능입니다. 대부분 애플리케이션 바를 통해 이동합니다.

로그인​

DataWorX를 사용하기 위한 사용자 인증 페이지입니다. 세션이 없거나 종료된 경우 이 페이지로 이동됩니다.

최초 사용 시 슈퍼 관리자 계정 admin / 초기 비밀번호 1234로 로그인합니다.

최초 사용자 로그인​

최초 로그인 시 시작화면과 함께 초기 비밀번호 설정을 진행해야 합니다. 비밀번호는 최소 8자, 최대 15자입니다.

로그인 시도 잠금​

일정 횟수 로그인 시도가 실패하면 일정 시간 동안 로그인이 제한됩니다. 잠금 이후 로그인 시도 시 실패 횟수와 남은 잠금 시간이 표시됩니다. 설정은 시스템 설정 → 사용자 보안에서 합니다.

비밀번호 만료​

로그인 만료 기간 설정 시, 기간이 지난 후 로그인하면 비밀번호 변경 화면이 표시됩니다. 다음에 변경하기 클릭 시 비밀번호는 유지되고 만료기간이 초기화됩니다. 설정은 사용자 관리에서 합니다.

프로필​

로그인한 사용자의 정보를 수정합니다.

  • 사용자 명 — 영문·한글 3~30자
  • 아이디와 권한은 변경할 수 없습니다.
  • 프로필 카드 하단 우측의 비밀번호 설정 버튼으로 비밀번호를 수정합니다. 모달의 확인 버튼을 클릭하면 즉시 설정됩니다.

라이선스​

:::info 관리자 전용 라이선스 페이지는 관리자 권한만 사용할 수 있습니다. :::

라이선스를 등록하지 않은 경우, DataWorX 설치일로부터 14일간 태그 1000개를 사용할 수 있는 Trial 라이선스가 자동 부여됩니다. 14일 이후에는 라이선스를 등록해야 사용할 수 있습니다.

라이선스 발급​

DataWorX 구매 시 라이선스 키가 메일로 제공됩니다.

  • EID — 오프라인 라이선스 등록을 위한 로그인 ID
  • Product Key — 온라인 라이선스 등록을 위한 제품 번호

온라인 라이선스 등록​

인터넷이 연결된 환경에서 사용합니다.

  1. 라이선스 관리 우측 상단의 수정 버튼을 클릭합니다.
  2. 등록 방법을 Online으로 선택합니다.
  3. 라이선스 메일에 기재된 Product Key를 제품 키(pkId) 에 입력한 후 저장합니다.
  4. 라이선스 정보 화면에서 등록을 확인합니다.

오프라인 라이선스 등록​

인터넷이 연결되지 않은 환경에서 사용합니다.

  1. 라이선스 관리 화면 테이블 좌측 상단의 오프라인 키 다운로드 버튼을 클릭하여 DataWorX_Information.c2v 파일을 다운로드합니다.
  2. 인터넷이 가능한 PC에서 ls-electric.prod.sentinelcloud.com/customer에 접속합니다.
  3. 라이선스 파일에 기재된 EID 또는 Product ID를 입력하여 로그인합니다.
  4. Activate Offline 버튼을 클릭하고, 라이선스 인증 파일을 받을 E-Mail 주소를 입력합니다.
  5. Select File 버튼으로 1단계에서 저장한 *.c2v 파일을 업로드합니다.
  6. Complete Activation을 클릭하여 오프라인 라이선스를 활성화합니다.
  7. Activation was successful 메시지와 함께 오프라인 라이선스 파일(.V2CP)을 다운로드합니다. 입력한 E-Mail 주소로도 압축 파일이 전송됩니다.
  8. 다운로드한 .V2CP 파일을 업로드하고 저장 버튼을 클릭합니다.
  9. 라이선스 정보 화면에서 등록을 확인합니다.

라이선스 이전 (Transfer)​

사용 중인 라이선스를 다른 PC로 옮기는 기능입니다.

  • 실행 파일 경로: [DataWorX 설치 경로]\ETC\LicenseRehostTool\LicenseRehostTool.exe
  • 기본 경로 설치 시: C:\EdgeHub\DataWorX\ETC\LicenseRehostTool\LicenseRehostTool.exe
노트

본 라이선스 이전 방식은 DataWorX v4.0.0 이후 적용되는 방식입니다. v4.0.0 이전 버전의 라이선스 키를 마이그레이션하거나 계속 유지해야 하는 경우 LS ELECTRIC 측에 문의하십시오.

이전 작업에는 두 대의 PC(새 PC, 기존 PC)가 사용되며, 두 PC 모두에서 LicenseRehostTool.exe를 실행합니다.

1. [새 PC] 정보 파일(.id) 생성​

  1. 새 PC에서 LicenseRehostTool.exe를 실행합니다.
  2. Step 1. Generate New PC Info (New PC) 영역으로 이동합니다.
  3. Save PC Info File (.id) 우측의 ... 버튼으로 저장 경로를 지정합니다.
  4. 우측 하단의 Create 버튼으로 정보 파일(.id)을 생성합니다.
  5. 생성된 .id 파일을 USB 등으로 기존 PC에 복사합니다.

2. [기존 PC] 이전 파일(.h2h) 생성​

  1. 기존 PC에서 LicenseRehostTool.exe를 실행합니다.
  2. Step 2. Export License File (Current PC) 영역으로 이동합니다.
  3. Select License to Transfer 목록에서 이전할 제품 라이선스를 선택합니다.
  4. Import New PC Info File (.id) 우측의 ... 버튼으로 1단계의 .id 파일을 불러옵니다.
  5. Save Transfer File 우측의 ... 버튼으로 이전 파일(.h2h) 저장 경로를 지정합니다.
  6. Create 버튼으로 이전 파일(.h2h)을 생성하고, USB로 새 PC에 복사합니다.

3. [새 PC] 라이선스 활성화​

새 PC에서 제품 프로그램을 실행하고, 2단계의 .h2h 파일을 라이선스 등록 창에 등록하여 활성화를 완료합니다.

:::danger 필수 주의 사항 1. 실행 중인 제품 세션 확인 — 기존 PC에서 .h2h 파일을 생성하기 전에 해당 제품 프로그램이 완전히 종료되어 있어야 합니다. 종료 후에도 세션이 남아있다면 http://localhost:1947/_int_/sessions.html에 접속하여 해당 세션의 Actions 열에서 Disconnect 버튼으로 강제 종료하십시오.

2. 이전 파일(.h2h) 분실 주의 — 생성된 .h2h 파일을 분실하면 어떠한 경우에도 다시 생성할 수 없습니다. 이 경우 기존 PC와 새 PC 모두에서 라이선스를 사용할 수 없게 되며, 사전 백업 미이행으로 인한 라이선스 분실은 무상 재발급 및 보상이 지원되지 않습니다. :::

사용자 관리​

기능설명
사용자 목록현재 DataWorX에 추가된 사용자 목록 확인
사용자 추가목록 카드 우측 상단의 + 버튼
사용자 정보 수정목록의 메뉴 버튼 → 수정 페이지 (아이디는 변경 불가)
비밀번호 설정사용자 정보 카드 하단 우측의 비밀번호 설정 버튼
사용자 삭제목록의 메뉴 버튼. Ctrl/Shift로 다중 선택 삭제 가능
  • 사용자 아이디 — 영문, 숫자, 특수문자 -, _를 사용하여 3~30자
  • 사용자 명 — 영문, 한글 3~30자
  • 역할 — 복수 선택 가능. 접근 제어 참고
주의

최초 관리자 admin은 삭제할 수 없습니다.

비밀번호 만료 설정​

비밀번호 정보 카드의 토글을 ON하고 유효기간과 시간 단위를 설정합니다. 설정한 기간 이후 로그인 시 비밀번호 재설정 창이 표시됩니다.

세션 만료 설정​

세션 설정 카드의 토글을 ON하고 세션 유효기간과 시간 단위를 설정합니다. 설정한 시간 동안 웹 화면에서 움직임이 없으면 자동 로그아웃됩니다. 웹 화면이 꺼져 있을 때는 1시간 동안만 로그인이 유지됩니다.

접근 제어​

역할(Role)을 생성하고 권한을 부여하는 페이지입니다. 애플리케이션 바 → 사용자 관리 → 접근제어 버튼으로 이동합니다. 생성된 역할은 사용자별로 적용할 수 있습니다.

클라이언트 화면 자동절체 사용 여부를 설정합니다. 자세한 내용은 프로젝트 — 클라이언트 이중화를 참고하세요.

시스템 로그​

DataWorX 내 시스템 로그를 확인합니다. 페이지 진입 시 날짜 범위는 오늘로 설정됩니다.

로그 기간 지정​

테이블 상단 툴바의 날짜 필드를 클릭하여 기간을 수정합니다. 날짜 선택기 좌측의 바로가기 버튼으로 특정 기간을 쉽게 조회할 수 있습니다.

바로가기설명
오늘 (Today)오늘
어제 (Yesterday)어제
지난 7일 (Last 7 Days)7일 전 ~ 오늘
지난 주 (Last Week)지난 주 일요일 ~ 지난주 토요일
이번 달 (Current Month)이번 달 1일 ~ 오늘
지난 달 (Last Month)지난 달

미래의 날짜는 선택할 수 없으며, 시작날짜가 종료날짜보다 미래일 수 없습니다.

로그 보관기간 설정​

테이블 상단의 기간 설정 버튼으로 보관기간을 설정합니다. 0은 영구 보관이며, 숫자를 입력하면 보관 일수를 지정할 수 있습니다.

시스템 정보​

DataWorX가 실행되는 서버의 리소스 정보를 확인합니다.

  • 세부정보 — 서버 이름, 운영체제, CPU 종류, 메모리, 시스템 타입, IP 주소
  • 하드 디스크 — 각 저장장치별 사용량
  • CPU 사용량 / 메모리 사용량 — 현재 사용량
  • CPU 사용량 추이 / 네트워크 추이 — 사용량 추이 그래프

드라이버 / 버전 정보​

  • 드라이버 — DataWorX에서 사용 가능한 드라이버를 확인합니다. 드라이버 카드의 정보 아이콘을 클릭하면 우측 패널에서 상세 정보를 확인할 수 있습니다. 전체 목록은 드라이버를 참고하세요.
  • 버전 정보(About) — DataWorX의 버전 관련 정보를 확인합니다.

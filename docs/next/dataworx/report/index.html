버전: DX:4.1.0, VX:5.0.0

보고서

EdgeHub 보고서는 수집 모델에 정의된 로깅 데이터를 조회하여 지정된 시간에 엑셀 파일을 생성하거나 출력할 수 있습니다.

  • 엑셀이 설치되지 않은 환경에서도 자체 형식의 보고서 파일을 생성·출력할 수 있습니다.
  • 알람 로깅 데이터를 조회하여 자체 형식의 보고서 파일을 생성·출력할 수 있습니다.
  • 태그 현재값, 태그 속성값을 조회하여 엑셀 파일이나 자체 형식의 보고서를 생성·출력할 수 있습니다.
  • 시보, 일보, 주보, 월보, 연보, 임의보, 기간보 등 다양한 주기의 보고서를 원하는 시간에 출력할 수 있습니다.

보고서 특징​

  • 보고서 복제 기능으로 비슷한 유형의 보고서 작성이 편리합니다.
  • 엑셀 파일을 양식으로 사용하는 엑셀 보고서와 자체 양식을 사용하는 일반 보고서로 구성됩니다.
  • 엑셀 보고서는 엑셀의 그래프, 도표, 서식, 통계 등의 기능을 그대로 사용할 수 있습니다.
  • 일반 보고서의 자체 양식 편집기로 테이블 기반의 보고서 양식을 편리하게 작성하고, 태그/알람/이벤트 로깅 보고서 양식을 작성할 수 있습니다.
  • PDF, DOC, XLS, TEXT 등 다양한 형식으로 결과를 생성할 수 있습니다.

본 매뉴얼은 Microsoft Excel 2010 기준으로 작성되었습니다.

보고서 시작​

EdgeHub 보고서는 .NET Framework 3.5 기반의 C# 으로 제작되어 실행 파일로 실행됩니다. 엑셀 보고서를 작성하려면 Microsoft Excel 2007 이상이 설치되어야 합니다.

보고서 편집기 실행 파일: [설치경로]/DataWorX/bin/Report/EhReportEditor.exe

보고서 편집기 구성​

영역설명
메뉴자동 출력 정보 갱신 — 편집기에서 수정한 내용을 온라인 중에 반영 / 이력 정보 — 이력 데이터 수집모델의 저장 현황 조회
프로젝트 폼프로젝트의 보고서 그룹 및 보고서 목록을 트리 형태로 표시. 최상위 노드 우클릭 시 관리 팝업 메뉴 표시
보고서 레이아웃 편집기엑셀 보고서와 일반 보고서 레이아웃 편집기로 구분되어 표시
보고서 편집 로그편집기에서 이루어지는 작업 내용을 로그로 표시

보고서 편집 메뉴​

  • 프로젝트 메뉴 (최상위 노드 우클릭) — 그룹 추가 / 보고서 추가 / 속성
  • 그룹 메뉴 (그룹 아이콘 우클릭) — 그룹 추가 / 그룹 삭제(하위에 그룹·보고서가 있으면 삭제 불가) / 보고서 추가 / 속성
  • 보고서 메뉴 (보고서 아이콘 우클릭) — 보고서 복사 / 보고서 이동 / 보고서 삭제 / 보고서 속성 / 보고서 레이아웃

보고서 속성 정의​

속성설명

보고서 세부종류시보/일보/주보/월보/연보, 임의보, 기간보
서식 파일엑셀 보고서일 때만 선택 가능. .xls, .xlsx, .xlt, .xltx 파일을 반드시 설정해야 함
보고서 생성 주기임의보(Free Report)인 경우에만 설정 가능

저장경로프로젝트 내 폴더 선택 시 프로젝트 경로는 생략되어 저장
출력형식PDF/엑셀/워드/텍스트 문서. 복수 선택 가능. 엑셀 보고서일 때는 PDF만 선택 가능
출력 여부보고서 자동출력 실행 여부. 자동출력 시작 시간은 보고서 작성 시간과 동일
페이지 정보일반 보고서일 때만 설정 가능. 보고서 양식의 페이지 크기 지정

보고서 세부종류​

종류설명
시보, 일보, 주보, 월보, 연보기본 보고서로서 데이터 개수가 고정됨. 보고서 생성주기는 고정되며 데이터 수집주기를 사용자가 설정
임의보보고서 생성주기와 데이터 수집주기를 모두 사용자가 설정
기간보보고서 생성주기는 없으며 데이터 수집주기만 설정. Script와 같은 트리거를 통해 조회 기간을 입력받아 생성

보고서 생성 주기 예시

  • 일보 보고서 주기 = 1일, 수집주기 = 1시간 → 24개의 1시간 데이터가 모이면 일보 생성
  • 일보 보고서 주기 = 1일, 수집주기 = 15분 → 96개의 15분 데이터가 모이면 일보 생성

레이아웃 정의​

레이아웃 편집기는 보고서 유형에 따라 두 가지로 나뉩니다.

  • 태그 로깅 보고서 레이아웃 — 편집기 화면에서 테이블 속성을 설정합니다.
  • 엑셀보고서 레이아웃 — 엑셀 양식을 기반으로 최종 결과물을 구성합니다.

보고서 런타임​

보고서 런타임 트레이 아이콘의 팝업 메뉴에서 [보고서 런타임 보이기] 를 선택하면 런타임 화면이 표시됩니다. 정의된 모든 보고서 정보와 보고서 생성 과정 로그가 표시됩니다.

등록된 보고서 목록​

보고서 편집기를 통해 등록된 보고서 목록을 표시하며, 일반보고서와 엑셀보고서를 타입으로 구별할 수 있습니다.

색상의미
파란색세부종류가 기간보. 자동 생성에서 제외되며, 수동 생성이나 스크립트를 통해서만 생성 가능
빨간색속성은 설정되었으나 레이아웃이 없는 보고서. 자동 생성에서 제외

레이아웃 편집 / 파일 조회 / 수동 생성​

보고서 목록에서 우클릭하여 팝업 메뉴로 실행합니다.

레이아웃 편집 — 선택된 보고서를 보고서 편집기로 열어 레이아웃 편집 화면을 표시합니다.

파일 조회 — 생성된 보고서를 조회·열기·인쇄·삭제할 수 있습니다.

  • 보고서 열기 — 일반 보고서(.RPT)는 자체 뷰어, 엑셀 보고서는 엑셀이 실행됩니다. PDF/DOC/TXT 형식은 해당 애플리케이션과 연결되어 실행되므로, 애플리케이션 설치 여부를 사전에 확인해야 합니다.
  • 일반 보고서 뷰어 — 보고서 출력뿐 아니라 [내보내기] 메뉴를 통해 PDF/XLS/DOC/TXT/TIFF 형식의 보고서를 생성합니다.
  • 보고서 인쇄 — .RPT 형식의 일반보고서와 엑셀보고서만 직접 인쇄 가능합니다.
  • 보고서 삭제 — 삭제한 보고서 내용은 로그로도 출력됩니다.

수동 생성 — 사용자가 원하는 시간대의 보고서를 생성합니다.

  • 보고서 데이터 수집 현황 — 데이터 모델, 수집주기, 최초저장 시간, 최종저장 시간을 리스트로 표시 (알람 보고서는 미표시)
  • 요청시간 선택 — 정기보고서는 기준시간을, 기간보고서는 시작·종료 시간을 설정
  • 확인 — 요청 시간대의 데이터로 보고서를 생성합니다. 보고서 명에는 날짜/시간 정보와 함께 manual이라는 이름이 부여됩니다.

자동 보고서 생성​

  • 보고서 런타임은 실행과 동시에 보고서 목록을 조회하여 생성 시간을 체크하고, 생성 시간이 되면 구성정보와 레이아웃을 참고해 이력 데이터를 조회하여 보고서를 작성·저장·출력합니다.
  • 보고서 편집기에서 [자동 출력정보 갱신] 메뉴를 선택하면 온라인 중에 변경 내용이 반영됩니다.
  • 자동 생성 과정은 보고서 런타임 하단의 로그에 기록됩니다.
  • 보고서 속성에서 지정한 출력형식에 따라 PDF/XLS/DOC/TXT 형식의 보고서도 함께 생성됩니다.

보고서 제약사항​

경고
  • 엑셀 보고서에서 Sheet 1개에 추가할 수 있는 최대 Tag 수는 100개입니다.
  • 엑셀 보고서 Form 파일의 개인 정보 옵션에서 "저장 시 파일 속성의 개인 정보 제거" 항목이 체크 해제되어 있어야 보고서가 정상 동작합니다.
  • 연보 사용 시:
    • 월별 12개 데이터를 표시할 경우 → 수집주기 1달인 수집 모델(통계값, 적산값)
    • 월별 365개 데이터를 표시할 경우 → 수집주기 1일인 로깅 그룹(정주기)

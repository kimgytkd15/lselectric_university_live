DataWorX 소개

DataWorX는 IoT 시대의 데이터 처리를 강화하고 IT와 OT 영역 간의 Bridge 역할을 수행하는 웹 기반 소프트웨어입니다. Microsoft Windows OS를 기반으로 하며, 넓은 확장성·높은 신뢰성·빠른 처리속도·운용 편의성을 제공합니다.

DataWorX를 통해 OT 영역의 다양한 장비로부터 데이터를 수집·가공·저장하고, 현장의 요구와 로직을 프로그래밍하여 IT 영역의 상위 시스템에 안정적이고 유연하게 데이터를 제공하는 시스템을 구축할 수 있습니다.

:::info 문서 기준 버전 이 문서는 DataWorX v4.1.0 (온라인 매뉴얼 v3.0.6) 기준으로 작성되었습니다. :::

주요 특징​

개방형 구조​

Open Source를 활용한 확장성과 호환성이 뛰어난 개방형 구조로, 기기와의 안정적인 통신과 타 시스템과의 효과적인 인터페이스 구성이 가능합니다.

효율적인 프로젝트 관리​

다양한 종류의 프로젝트를 생성·관리할 수 있으며, 복사 기능을 활용한 손쉬운 엔지니어링을 지원합니다.

태그 엔지니어링​

두 가지 관점의 태그 관리 기준을 제공하여 엔지니어링의 효율성과 오퍼레이터 작업의 편리성을 함께 확보합니다.

기능설명
기기별 보기장비 구성에 따른 트리 형태의 태그 탐색기. 장비 설정과 태그 작업을 동시에 수행
그룹별 보기논리적 태그그룹을 윈도우 탐색기 형태로 표시. 운영자 관점에서 용도별 관리
Excel 가져오기/내보내기.xlsx 파일로 대량의 태그를 출력·추가·편집
연산식메모리 태그 값으로 수치연산식뿐 아니라 논리연산식 사용 가능
스프레드시트여러 태그의 데이터를 시트 형태로 한 번에 추가·수정
LS PLC 가져오기XG5000에서 저장한 변수 파일(CSV)을 DataWorX 태그로 자동 등록

드라이버 편의성​

  • 태그 시뮬레이터 — 실제 디바이스가 없거나 통신 개통 전이라도 태그에 여러 규칙의 데이터를 공급하여 현장과 동일하게 애플리케이션을 검증할 수 있어 디버깅 시간을 대폭 단축합니다.

    데이터 타입시뮬레이션 타입
    아날로그랜덤, 사인파, 삼각파, 톱니파, 제어가능, XG5000
    디지털랜덤, 변경, 제어가능, XG5000
    스트링랜덤, 제어가능

  • 디바이스 추가 시 시스템 태그 자동 등록 — 디바이스 등록 시 장비의 통신상태 태그가 자동 등록되어 디바이스 상태 및 통신 성능을 점검할 수 있습니다.

  • 태그 유효성 검사 — XGI/XGK 계열 디바이스의 입출력 주소와 통신 블록 설정이 올바른지 검사하여, 실제 통신 전에 잘못된 설정을 확인할 수 있습니다.

LogicFlow​

JavaScript 기반의 프로그래밍을 지원합니다. 스크립트 언어를 직접 작성하는 대신, LogicFlow라는 비주얼 개발 도구에서 드래그 앤 드롭 GUI로 현장 로직을 구현할 수 있습니다.

Web 기반 시스템​

웹 브라우저로 DataWorX 시스템에 접속하여 엔지니어링과 런타임을 수행합니다. DataWorX 서버 머신에 직접 가지 않아도 인터넷 환경에서 원격으로 모든 작업이 가능합니다.

시스템 요구 규격​

구분권장 사양
운영체제Windows 11 64bit Pro 이상
CPUIntel Core i5 이상 또는 동급 사양
RAM최소 16GB 이상
저장공간10GB 이상의 여유 공간
디스플레이기본 해상도 1024 × 768 이상을 지원하는 그래픽 카드 및 모니터
네트워크Ethernet 100Mbps 이상
통신 포트표준 시리얼 포트 (시리얼 통신 사용 시)
주의

실제 성능은 프로젝트 규모, 태그 수, 통신 주기, 연동 장비 수 및 실행 환경에 따라 달라집니다. 태그 개수가 많으면 CPU 및 RAM 스펙 증가가 필요합니다.

라이선스​

DataWorX는 실물이 없는 SW 형태의 라이선스를 사용합니다.

데모 모드​

  • 프로젝트에서 SW 라이선스로 제한된 태그 수를 초과하면 더 이상 태그가 저장되지 않으며 Runtime 실행도 불가능합니다.
  • 라이선스 유효기간을 넘기면 프로젝트 목록 화면으로 돌아가며 프로젝트 OPEN과 RUN이 불가능합니다. 신규 라이선스를 등록한 후 사용할 수 있습니다.

사용 예

  • 1000 태그용 라이선스 사용 시, 태그 1000개를 초과하면 런타임 실행 불가
  • 기간 라이선스 사용 시, 해당 기간 동안 등록된 태그 수 이하의 태그로 런타임 실행 가능
  • 라이선스 없이 사용 시, DataWorX 설치일로부터 14일간 태그 1000개로 런타임 실행 가능

라이선스 등록·이전 절차는 관리 기능을 참고하세요.

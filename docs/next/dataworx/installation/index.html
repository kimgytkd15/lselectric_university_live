설치 및 설정

DataWorX 설치 및 제거​

설치​

  1. Setup 프로그램을 실행하고, 설치 경로를 입력한 뒤 다음으로 진행합니다.
  2. 라이선스에 동의합니다.
  3. 사용자 및 조직 정보를 입력합니다.
  4. Install 버튼을 클릭하여 설치를 진행합니다.
  5. Node.js 설치를 진행합니다.
  6. PostgreSQL 설치를 진행합니다. (이력 DB 설치 참고)
  7. 설치 완료 후 컴퓨터를 재부팅합니다.

기본 설치 경로는 C:\EdgeHub\DataWorX 입니다.

제거​

  1. 제어판 → 프로그램 및 기능 메뉴로 이동합니다.
  2. 앱 리스트에서 DataWorX를 선택한 후 제거를 실행합니다.
  3. 확인 대화상자에서 제거 버튼을 클릭합니다.
  4. 컴퓨터를 재부팅한 뒤 정상적으로 삭제되었는지 확인합니다.

포트 설정​

DataWorX는 웹 브라우저가 접속하는 웹 접속 포트와, 웹 서버(nginx)가 내부적으로 요청을 전달하는 서버(백엔드) 포트를 각각 변경할 수 있습니다.

  • 설정 파일 경로: [DataWorX 설치 경로]\bin\EngineeringTool\Client\conf
  • 기본 경로에 설치한 경우: C:\EdgeHub\DataWorX\bin\EngineeringTool\Client\conf
설정 파일용도기본값
client-port.conf웹 브라우저로 접속하는 웹 접속 포트7600
server-port.confDataWorX 서버(백엔드)가 사용하는 포트5000

웹 브라우저의 요청은 웹 접속 포트로 들어온 뒤, 내부적으로 서버 포트로 전달되어 처리됩니다.

웹 접속 포트 변경​

client-port.conf 파일을 문서 편집기로 열어 listen 값을 원하는 포트로 변경합니다.

listen 7600;

예를 들어 접속 포트를 8080으로 변경하려면 listen 8080; 으로 수정하고, 웹 브라우저에서 http://[서버 IP]:8080 형식으로 접속합니다.

서버 포트 변경​

server-port.conf 파일을 열어 proxy_pass 주소의 포트를 변경합니다.

proxy_pass http://127.0.0.1:5000;

DataWorX 서버는 이 파일에 설정된 포트로 동작하며, 웹 서버도 동일한 포트로 요청을 전달합니다. 포트 값을 찾지 못하는 경우 기본값 5000으로 동작합니다.

:::caution 포트 변경 시 주의사항

  • 설정 파일을 변경한 후에는 DataWorX 서비스(서버 및 웹 서버)를 재시작해야 변경 사항이 적용됩니다.
  • 다른 프로그램이 이미 사용 중인 포트는 피해서 설정하십시오. 포트가 충돌하면 정상적으로 실행되지 않습니다.
  • 변경한 포트는 Windows 방화벽 등에서 허용되어 있어야 외부에서 접속할 수 있습니다. :::

이력 DB 설치 및 제거​

이력 DB 설치는 DataWorX 설치와 별개로 이루어집니다. DataWorX는 태그 이력과 알람 이력 로깅을 위해 PostgreSQL을 사용하며, 기본 설정 정보 대신 사용자가 설정을 변경하여 설치할 수 있습니다.

설치​

PostgreSQL 설치 마법사에서 다음 항목을 설정합니다.

설정 항목DataWorX 기본값 / 권장
설치 경로기본값 사용
ComponentsPostgreSQL Server, Command Line Tools 필수. pgAdmin, Stack Builder는 선택
data 저장 경로기본값 C:\EdgeHub\DataWorX\bin\Historian\pgData
비밀번호dxmaster
Port 번호7678
Cluster LocaleDefault locale

pgAdmin은 PostgreSQL 데이터 관리에 유용하지만, 설치 후 pgAdmin 다운로드 페이지에서 최신 버전을 따로 받아 설치할 수 있으므로 기본 설치 components에서는 제외되어 있습니다.

:::warning 포트/비밀번호를 변경한 경우 PostgreSQL 설치 시 port 번호나 비밀번호 설정을 변경했다면, 다음 파일들도 동일하게 변경해야 합니다.

  • 템플릿 프로젝트: [DataWorX 설치경로]\bin\EngineeringTool\Server\template\[패키지명]\Config\DX-HISTORIAN.conf
  • 사용자 프로젝트: [Project 경로]\[Project 명]\Config\DX-HISTORIAN.conf

해당 정보는 PostgreSQL에 이력 DB를 구성할 때 사용됩니다. :::

설치 확인​

  1. PostgreSQL 설치 경로와 data 저장 경로에 정상적으로 설치되었는지 확인합니다.
  2. 작업관리자 → 서비스에서 dataworx-historian-pg가 실행 중인지 확인합니다.
  3. 작업관리자 → 자세히에서 postgres.exe가 실행 중인지 확인합니다.

제거​

PostgreSQL 설치 경로 내의 uninstall 프로그램을 실행하여 PostgreSQL을 삭제합니다.

엔진 언어 설정​

엔진 언어 설정을 통해 한국어와 영어를 선택할 수 있습니다. 이 설정으로 Report와 Modbus Server 엔진의 언어가 결정됩니다.

로컬 PC 하단의 DataWorX 트레이 아이콘에서 설정하며, 예 버튼을 클릭하고 EdgeHub를 재기동하면 언어가 적용됩니다.

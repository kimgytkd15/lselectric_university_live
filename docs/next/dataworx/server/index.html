서버

DataWorX를 통해 수집한 데이터를 외부 시스템에 전달하기 위한 페이지입니다. 현재 Modbus Server와 OPCUA Server를 생성할 수 있습니다.

서버 관리​

작업방법
서버 추가서브 내비게이션 상단 또는 테이블 우측 상단의 서버 추가 버튼
서버 정보서브 내비게이션 메뉴 / 테이블 행 더보기 / 테이블 Lock 모드에서 열기 버튼
서버 수정서브 내비게이션 메뉴 / 테이블 행 더보기 / 테이블 Edit 모드에서 열기 버튼
서버 삭제서브 내비게이션 메뉴 / 테이블 행 더보기
서버 내보내기테이블 우측 상단 더보기 → 내보내기. server_tags_[날짜] 파일로 태그 정보 다운로드
노트

서버에 추가된 태그가 없으면 내보내기 시 에러 토스트가 나타납니다.

태그 설정​

서브 내비게이션 또는 테이블의 서버명을 클릭하여 이동합니다.

  1. 테이블 우측 상단의 태그 등록 버튼을 클릭합니다.
  2. 모달 제목 하단의 필드에서 서버의 특정 속성 또는 태그 속성을 변경합니다.
  3. 테이블에서 등록할 태그를 선택하고 확인을 클릭합니다.
  4. 태그 목록 페이지에서 등록된 태그를 확인합니다. 페이지 좌측 하단 스낵바에 성공·복제·무효 건수가 표시됩니다.

태그 제거는 테이블 행 더보기 메뉴 또는 다중 선택 후 테이블 좌측 상단의 제거 버튼으로 수행합니다.

OPC UA 서버 설정​

서버 추가 리스트에서 OPCUA를 선택한 후 확인 버튼을 누릅니다.

서버 속성​

속성설명
서버명서버 이름
포트포트 번호
인증서 자동 수락접속하는 OPC UA Client의 인증서를 자동 수락할지 설정
익명 유저 허용Anonymous(익명) 사용자 접속을 수락할지 설정

:::caution 인증서 / 사용자 설정

  • 인증서 자동 수락을 OFF한 경우, 인증서는 [DataWorX 설치경로]\bin\Connectivity\OPCUAServer\Config\PKI\rejected에 저장되며, ...\PKI\trusted\certs 위치로 수동 이동해야 합니다.
  • 익명 유저 허용을 OFF한 경우, 서버 사용자를 등록하여 접속해야 합니다.
  • 서버 사용자는 필수 등록 항목이 아니며, 익명 사용자로 접속할 수 있습니다. :::

태그 등록​

  1. 테이블 우측 상단의 태그 등록 버튼을 클릭합니다.
  2. 테이블에서 등록할 태그 또는 그룹을 선택하고 확인을 클릭합니다.
노트
  • 태그 등록에서 그룹을 선택하는 경우, OPC Server에 Object로 추가되며 하위 폴더 내용이 모두 한 번에 추가됩니다.
  • 태그 설정의 태그값 쓰기 On/Off에 따라, 서버에 등록된 태그의 제어 가능 여부가 결정됩니다.

노드 등록​

  1. 테이블 우측 상단의 노드 등록 버튼을 클릭합니다.
  2. 노드 추가 패널에서 오브젝트 또는 폴더 타입을 선택합니다.
  3. 노드명과 설명을 입력하고 확인을 클릭합니다.

노드는 OPC UA Server에서 데이터의 구조를 만드는 기능으로 폴더와 오브젝트가 있습니다. 폴더는 오브젝트 하위에서 생성할 수 없습니다.

태그 및 노드 제거​

  1. 다음 방법으로 태그 제거 모달을 엽니다.
    • 테이블 행 더보기 메뉴 → 태그 제거 또는 OPCUA 노드 삭제
    • 테이블에서 태그 다중 선택 → 테이블 좌측 상단의 제거 버튼
  2. 모달 하단의 확인 버튼을 클릭합니다.

실행 및 연결​

  1. 프로젝트 정보의 OPCUA Server 실행 모듈 토글을 ON으로 변경합니다.
  2. 프로젝트를 실행합니다.
  3. OPC UA Client에서 opc.tcp://[Hostname 또는 Server IP]:[포트 번호]/[프로젝트명]으로 접속합니다.
    • 예: opc.tcp://WAOLTVQINH2DKUR.LSWORKPLACE.COM:53880/Manual

NodeId는 identifierType으로 String을 사용합니다.

  • 예: ns = 1, s = TAG명

런타임 (Runtime)

VisualWorX Runtime은 HTML5 기술을 적용한 웹 페이지와 자바스크립트로 구성됩니다. VisualWorX Server에서 서비스하는 프로젝트 정보를 전송받아 모니터링을 수행합니다.

:::caution 실행 조건 VisualWorX Runtime이 정상적으로 실행되려면 EdgeHub DataWorX와 VisualWorX Server가 실행되어 있어야 합니다.

HTML5 표준을 지원하는 웹 브라우저(Chrome, FireFox 등)에서 실행할 수 있으며, Chrome 최신 버전을 권장합니다. :::

로그인​

  1. 웹 브라우저의 주소 창에 VisualWorX Server의 주소를 입력하면 로그인 화면이 표시됩니다.
  2. VisualWorX 프로젝트에 등록된 사용자 ID와 PW를 USER_ID와 PASSWORD에 입력한 후 LOGIN 버튼을 클릭합니다.

자동 로그인​

자동로그인 항목을 체크하고 로그인하면, 추후 Runtime 경로로 재진입 시 자동으로 로그인되어 마지막으로 보던 화면이 표시됩니다.

  • 브라우저가 꺼졌다 켜져도, 서버가 재부팅되어도 자동 로그인은 유지됩니다.
  • 단, 자동 로그인을 설정하고 로그인한 시점으로부터 365일이 지나면 해제됩니다. 이후 브라우저를 다시 켜거나 서버가 재부팅되면 재로그인이 필요합니다.
  • 웹 클라이언트 툴바 우측 상단의 로그아웃을 선택하면 자동로그인이 해제되고 로그인 창으로 리다이렉트됩니다.

재접속​

Runtime 실행 중 네트워크가 끊어지거나 서버가 종료되면 재접속 팝업이 노출됩니다.

  • 네트워크 이상 시 — 재접속 팝업 노출 후, 네트워크 정상화 시 기존 페이지로 전환
  • 서버 종료 시 — 재접속 팝업 노출 후, 서버 가동 시 로그인 페이지로 전환

클릭 동적 특성​

클릭 동적 특성이 설정된 객체에 대해 사용자는 마우스로 동작을 실행합니다. 해당 객체는 마우스 커서에 반응하여 테두리를 표시하며, 페이지 이동·값 입력 등의 동적 특성을 실행합니다.

설정 방법은 동적 특성 — 클릭 동작을 참고하세요.

태그 뷰어​

툴바에서 태그 뷰어 버튼을 클릭하면 태그 뷰어가 표시됩니다.

태그를 더블클릭하면 태그 상세 화면이 표시되며, 변경값을 입력하고 적용 버튼을 클릭하여 해당 태그의 값을 변경할 수 있습니다.

노트

태그 뷰어에 표시되는 태그/그룹은 각 사용자에게 할당된 태그/그룹 설정에 따릅니다. 단, 관리자 권한을 갖는 경우 모든 태그가 표시됩니다.

보고서 뷰어​

툴바에서 보고서 버튼을 클릭하면 보고서 뷰어가 표시됩니다.

로그인한 사용자에게 설정된 보고서그룹에 속한 폴더들이 표시됩니다. 폴더를 더블클릭하여 들어가면 보고서 파일들을 확인할 수 있습니다.

파일 형식지원 기능
PDFPDF 보기 + 다운로드
엑셀다운로드만 지원

파일을 더블클릭하면 보고서 팝업 메뉴가 표시되며, PDF 보기를 실행하면 자체 PDF 뷰어를 통해 보고서를 확인할 수 있습니다.

원격 편집 기능​

VisualWorX Server에서 서비스하는 프로젝트를 원격에서 편집하는 기능입니다. 웹브라우저를 통해 VisualWorX Editor 기능을 실행하여 감시화면 페이지 편집과 사용자 정보 편집을 수행합니다.

:::warning 기능 제한 원격 편집기에서는 그래픽 라이브러리, 스마트 심볼, 프로젝트 관리 등의 기능을 사용할 수 없습니다. :::

원격 편집기 로그인​

원격 편집기를 실행하려면 관리자 권한으로 로그인해야 합니다.

  1. 웹 브라우저 주소 창에 원격 편집기 주소를 입력합니다.
    • 주소 형식: http://IPAddress:Port/editor
    • 예: http://192.168.0.11:80/editor
  2. VisualWorX 프로젝트에 등록된 사용자 ID와 비밀번호를 입력한 후 Login 버튼을 클릭합니다.
  3. 웹소켓 포트 항목은 기본값으로 2160을 표시합니다. VisualWorX Server의 웹소켓 포트 값이 변경된 경우, 서버 설정값과 동일한 값을 입력한 후 로그인합니다.

로그인되면 원격 편집기에 프로젝트가 표시되며, 일부 제한 기능을 제외하고 로컬 VisualWorX Editor와 동일하게 사용할 수 있습니다.

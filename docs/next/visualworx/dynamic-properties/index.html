동적 특성

오브젝트의 동적 특성을 설정하면 태그값에 따라 크기·위치·색상 등이 변화하는 애니메이션과, 클릭으로 페이지를 전환하거나 값을 쓰는 유저 액션을 구현할 수 있습니다.

오브젝트를 선택하고 우클릭하여 컨텍스트 메뉴에서 동적 특성 설정 메뉴를 실행합니다. 애니메이션을 수반하는 동적 특성은 기본적으로 태그와 연계됩니다.

설정 창 공통 항목​

속성설명
…동적특성 표시를 위해 입력값을 받을 태그를 태그 선택기 창에서 선택
스크립트연산식을 사용하여 동적특성을 표시. 동적특성 스크립트 참고
확인변경 내용을 저장하고 창을 닫음
적용변경 내용을 저장하고 창을 유지. 창을 닫지 않고 객체 간을 이동하며 설정할 때 사용
취소설정한 내용을 저장하지 않고 화면을 닫음

:::warning 동적 특성 주의사항

  • 동적 특성은 오브젝트별로 설정합니다.
  • 오브젝트별로 설정할 수 있는 동적 특성이 상이합니다.
  • 동적 특성이 실행되려면 해당 동적 특성 이름에 체크 표시가 되어야 합니다. 체크된 동적 특성의 입력 항목에 대해 입력 오류 체크를 실행합니다.
  • 하나의 오브젝트에 복수 개의 동적 특성을 설정할 수 있습니다. :::

크기 및 이동​

수평크기 / 수직크기​

수평·수직 방향으로 크기가 변화하는 동적 특성입니다.

속성설명
태그이름동적특성을 적용시킬 태그명. 스크립트에서 DBSource로 데이터를 가져오는 방식으로 DB값에 따라서도 적용 가능
이동방향크기가 변화할 방향
데이터변화 범위동적특성에 사용되는 태그 입력값의 범위. 예를 들어 최소값 50, 최대값 100을 설정하면 태그값이 50~100 사이일 때 동적 특성을 표시. 값 입력의 범위 제한은 없으나 입력 태그값의 범위를 고려하여 입력
크기변화 범위크기 변화 범위를 퍼센트(%) 단위로 입력. 0~100 사이

수평이동 / 수직이동​

수평·수직 방향으로 이동하는 동적 특성입니다. 태그이름, 이동방향, 데이터변화 범위는 크기 변화와 동일합니다.

속성설명
이동 변화범위(픽셀)이동 범위를 픽셀 단위로 0~9999 사이 입력. 최소이동의 값은 0으로 고정
주의

캔버스 크기보다 큰 값을 입력하면 오브젝트가 화면 바깥으로 이동하여 표시되지 않을 수 있습니다.

수평채우기 / 수직채우기​

수평·수직 방향으로 채워지는 동적 특성입니다.

수평끌기 / 수직끌기​

사용자가 오브젝트를 드래그하여 태그값을 변경하는 동적 특성입니다.

표시 변화​

이미지​

태그 또는 DBSource의 값에 따라 보여줄 이미지를 다르게 설정합니다.

속성설명
기준값설정어떤 값에서 어떤 이미지를 보여줄지 설정
행삽입 / 행삭제기준값을 추가 / 삭제

색상​

태그값에 따라 오브젝트의 색상을 변화시킵니다.

문자표시​

태그값에 따라 표시할 문자열을 설정합니다.

값 표시​

태그의 값을 오브젝트에 표시합니다. 태그값 오브젝트에서 사용합니다.

점멸 / 출몰 / 회전​

  • 점멸 — 태그값에 따라 오브젝트를 깜빡이게 표시
  • 출몰 — 태그값에 따라 오브젝트를 표시/숨김
  • 회전 — 태그값에 따라 오브젝트를 회전

프레임 애니메이션​

여러 프레임을 순차적으로 표시하는 애니메이션입니다.

클릭 동작​

클릭 - 페이지 전환​

클릭 시 지정한 페이지로 전환합니다.

클릭 - 디지털값 쓰기​

클릭 시 디지털 태그에 값을 씁니다.

클릭 - 값입력​

클릭 시 값 입력 창을 표시하여 태그에 값을 씁니다.

노트

런타임에서 클릭 동적 특성이 설정된 객체는 마우스 커서에 반응하여 테두리를 표시합니다. 자세한 내용은 런타임 — 클릭 동적 특성을 참고하세요.

동적특성 스크립트​

태그 연산식을 사용하려면 스크립트 버튼을 클릭하여 태그를 불러오고 스크립트를 작성하는 창을 엽니다.

스크립트에서 DBSource의 데이터를 가져오는 방식으로 작성하면, 태그값뿐 아니라 DB값에 따라서도 동적 특성을 적용할 수 있습니다.

그리기와 편집도구

페이지에 오브젝트를 삽입하고 편집하는 기능입니다. 모든 오브젝트는 메인 메뉴의 삽입 메뉴 또는 툴바 아이콘으로 삽입합니다.

공통 속성​

대부분의 오브젝트는 다음 속성을 공통으로 가집니다.

속성설명
객체이름객체의 이름(객체 타입)
레이어객체가 속한 레이어 번호
Left 좌표, Top 좌표오브젝트를 포함하는 최소경계사각형(MBR)의 좌측상단 좌표값
너비, 높이오브젝트의 너비와 높이
선색 / 선두께오브젝트를 나타내는 선의 색상 / 두께
배경색오브젝트 내부를 채울 색상
선색 없음true일 경우 오브젝트의 선색을 투명 처리
배경색 없음true일 경우 오브젝트의 배경색을 투명 처리

그리기 (일반)​

문자​

삽입 → 문자 메뉴 또는 툴바의 문자 아이콘으로 삽입합니다.

공통 속성 외에 다음 속성을 가집니다.

속성설명
전경색문자의 색상
폰트종류 / 폰트크기 / 폰트스타일문자의 폰트 설정
가로정렬텍스트를 Left / Center / Right로 정렬
세로정렬텍스트를 Top / Middle / Bottom으로 정렬

태그값​

삽입 → 태그값 메뉴로 삽입합니다. 동적 특성 설정(값 표시)을 통해 태그를 선택하면 태그의 값을 표시합니다.

속성은 문자 오브젝트와 동일합니다.

그림​

삽입 → 그림 메뉴로 삽입합니다. 파일 선택 다이얼로그에서 그림 파일을 선택하면 페이지 중심에 삽입됩니다.

사용 가능한 포맷: bmp, gif, jpg, png, svg 등

속성설명
이미지 투명색투명 처리할 색상
투명색 적용투명색 적용을 취소할 경우 False. 이미지 투명색을 선택하면 True로 변경
이미지 설정이미지 파일 설정
이미지 비율원본 이미지 비율에 맞게 크기 조정

GIF 애니메이션​

삽입 → GIF 애니메이션 메뉴로 삽입합니다. 삽입될 위치를 클릭한 후 GIF 파일을 선택합니다. 속성은 그림 오브젝트와 동일합니다.

그리기 (도형)​

도형작화 방법
선삽입 → 선. 드래그하여 작화
타원삽입 → 타원. 드래그하여 작화
직사각형삽입 → 직사각형. 드래그하여 작화
둥근 직사각형삽입 → 둥근직사각형. 드래그하여 작화
삼각형삽입 → 삼각형. 드래그하여 작화
다각형삽입 → 다각형. 마우스를 클릭하여 점을 추가. 더블클릭 또는 Esc로 종료
연속선삽입 → 연속선. 다각형과 동일한 방법으로 작화

도형 오브젝트는 공통 속성을 사용합니다. 단, 선 오브젝트는 배경색 관련 속성이 없습니다.

그리기 (컨트롤)​

컨트롤은 마우스를 클릭한 후 드래그하여 크기를 결정하면 화면에 삽입됩니다.

컨트롤설명
알람 뷰어 컨트롤알람 목록 표시. 가로/세로 크기가 각각 100보다 커야 화면에 표시됨
트랜드 뷰어 컨트롤트랜드 차트 표시. 가로/세로 크기가 각각 100보다 커야 화면에 표시됨
데이터 뷰어 컨트롤리스트 형태의 데이터 조회. 가로/세로 크기가 각각 100보다 커야 화면에 표시됨
콤보박스 컨트롤드롭다운 선택. 가로 크기만 변경 가능
에디트박스 컨트롤텍스트 입력
날짜 컨트롤 / 시간 컨트롤날짜 / 시간 선택
리스트박스 컨트롤목록 선택
라디오버튼 컨트롤 / 체크박스 컨트롤단일 / 다중 선택
사운드 컨트롤소리 재생
트리 컨트롤계층 구조 표시
웹뷰어 컨트롤웹 페이지 임베드
파일 오픈 컨트롤파일 선택 및 열기
흐름 메세지 컨트롤알람 발생 시 흐름 메시지 표시 (sysRTFlow 참고)
VX 차트 컨트롤각종 차트 표시 (VX 차트 참고)
VX 그리드 컨트롤외부 데이터를 그리드로 표시
VX 텍스트 컨트롤외부 데이터를 텍스트로 표시

:::tip 보조 설정 컨트롤에서 우클릭하여 컨텍스트 메뉴를 표시한 후 보조 설정을 클릭하면 컨트롤별 세부 속성을 설정할 수 있습니다. 런타임에서의 상세 설정은 컨트롤 설정을 참고하세요. :::

:::note 컨트롤 개수 제한 각 컨트롤 객체의 개수는 VisualWorX 서버 설정(editorEnv)에서 제한할 수 있습니다. :::

편집도구​

정렬​

2개 이상 선택된 오브젝트를 정렬합니다.

  • 가로 — 왼쪽 정렬 / 가운데 정렬(좌우) / 오른쪽 정렬
  • 세로 — 위쪽 정렬 / 가운데 정렬(상하) / 아래쪽 정렬

실행취소 / 다시실행​

편집 중 실행취소로 이전 상태로 되돌리거나, 다시 실행으로 원래 상태로 되돌아갑니다. 히스토리는 10개까지 저장됩니다.

그룹 / 그룹 해제​

2개 이상의 오브젝트를 선택한 후 우클릭 → 그룹화 → 그룹 메뉴 또는 툴바의 그룹 아이콘으로 그룹화합니다. 그룹으로 묶인 오브젝트는 하나의 오브젝트처럼 사용할 수 있습니다.

그룹 오브젝트가 선택된 상태에서 서브 오브젝트를 한 번 더 클릭하면 그룹 내의 서브오브젝트를 편집할 수 있습니다.

주의
  • 그룹 오브젝트를 포함시켜 다시 그룹 지을 수 없습니다.
  • 그룹 오브젝트 해제 시, 그룹에 적용된 동적 특성은 삭제됩니다.

문자열 찾기 & 바꾸기​

페이지의 전체 객체에서 사용된 문자열을 찾거나 다른 문자열로 바꿉니다.

속성설명
찾을 내용찾을 문자열
바꿀 내용대체할 문자열
전체 문자열 단위로 바꾸기찾을 내용이 속한 전체 문자열을 바꿀 내용으로 전체 변경
다음 찾기찾을 내용에 알맞은 다음 문자열을 찾음
바꾸기목록에 계획된 문자열로 표시
모두 선택찾을 내용이 속한 모든 문자열을 선택
적용보여지는 목록처럼 문자열을 실제로 변경

태그 찾기 & 바꾸기​

페이지의 전체 객체 또는 선택된 객체에서 매핑된 태그를 찾거나 다른 태그로 바꿉니다. 또한 선택된 태그를 사용하는 객체에 태그정보 및 사용자정의를 툴팁으로 일괄 정의할 수 있습니다.

속성설명
찾을 내용찾을 태그명
바꿀 내용대체할 태그명
태그이름 단위로 바꾸기찾을 내용이 속한 전체 태그이름을 바꿀 내용으로 전체 변경
다음 찾기찾을 내용에 알맞은 다음 태그를 찾음
태그 선택태그 선택기를 열어 변경할 태그명을 선택
바꾸기목록에 계획된 태그로 표시
적용보여지는 목록처럼 태그를 실제로 변경

툴팁 적용 — 객체에 툴팁을 적용하는 기능으로, 오른쪽 객체목록에서 객체를 선택하고 원하는 툴팁을 설정한 후 적용합니다.

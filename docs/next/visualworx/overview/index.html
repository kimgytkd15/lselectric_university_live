VisualWorX 소개

VisualWorX는 OT 영역에서 수집된 데이터를 시각화하여 보여주는, SCADA 역할을 수행하는 웹 기반 소프트웨어입니다.

Microsoft Windows OS를 기반으로 하며, .NET Framework 4.6.2가 설치 가능한 Windows 7 SP1, Windows 8.1 Update1, Windows 10, Windows Server 2012·2022 등에서 사용할 수 있습니다.

VisualWorX를 통해 다양한 그래픽 오브젝트, 차트, 이벤트 스크립트를 설정하여 현장 상황을 감시하고 제어하는 모니터링 화면을 구축할 수 있습니다.

:::info 문서 기준 버전 이 문서는 VisualWorX v5.0.0 (온라인 매뉴얼 v3.0.1) 기준으로 작성되었습니다. :::

시스템 구성​

VisualWorX는 클라이언트/서버 구조로 구성됩니다.

  • 서버 측에는 VisualWorX Server, Runtime, Editor가 설치됩니다.
  • VisualWorX Runtime과 Editor는 웹 브라우저에서도 접속 가능합니다.
  • Editor로 작화한 화면은 Server를 통해 Runtime에서 서비스됩니다.
  • 원격에서 Server에 접속하여 작화하고, 현장 상황을 감시·제어할 수 있습니다.
[VisualWorX Editor] ──작화──▶ [VisualWorX Server] ──서비스──▶ [VisualWorX Runtime]
                                       ▲
                                       │ 태그 데이터
                                [EdgeHub DataWorX]

주요 특징​

그래픽 오브젝트​

선, 타원, 직사각형 등의 기본 도형과 컨트롤 박스 등을 활용하여 다양한 시각화 디자인이 가능하며, 애니메이션 효과로 다이나믹한 모니터링 설계가 가능합니다.

차트​

라인, 바, 분산, 영역, 파이, 도넛, 버블, 게이지, 박스 플롯, 정규분포 등 다양한 차트를 제공합니다. 자세한 내용은 VX 차트를 참고하세요.

이벤트 스크립트​

모니터링 페이지에서 클릭, 값 변경, 마우스 이동 등의 이벤트 발생 시 JavaScript를 활용하여 화면을 제어하거나 데이터 값을 변경하는 등 세부 기능을 구현할 수 있습니다. 자세한 내용은 이벤트 스크립트를 참고하세요.

Web 기반 시스템​

웹 브라우저를 활용하여 VisualWorX 시스템에 접속해 엔지니어링과 런타임을 수행합니다. VisualWorX 서버 머신에 직접 가지 않아도 인터넷 환경에서 원격으로 모든 작업이 가능합니다.

시스템 요구 규격​

프로그램을 실행하기 위한 권장 사양은 다음과 같습니다.

구분권장 사양
운영체제Microsoft Windows 10 64bit (Pro 버전 이상)
메모리8GB 이상
디스플레이기본 해상도 1024 × 768 이상의 VGA 그래픽 카드 및 모니터
저장공간10GB 이상의 하드 디스크 여유 공간
네트워크Ethernet Card 100Mbps 이상
통신 포트표준 Serial Port (Serial 통신 사용 시)

라이선스​

VisualWorX는 실물이 없는 SW 형태의 라이선스를 사용합니다.

처음 설치하면 14일간 무료로 사용할 수 있는 Trial 라이선스로 서비스를 시작할 수 있습니다. Trial 라이선스는 동시 접속 가능한 Client가 무제한이며, 이중화 기능과 차트 기능을 14일간 사용할 수 있습니다.

라이선스 발급·등록·이전 절차는 서버 — 라이선스를 참고하세요.

서버

VisualWorX Server는 VisualWorX 프로젝트와 EdgeHub DataWorX의 데이터를 VisualWorX Runtime에게 전송하기 위한 서비스를 제공합니다.

서버 실행​

  1. 프로그램 메뉴에서 VisualWorX Server를 선택하여 시작합니다.
  2. 실행되면 작업 표시줄에 아이콘이 생성되며 시작 메시지가 표시됩니다.
노트

VisualWorX Server를 최초 실행한 경우 중지된 상태로 실행됩니다. 아이콘을 우클릭하여 서비스 설정 작업과 라이선스 등록을 마친 후 서비스를 시작할 수 있습니다.

서비스 설정​

작업 표시줄 트레이 아이콘을 우클릭하여 서비스 설정 메뉴를 선택합니다.

이중화 설정​

회선 이중화​

회선 이중화는 보조 IP를 두어 양쪽 모두 서비스하는 기능입니다.

  • 회선이중화를 체크하면 기본IP, 보조IP가 활성화됩니다.
  • 시스템이중화까지 체크하면 Master IP1·2, Standby IP1·2 총 6개의 입력란이 활성화됩니다.
  • 기본IP·보조IP에는 현재 서버에서 서비스할 IP를 입력합니다.
  • Master IP1·2, Standby IP1·2에는 Master·Standby 측에서 서비스하는 기본·보조 IP를 입력합니다.

클라이언트 접속 IP에 따른 절체:

  • 접속 IP가 기본IP인 경우 → 시스템 이중화 역할에 따라 Master IP1 또는 Standby IP1로 절체
  • 접속 IP가 보조IP인 경우 → 시스템 이중화 역할에 따라 Master IP2 또는 Standby IP2로 절체

설정 예시

Master 역할 A PC의 서비스 IP가 10.13.110.110, 10.13.111.111이고, Standby 역할 B PC의 서비스 IP가 10.13.112.112, 10.13.113.113일 때:

  • A PC — 기본IP·보조IP·Master IP1·2에 10.13.110.110, 10.13.111.111 / Standby IP1·2에 10.13.112.112, 10.13.113.113
  • B PC — 기본IP·보조IP·Standby IP1·2에 10.13.112.112, 10.13.113.113 / Master IP1·2에 10.13.110.110, 10.13.111.111

시스템 이중화​

시스템 이중화는 Master와 Standby IP를 두고, 한쪽이 끊길 경우 다른 한쪽으로 접속하는 클라이언트 절체를 수행합니다.

시스템이중화를 체크하면 기본IP, Master IP1, Standby IP1이 활성화됩니다.

설정 예시

A PC(10.13.110.110)가 Master, B PC(10.13.111.111)가 Standby인 경우:

  • A PC의 기본IP → 10.13.110.110 / B PC의 기본IP → 10.13.111.111
  • 두 PC 모두 Master IP1에 10.13.110.110, Standby IP1에 10.13.111.111을 입력

:::warning IP 설정 규칙

  • 역할이 Master인 경우, 기본IP = Master IP1, 보조IP = Master IP2
  • 역할이 Standby인 경우, 기본IP = Standby IP1, 보조IP = Standby IP2
  • Master IP와 Standby IP는 서로 달라야 합니다. :::

클라이언트 이중화​

시스템 이중화 설정 시 클라이언트가 접속했을 때 화면이 자동 절체되는 기능입니다.

  • Master PC와 Standby PC 모두 Active인 경우: Standby PC로 접속 시 Master PC 화면으로 전환
  • Master PC 화면 접속 중 Master PC가 종료되면 Standby PC 화면으로 자동 절체
  • Master PC가 복구되면 Standby PC 화면이 Master PC 화면으로 자동 절체
노트

localhost 또는 127.0.0.1 IP로 접속한 경우 엔지니어링으로 간주하여 화면 절체가 이루어지지 않습니다.

클라이언트 자동 절체를 원하지 않으면 로그인 화면에서 클라이언트 자동 절체 체크를 해제하고 로그인합니다. 로그인 후에는 런타임 상단 메뉴 툴바에서 다시 체크하여 적용할 수 있습니다.

프로젝트 생성​

서비스 설정 → 프로젝트 설정 → 새 프로젝트 버튼을 실행합니다.

프로젝트의 이름, 타입, 경로, 작성자, 설명을 입력하고 확인 버튼을 클릭합니다. 작성자와 설명은 생략 가능합니다.

:::info 기본 관리자 계정 프로젝트 생성 시 기본 관리자 계정은 ID admin / PW 1234 입니다.

프로젝트 이름은 한글/영문/숫자와 _의 조합으로 최대 60자까지 작성할 수 있습니다. 기본 관리자 설정은 에디터/런타임 로그인 시 필요하며, 에디터의 프로젝트 설정 → 사용자에서 변경할 수 있습니다. :::

SSL 설정​

자체 서명 인증서 생성​

  1. Win32/Win64 OpenSSL에서 OpenSSL을 설치합니다.
  2. 설치한 파일을 실행하여 CMD 창을 엽니다.
  3. 사용자 계정에 certs 폴더를 만듭니다. 이후 OpenSSL에서 생성되는 파일은 이 폴더 아래에 만들어집니다.
  4. 다음 명령어를 차례로 입력합니다.
openssl genrsa -out privKey.pem 1024
openssl req -new -key privKey.pem -out private-csr.pem
openssl x509 -req -days 730 -in private-csr.pem -signkey privKey.pem -out cert.pem
주의

Common Name에는 PC의 IP 주소나 localhost를 입력하십시오.

명령어 입력 후 생성 경로에 3개의 파일이 생성됩니다.

SSL 보안 통신 설정​

  1. 서비스 설정 → 보안통신 → 인증서 관리 버튼을 실행합니다.
  2. 인증서 관리에서 등록 버튼을 실행합니다.
  3. 인증서 파일에는 cert.pem을, 개인키 파일에는 privKey.pem을 각각 등록합니다.
  4. https://(설정한 주소) 로 접속하면 VisualWorX 화면을 확인할 수 있습니다.

라이선스​

트레이 아이콘에서 VisualWorX 아이콘을 우클릭하고 라이선스 메뉴를 선택합니다.

정보

처음 VisualWorX를 설치하면 14일간 무료로 사용할 수 있는 Trial 라이선스로 서비스를 시작할 수 있습니다. Trial 라이선스는 동시 접속 Client 무제한이며, 이중화 기능과 차트 기능을 14일간 사용 가능합니다.

라이선스를 등록하지 않은 상태로 서비스 시작을 하면 알림이 표시되며 서비스를 시작할 수 없습니다.

라이선스 정보​

현재 등록된 라이선스 정보를 확인합니다. 다시 읽기 버튼으로 갱신된 라이선스를 다시 읽어들이고, 자세히 버튼으로 Feature별 상세 내역을 확인할 수 있습니다.

라이선스 발급​

VisualWorX 구매 시 라이선스 키가 메일로 제공됩니다.

  • EID — 오프라인 라이선스 등록을 위한 로그인 ID
  • Product Key — 온라인 라이선스 등록을 위한 제품 번호

라이선스 타입​

타입설명
OnlineVisualWorX가 설치된 PC가 LSE 라이선스 서버와 통신 가능한 경우, 메일로 발급받은 라이선스를 등록
Offline통신이 불가능한 경우, 오프라인 키를 생성한 후 라이선스 등록 사이트에서 활성화 키를 발급받아 등록 (.v2cp, .v2c, .h2r, .r2h, .h2h)

온라인 라이선스 등록​

  1. 라이선스 메뉴에서 라이선스 등록 메뉴를 클릭합니다.
  2. 라이선스 메일에 기재된 Product Key를 제품 키(pkId) 에 입력한 후 등록 버튼을 클릭합니다.
  3. 라이선스 정보 화면에서 등록을 확인합니다.

오프라인 라이선스 등록​

  1. 라이선스 메뉴에서 오프라인 유저키 다운로드를 클릭하여 VisualWorX_Information.c2v 파일을 다운로드합니다.
  2. 인터넷이 가능한 PC에서 ls-electric.prod.sentinelcloud.com/customer에 접속합니다.
  3. 라이선스 파일에 기재된 EID 또는 Product Key를 입력하여 로그인합니다.
  4. Activate Offline 버튼을 클릭하고, 라이선스 인증 파일을 받을 E-Mail 주소를 입력합니다.
  5. Select File 버튼으로 1단계의 *.c2v 파일을 업로드합니다.
  6. Complete Activation을 클릭하여 오프라인 라이선스를 활성화합니다.
  7. Activation was successful 메시지와 함께 오프라인 라이선스 파일(*.v2cp)을 다운로드합니다. 입력한 E-Mail 주소로도 압축 파일이 전송됩니다.
  8. 다운로드한 *.v2cp 파일을 업로드하고 등록 버튼을 클릭합니다.
  9. 라이선스 정보 화면에서 등록을 확인합니다.

라이선스 이전 (Transfer)​

사용 중인 라이선스를 다른 PC로 옮기는 기능입니다.

  • 실행 파일 경로: [VisualWorX 설치 경로]\ETC\LicenseRehostTool\LicenseRehostTool.exe
  • 기본 경로 설치 시: C:\EdgeHub\VisualWorX\ETC\LicenseRehostTool\LicenseRehostTool.exe
노트

본 라이선스 이전 방식은 VisualWorX v5.0.0 이후 적용되는 방식입니다. v5.0.0 이전 버전의 라이선스 키를 마이그레이션하거나 계속 유지해야 하는 경우 LS ELECTRIC 측에 문의하십시오.

이전 작업에는 두 대의 PC(새 PC, 기존 PC)가 사용되며, 두 PC 모두에서 LicenseRehostTool.exe를 실행합니다.

1. [새 PC] 정보 파일(.id) 생성

  1. 새 PC에서 LicenseRehostTool.exe를 실행합니다.
  2. Step 1. Generate New PC Info (New PC) 영역으로 이동합니다.
  3. Save PC Info File (.id) 우측의 ... 버튼으로 저장 경로를 지정합니다.
  4. Create 버튼으로 정보 파일(.id)을 생성하고, USB 등으로 기존 PC에 복사합니다.

2. [기존 PC] 이전 파일(.h2h) 생성

  1. 기존 PC에서 LicenseRehostTool.exe를 실행합니다.
  2. Step 2. Export License File (Current PC) 영역으로 이동합니다.
  3. Select License to Transfer 목록에서 이전할 제품 라이선스를 선택합니다.
  4. Import New PC Info File (.id) 우측의 ... 버튼으로 1단계의 .id 파일을 불러옵니다.
  5. Save Transfer File 우측의 ... 버튼으로 저장 경로를 지정합니다.
  6. Create 버튼으로 이전 파일(.h2h)을 생성하고, USB로 새 PC에 복사합니다.

3. [새 PC] 라이선스 활성화

새 PC에서 제품 프로그램을 실행하고, 2단계의 .h2h 파일을 라이선스 등록 창에 등록하여 활성화를 완료합니다.

:::danger 필수 주의 사항 1. 실행 중인 제품 세션 확인 — 기존 PC에서 .h2h 파일을 생성하기 전에 해당 제품 프로그램이 완전히 종료되어 있어야 합니다. 종료 후에도 세션이 남아있다면 http://localhost:1947/_int_/sessions.html에 접속하여 해당 세션의 Actions 열에서 Disconnect 버튼으로 강제 종료하십시오.

2. 이전 파일(.h2h) 분실 주의 — 생성된 .h2h 파일을 분실하면 어떠한 경우에도 다시 생성할 수 없습니다. 이 경우 기존 PC와 새 PC 모두에서 라이선스를 사용할 수 없게 되며, 사전 백업 미이행으로 인한 라이선스 분실은 무상 재발급 및 보상이 지원되지 않습니다. :::

트레이 아이콘을 우클릭하고 서비스 상태 메뉴를 선택합니다.

사용자 계정상태 관리​

사용자 계정상태를 확인하는 창이 열립니다. 처음 만든 사용자는 패스워드에 초기값이라고 표시되고, 잠김 상태는 잠김해제입니다. 패스워드 변경 시 적용됨으로 바뀝니다.

admin은 다른 사용자의 행을 선택하고 우클릭하여 계정잠금할 수 있습니다.

:::note 잠김 상태 용어

  • 기한잠김 — 로그인 시도 중 인증실패횟수(CFG_AUTHERR_LIMIT)에 도달하여, 로그인 접근 차단 시간(CFG_AUTHERR_ACCINTERVAL)까지 사용자 로그인이 잠긴 상태
  • 계정잠김 — 사용자 계정상태 관리 창에서 admin이 우클릭으로 사용자 계정을 잠근 상태 :::

인증 규칙 설정 — 프로젝트 경로의 Database\VX_CONFIG.db의 USER_CONFIGRULE 테이블에서 변경합니다.

칼럼명기본 값설명
CFG_PWDRULE{"min":8,"max":15,"special":0,"upper":0,"number":0}패스워드 생성 룰. min/max 길이, special 특수문자 최소 개수, upper 대문자 최소 개수, number 숫자 최소 개수
CFG_AUTHERR_LIMIT5인증 실패 시 로그인 인터벌을 주는 실패횟수의 합
CFG_AUTHERR_ACCINTERVAL005MI인증 실패 한도 도달 시 다음 로그인 허용 인터벌. 세 자리 숫자 + 두 자리 시간 구분(SS 초 / MI 분 / HH 시간). 값이 0이면 영구
CFG_PWD_CHGINTERVAL006MM패스워드 변경주기. 시간 구분(HH 시 / DD 일 / MM 월 / YY 년)
CFG_SESSNOUSE_EXPIRETIME006HH미사용 시 세션잠금(로그아웃) 기준 시간. 시간 구분(MI 분 / HH 시 / DD 일)

로그인 상태 보기​

로그인 상태를 확인하는 창이 열립니다. 접속해 있는 사용자 세션을 우클릭하여 종료시킬 수 있습니다.

이중화 상태​

노트

이중화 상태 메뉴는 동일한 PC에서 DataWorX 프로젝트가 Open 혹은 Run 상태일 때만 나타납니다.

라벨설명
이중화 역할현재 VisualWorX Server의 역할 (Master / Standby)
로컬DX동일 PC에서 DataWorX의 상태 (Run / Open)
접속상태이중화 설정된 상태 PC와의 연결 상태 (Listening / Connecting / Connected)

VisualWorX 설정 (VisualWorXServer.info)​

[VisualWorX 설치경로]\Server\VisualWorXServer.info 파일을 메모장으로 열어 설정을 변경합니다.

주의

아래 설정을 변경하면 VisualWorX Server 종료 후 재실행이 필요합니다.

일반 속성​

속성설명
pkgVersion설치된 VisualWorX의 version
licServerLSE 라이선스 서버 (라이선스키 등록 시 필요)
useHistRealRTSM태그 히스토리안 정주기·문자열 이력데이터 로드 시, 실시간값(true)을 사용할지 이력값(false)을 사용할지
useSetTagLogging태그값 제어 시 로깅 여부

networkServiceConfig​

서버 설정과 연관된 속성입니다.

속성설명
httpServicePortVisualWorX Server가 서비스할 포트
httpBackendPorthttp의 백엔드로 동작하는 웹서버의 포트
websocketBackendPorthttp의 백엔드로 동작하는 웹소켓 서버의 포트
proxyBundledFiles정적 파일을 백엔드 웹서버로부터 전달받아 서비스할지 여부. 기본값 false
waitForBindableIP서비스 시작 시 설정된 엔드포인트로 서비스가 가능해질 때까지 대기. checkIntervalSec 확인 주기(초), maxAttempts 최대 시도 횟수(초과 시 서비스 시작 안 됨)

redundant​

시스템 이중화 설정과 연관된 속성입니다.

속성설명
SyncServer.bindIp해당 VisualWorX 서버가 TCP 서버로 동작할 때 바인딩될 IP 주소
SyncServer.portTCP 서버로 동작하거나 원격 서버로 접속할 때 사용할 포트번호. Master와 Standby 양쪽 모두 동일하게 설정
SyncServer.preSharedKey서버 간 송수신 데이터를 암호화하기 위한 32바이트 Hex 문자열의 AES 암호화 키. Master와 Standby 양쪽 모두 동일하게 설정

editorEnv​

그리기(컨트롤)와 연관된 속성으로, 페이지에 배치할 수 있는 컨트롤 개수를 제한합니다.

속성설명
pageConfigVisualWorX Editor의 페이지에 대한 설정
embedObjectCount알람뷰어, 트랜드뷰어 등 임베디드된 객체들에 대한 정의
embedObjectTotalCount임베디드된 객체들의 총 제한 개수
trendViewCount / dataViewCount트랜드뷰어 / 데이터뷰어 컨트롤의 제한 개수
comboCount / editBoxCount / listBoxCount콤보박스 / 에디트박스 / 리스트박스 컨트롤의 제한 개수
radioButtonCount / checkBoxCount / treeCount라디오버튼 / 체크박스 / 트리 컨트롤의 제한 개수
dbChartCount / dbGridCountVX 차트 / VX 그리드 컨트롤의 제한 개수
alarmViewCount / webViewCount / soundCount알람뷰어 / WebView / 사운드 컨트롤의 제한 개수
datePickerCount / timePickerCount날짜 / 시간 컨트롤의 제한 개수
trendview.channelCount트랜드뷰어의 채널 제한 개수
dataview.channelCount데이터뷰어의 채널 제한 개수
dbchart.channelCountVX 차트의 채널 제한 개수
경고

콜론(:) 뒤의 숫자를 변경해서 설정하며, -1은 제한 없음입니다. 값을 너무 많이 늘리면 VisualWorX 성능에 영향을 끼칠 수 있으니 주의하십시오.

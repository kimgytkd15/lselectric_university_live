이벤트 스크립트

오브젝트 및 페이지의 이벤트 발생 시 실행할 스크립트를 작성할 수 있습니다. 스크립트는 자바스크립트(JavaScript) 언어로 작성해야 합니다.

:::tip 자동 완성 단어를 완성하려면 Ctrl + Space 키를 사용합니다. 예를 들어 Open을 입력하고 Ctrl + Space를 누르면 Open으로 시작하는 단어 리스트가 표시됩니다. 해당 단어가 하나만 존재할 경우 단어가 완성되어 표시됩니다.

감시화면 내의 객체는 객체 이름으로 접근할 수 있습니다. :::

캔버스 스크립트​

페이지(캔버스) 단위의 이벤트입니다.

이벤트명내용
OnInitialize해당 페이지가 띄워질 때 발생
OnDispose해당 페이지가 닫힐 때 발생
OnUpdate해당 페이지가 갱신될 때 발생

기본 스크립트​

오브젝트 공통 이벤트입니다.

이벤트명내용
OnClick마우스 클릭 이벤트
OnDblClick마우스 더블 클릭 이벤트
OnInitialize객체 초기화 이벤트
OnLButtonDown / OnLButtonUp마우스 왼쪽 버튼 눌림 / 놓음 이벤트
OnMouseMove마우스 이동 이벤트
OnRButtonDown / OnRButtonUp마우스 오른쪽 버튼 눌림 / 놓음 이벤트
OnUpdate객체 갱신 이벤트

페이지 제어 함수​

OpenPage(PageName, TagParam, Callback?)

팝업 창을 열어 페이지를 표시합니다.

인자설명
PageName오픈할 페이지 이름
TagParam템플릿 화면에서 태그를 대체할 이름들. 교체할 태그를 지정하지 않을 경우 빈 문자열("") 지정
Callback팝업 페이지로부터 결과를 받음 (선택)
OpenPage("페이지1", "$TagGroup=감시화면");

OpenPage("페이지1", "$TagGroup=감시화면", (object) => {
  console.log(object);
});

OpenPageEx(x, y, width, height, pageName, TagParam, Callback?)

OpenPage에 창의 위치와 크기가 추가된 함수입니다.

인자설명
x, y창의 위치 좌표
width, height창의 너비와 높이
PageName, TagParam, CallbackOpenPage와 동일
OpenPageEx(100, 100, 800, 600, "페이지1", "$Tag=SOLAR");

OpenPageEx(100, 100, 800, 600, "페이지1", "$Tag=SOLAR", (object) => {
  console.log(object);
});
팁

API를 사용하여 화면의 레이아웃을 변경하는 방법은 온라인 매뉴얼의 이벤트 스크립트 — 기본 스크립트를 참고하세요.

컨트롤별 전용 스크립트​

각 컨트롤은 고유한 이벤트와 함수를 제공합니다. 전체 함수 시그니처와 예제는 온라인 매뉴얼의 이벤트 스크립트 페이지를 참고하세요.

스크립트 그룹대상
콤보박스 스크립트콤보박스 컨트롤
에디트박스 스크립트에디트박스 컨트롤
날짜 스크립트 / 시간 스크립트날짜 / 시간 컨트롤
리스트박스 스크립트리스트박스 컨트롤
라디오버튼 스크립트 / 체크박스 스크립트라디오버튼 / 체크박스 컨트롤
사운드 스크립트사운드 컨트롤
트리 스크립트트리 컨트롤
트랜드 스크립트트랜드 뷰어 컨트롤
웹뷰어 스크립트웹뷰어 컨트롤
파일 오픈 스크립트파일 오픈 컨트롤
기타 스크립트공통 유틸리티

VX 객체 스크립트​

VX 차트·그리드·텍스트 컨트롤은 공통 스크립트와 전용 스크립트로 나뉩니다.

스크립트 그룹설명
VX 객체 공통 스크립트VX 차트·그리드·텍스트가 공통으로 사용하는 함수
VX 차트 전용 스크립트차트 전용 함수. 박스플롯차트 전용, 표준정규분포차트 전용 함수 포함
VX 그리드 전용 스크립트setJsonData 등 그리드 데이터 설정 함수
VX 텍스트 전용 스크립트setText, setJsonData 등 텍스트 데이터 설정 함수
노트

VX 컨트롤의 Script 타입 설정에서는 Axios 라이브러리가 내장되어 있어 REST 데이터를 가져와 컨트롤에 넣을 수 있습니다. 자세한 사용법은 컨트롤 설정을 참고하세요.

전역 스크립트와의 관계​

프로젝트 전체에서 공통으로 사용할 함수·변수는 에디터의 전역 스크립트에 선언하고, 이벤트 스크립트에서 Global. 접두어로 호출합니다.

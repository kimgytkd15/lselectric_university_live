설치 및 제거

설치​

  1. Setup 프로그램을 실행하고 설치 언어를 선택합니다.
  2. 설치될 경로를 입력하고 다음으로 진행합니다.
  3. 다음 버튼을 눌러 진행합니다.
  4. 라이선스에 동의합니다.
  5. 사용자 및 조직 정보를 입력합니다.
  6. 설치 옵션을 선택합니다.
    • Complete — 전체 항목 설치 (권장)
    • Custom — 선택 항목 설치
  7. 설치 버튼을 클릭하여 설치를 진행합니다.
  8. OK 버튼을 눌러 VisualWorX 라이선스 프로그램 설치를 마칩니다.
  9. 설치 완료.

기본 설치 경로는 C:\EdgeHub\VisualWorX 입니다.

:::tip 설치 후 첫 실행 VisualWorX Server를 최초 실행한 경우 중지된 상태로 실행됩니다. 트레이 아이콘을 우클릭하여 서비스 설정과 라이선스 등록을 마친 후 서비스를 시작하십시오. :::

제거​

  1. 제어판을 실행한 후 프로그램 및 기능 메뉴로 이동합니다.
  2. 앱 리스트에서 VisualWorX를 선택한 후 제거를 실행합니다.
  3. 확인 대화상자에서 제거 버튼을 클릭합니다.
  4. VisualWorX 프로그램이 정상적으로 삭제되었는지 확인합니다.

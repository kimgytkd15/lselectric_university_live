알람 설정 창 (EdgeHub 프로젝트)​

필터링 설정 / 표시항목 설정 / 일반 설정 / 글꼴 설정 4개의 탭으로 구성됩니다.

필터링 설정

설정명설명
알람 상태알람뷰어에 표시할 알람 상태
알람 종류알람뷰어에 표시할 알람 종류
알람 그룹 (그룹 필터링)그룹 필터링 적용 여부와 대상 그룹 결정. 선택 시 해당 그룹만, 미선택 시 전체 알람태그가 표시됨
알람 그룹 (그룹 전체 선택)그룹 목록의 항목을 전체 선택
알람 그룹 (그룹 이름 필터링)알람그룹이름에 대한 상세 문자 필터링. ; 는 단어단위 구분자, + 는 문자열 단위 구분자
태그 필터링발생 태그이름에 대해 필터링하여 해당하는 알람만 표시. ;, + 구분자 동일
적용 / 닫기설정을 알람뷰 컨트롤에 적용 / 설정 창을 닫음

그룹 이름 필터링 예시 — UT;FA+Grp 를 입력하고 상세 문자 필터링 버튼을 누르면, 알람그룹이름에서 AlmGrp_UT와 AlmGrp_FA 그룹이 자동 설정됩니다.

표시항목 설정 — 표시할 항목을 전체항목에서 드래그/드롭하여 선택항목으로 옮기면 해당 컬럼이 화면에 표시됩니다.

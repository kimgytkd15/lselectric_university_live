DataWorX

EdgeHub DataWorX v4.1.0 데이터 수집 및 관리 소프트웨어 매뉴얼

📄️소개

DataWorX v4.1.0 제품 소개, 주요 특징, 시스템 요구 규격, 라이선스 정책

📄️설치 및 설정

DataWorX 설치·제거, 웹/서버 포트 변경, 이력 DB(PostgreSQL) 설치, 엔진 언어 설정

📄️화면 구성 요소

애플리케이션 바, 프로젝트 바, 메인/서브 내비게이션, 우측 패널, 브레드크럼, 테이블, 알림 바

📄️관리 기능

로그인, 프로필, 라이선스 등록·이전, 사용자 관리, 접근 제어, 시스템 설정·로그·정보

📄️프로젝트

프로젝트 목록·추가·경로·정보·수정·로그·삭제, 시스템/회선/클라이언트 이중화 설정

📄️필드 디바이스

채널·디바이스·블록 등록과 관리, 지원 드라이버 목록

📄️태그

태그 보기 방식, 전체 속성 레퍼런스, 태그 관리, 그룹 관리, Excel·LS PLC 가져오기, 입출력 태그 검사기

📄️로직플로우

LogicFlow 편집기 구성, 노드 카테고리, LSE 전용 노드와 LSE API, 로그·포트 설정

📄️시뮬레이터

시뮬레이션 생성·관리, 태그별 시뮬레이션 타입 설정, 런타임 적용/해제

📄️서버

외부 시스템 연계를 위한 Modbus 서버 / OPC UA 서버 설정과 태그 등록

📄️태그 히스토리안

수집모델 종류(정주기·통계값·적산값·문자열), 수집모델 관리, 수집태그 설정, 보관기간·로깅레벨

📄️알람 매니저

아날로그/디지털 알람의 발생·해제 규칙, 알람 지연, 알람그룹 관리, 알람태그 설정

📄️통신 상태 및 태그 모니터링

디바이스 통신상태 감시와 사용 설정, 런타임 태그값·상태 감시 및 태그값 제어

📄️뷰어

태그 이력, 알람 이력, 실시간 알람, 파일 뷰어 생성과 조회·필터링

📄️보고서

엑셀/일반 보고서 비교, 보고서 편집기, 보고서 속성 정의, 런타임 자동·수동 생성, 제약사항

📄️드라이버

제조사별 통신 드라이버 목록과 상세 매뉴얼 링크
